# Agent 审批令牌：批准一次动作，而不是永久放权

人工审批若只返回一个布尔值，Agent 可能在参数变化后仍复用旧批准。审批结果应绑定具体工具、规范化参数、目标资源和有效期限。

系统先展示即将执行的动作、影响范围、可逆性与费用估计，再生成不可篡改的请求摘要。批准令牌包含该摘要、审批者、签发时间和一次性标识；执行器重新计算摘要并校验，任何参数变化都要求重新审批。

令牌应短期有效、默认一次使用，并由服务端保存消费记录，防止并发重复执行。取消、超时和拒绝都是明确终态，Agent 不应通过换工具名绕过同一风险边界。

审计日志关联计划、审批与实际结果，但隐藏密钥和不必要正文。测试覆盖参数被修改、令牌过期、重复消费和执行前资源状态已变化等情况。
