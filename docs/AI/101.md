# Agent 外部状态快照：重放时区分事实与旧结果

长任务恢复时，工具上次返回的库存、权限或工单状态可能已经过期。把历史结果原样喂回 Agent 会让它基于旧世界继续行动。

为工具结果记录获取时间、资源版本、有效期和是否可重放。纯计算结果可以缓存；外部可变状态在恢复前必须重新读取。写操作则先用幂等键查询最终状态，不能因没有看到响应就直接再执行一次。

检查点分开保存“已确认事实”“待验证假设”和“已经产生的副作用”。恢复流程先验证关键前置条件，再从最近安全边界继续；若目标资源或权限变化，停止并重新规划。

用模拟时钟和可控假服务测试：在检查点后修改订单状态、撤销权限或让令牌过期，确认 Agent 不会沿用陈旧结果。可恢复性来自状态语义，不是把对话全文序列化。
