# Agent 完成条件：用可验证证据结束任务

Agent 说“已完成”只是一段文本，不代表目标状态真的存在。每类任务都应定义可机器检查的完成条件，并明确哪些证据必须来自外部系统。

文件任务可校验路径、摘要和语法；发布任务校验目标版本、健康探针与监控窗口；消息任务校验服务端返回的唯一标识。多个条件组成清单，全部通过才进入 completed，部分成功则保留具体未完成项。

验证器与执行器尽量分离，避免同一个错误假设同时生成结果和证明结果。验证失败时回到有限修复流程，并保存最新证据；达到重试上限后向人工交接，而不是修改完成标准。

完成记录包含目标、验证时间、资源版本和证据引用。对最终一致系统，在截止时间内按退避轮询；超过期限报告“状态未确认”，不要把“请求已接受”写成“业务已完成”。
