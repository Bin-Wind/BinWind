# 模型输入质量监控：从契约违规到分布偏移

线上模型可能仍返回 200，但输入已经悄悄改变。有效监控要分三层：结构契约检查字段、类型与单位；质量规则检查缺失率、取值范围和类别集合；分布监控比较近期窗口与训练基线。

先为每项指标写清窗口、分群和告警条件。例如按客户端版本统计 `age` 缺失率，比全局平均更容易定位灰度发布造成的问题。连续值可监控分位数和分桶占比，类别值监控新增类别及占比；不要只看均值，它会掩盖双峰和长尾变化。

告警必须连到动作：契约违规可拒绝请求或使用明确默认值；轻微分布变化先记录样本并观察；明显偏移则切换保守模型、暂停自动决策或回滚数据管线。所有降级都应计数，避免默认值长期吞掉故障。

监控数据本身也要脱敏并保留版本信息。一次排查至少能回答：哪个字段、从何时开始、影响哪些来源、使用了哪个模型版本，以及是否改变了业务结果。
