# 训练产物清单：用哈希锁定可部署模型

一个可部署模型不只有权重。分词器、配置、标签映射、预处理代码和依赖版本少一项，都可能让同一权重产生不同结果。训练完成时应生成机器可读的 manifest，并与产物一起保存。

~~~json
{
  "model_id": "intent-2026-09-16.1",
  "training_run": "run-1842",
  "files": {
    "model.safetensors": "sha256:...",
    "tokenizer.json": "sha256:...",
    "config.json": "sha256:..."
  },
  "dataset_snapshot": "tickets@8f31c2",
  "evaluation_report": "eval-9021",
  "runtime": "python3.12-cu124"
}
~~~

哈希应在不可变存储中的最终文件上计算；部署前重新校验，任何缺失或不匹配都直接失败。manifest 还应记录代码提交、数据快照、随机种子、模型格式和最低运行时要求，但不要把密钥或原始敏感样本写进去。

发布审批引用 manifest 的唯一标识，而不是“最新模型”这类可移动名称。回滚时按同一清单恢复整套文件，并用固定冒烟样本核对输出。这样才能证明线上运行的确实是评测过的那组产物。
