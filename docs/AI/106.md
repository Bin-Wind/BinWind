# 微调标签掩码审计：确认损失只落在目标答案

指令微调通常只希望助手答案参与损失计算，系统提示、用户问题和填充位应设为忽略标签。模板边界写错时，训练仍会正常下降，却可能是在学习复述输入或预测 padding。

在训练前随机抽样，将 token、token id、attention mask 和 label 并排解码。对每个样本验证：被忽略位置使用框架约定的值（常见为 `-100`）；有效标签从助手答案的第一个目标 token 开始；结束符是否纳入目标保持一致；截断后至少还剩一个有效标签。

再统计每条样本的有效标签数和占比。零标签样本应拒绝，极低或异常高的占比要回看模板。多轮对话要明确是只训练最后一轮，还是所有助手轮次；两种都可以，但不能由数据拼接偶然决定。

把几条固定样本做成回归测试，在模板、分词器或最大长度变化时比较掩码位置。损失曲线无法替代这项检查，因为它只说明某些标签变得可预测，不说明标签选对了。
