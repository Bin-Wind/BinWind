# 检查点保留策略：在可恢复与存储预算间取舍

检查点至少服务两个目标：训练中断后继续，以及从候选版本中选择模型。若只按固定步数无限保存，优化器状态很快占满磁盘；若只留最后一步，又可能丢掉验证集最优点和最近可恢复状态。

可把保留规则拆成三层：始终保留最近的两个完整恢复点；按主要验证指标保留若干最佳权重点；在长任务中按更稀疏的时间间隔保留里程碑。完整恢复点包含模型、优化器、调度器、随机数状态、数据采样进度和训练配置，不能只复制权重文件。

保存采用临时目录，全部文件写完并校验后再原子标记为完成。启动恢复时只读取有完成标记且清单哈希匹配的目录。删除旧检查点前，先确认新检查点能在另一进程中加载并完成一个小批次。

监控磁盘余量和单次检查点耗时，预留至少一次新写入和回滚的空间。策略应写进训练配置并进入运行记录，使“为什么留下这个版本”可以被解释，而不是靠人工临时清理。
