# 微调样本混合：让不同任务按计划进入批次

把多个数据集简单拼接后打乱，样本数量最大的任务会主导训练。先为每个任务定义目标采样权重，再根据训练步数计算期望样本量。权重表达产品优先级和数据质量，不应直接等同于原始规模。

采样器要使用显式随机种子，并记录每个 epoch 实际抽到的任务、语言和长度分布。小数据集被重复采样时尤其要监控重复次数，避免少量模板被模型记住。可以为单个来源设置上限，或在后期逐步降低过采样比例。

批次内按长度分桶能减少 padding，但分桶不能破坏任务混合目标。分布式训练还要保证各进程看到不重叠且可复现的样本序列；从检查点恢复后，采样位置必须接续而不是重新开局。

评测报告按任务分别给出指标，再提供按业务权重汇总的结果。只看一个总分会让高频任务的微小提升掩盖低频关键任务的退化。更改混合比例时保持其他配置不变，才能判断收益来自数据配方而非训练噪声。
