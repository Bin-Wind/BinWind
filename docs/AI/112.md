# Agent 副作用分级：只读、可逆与不可逆动作

工具是否“能调用”不等于 Agent 应在任何时刻调用。注册工具时给动作标注副作用等级：只读查询、可逆写入、外部通知、资金或权限变更，以及不可逆删除。等级决定审批、预览、幂等和审计要求。

只读工具也要限制数据范围；可逆写入应返回变更标识和撤销入口；发送消息、发布内容等对外动作需要展示收件人和最终正文；高风险操作使用短期审批令牌，且令牌绑定具体参数摘要，不能批准一次后任意改参。

规划阶段先生成动作清单，执行器根据等级逐项校验。支持 dry-run 的工具返回预计影响，不伪造“执行成功”。同一工具若参数不同会改变风险，例如读取公共文件与导出整库数据不能共享一个笼统等级。

审计日志记录请求者、计划、批准内容、实际参数、工具结果和补偿动作。定期从真实调用反查分类是否准确；出现未分类的新工具时默认禁止写入，而不是按最低风险放行。
