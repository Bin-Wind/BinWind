# Agent 上下文压缩验收：摘要之后仍保留关键约束

长任务会把早期对话压缩成摘要。摘要若遗漏文件范围、禁止动作、已批准参数或未决风险，Agent 可能在后续步骤偏离原意。压缩应产出结构化交接包，而不只是自然语言概述。

交接包至少保留：目标与完成条件、不可违反的约束、已经完成及其证据、当前外部状态、待办步骤、失败记录、资源标识和仍需确认的问题。事实要附来源或时间戳，推断则明确标记，避免旧查询结果被当作当前事实。

压缩前后运行一组问题：目标文件有哪些、哪些动作必须审批、最近一次工具结果是什么、下一步为何安全。答案缺失或相互矛盾时，不应继续自动执行，而要回读原始记录或请求人工确认。

每次再压缩都以最新交接包和新增事件为输入，并保留关键标识原文。任务完成后对照初始请求逐项验收，不能把“摘要中没有提到”误判为“用户没有要求”。
