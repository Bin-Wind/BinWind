# RAG 中文词法检索：分词词典与字符召回如何配合

中文没有天然空格边界，直接按空白切词会让 BM25 等词法检索几乎失效；完全依赖固定词典，又可能漏掉新品名、缩写和编号。实用方案通常把语言分词与字符级召回结合，再交给重排器判断相关性。

## 建立可解释的分析链

索引时保留原文，同时生成两路字段：一路用适合中文的分词器，加入经过审核的领域词典；另一路生成字符二元组或三元组，兜底未登录词。型号、版本号、错误码和英文缩写应尽量保留整体形式。

例如“星河数据库 X2 超时”可以同时产生领域词 `星河数据库`、`X2`、`超时`，以及有限的字符 n-gram。不要对所有字段无限制地产生 n-gram，否则索引体积和噪声都会上升。

## 查询侧保持一致

查询必须使用与索引兼容的分析器。词典升级后建立新索引并双读评测，不能只改查询分词。对自然语言问题可提取错误码、型号等高精度词并提高权重，但仍保留原查询用于向量检索。

## 用标注问题调权重

准备包含同义词、错别字、长产品名和中英混写的真实问题集，分别记录词法、字符和向量通道的召回。融合分数前先归一化，避免不同检索器的原始分值不可比。

重点观察误召回：字符通道可能因共享几个字而命中无关文档。最终报告 Recall@K、首个相关结果排名与索引大小。分词方案不是一次性配置，新增领域词时要用回归集证明收益没有换来更大的噪声。
