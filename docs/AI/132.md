# 微调权重衰减：只对该衰减的参数生效

权重衰减用于限制参数无限增大，但通常不应同样作用于偏置和归一化参数。把所有可训练参数放进一个优化器组，可能让小规模微调更不稳定。

## 按名称与形状审计分组

在创建优化器前列出实际可训练参数。常见做法是对矩阵权重使用衰减，对 bias 与 LayerNorm 等一维参数禁用衰减；具体规则仍要依据模型实现确认，不能只凭字符串猜测。

```python
decay, no_decay = [], []
for name, parameter in model.named_parameters():
    if not parameter.requires_grad:
        continue
    target = no_decay if parameter.ndim == 1 or name.endswith(".bias") else decay
    target.append(parameter)

optimizer = AdamW([
    {"params": decay, "weight_decay": 0.01},
    {"params": no_decay, "weight_decay": 0.0},
], lr=2e-4)
```

对 LoRA 微调，还应确认分组中只有适配器参数；若基础权重意外解冻，资源占用和训练目标都会改变。统计每组参数数量与元素总数，并断言两组无交集、合计等于全部可训练参数。

## 用对照实验决定数值

权重衰减不是越大越能防过拟合。保持数据顺序、学习率计划和随机种子一致，对比零衰减与少量候选值，同时观察训练损失、分层验证指标和参数范数。将分组规则写入训练配置和产物清单，恢复训练时也要恢复优化器状态。
