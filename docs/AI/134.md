# RAG 多查询融合：用 RRF 合并不同检索结果

同一问题可改写成关键词查询、完整问句和实体限定查询。它们返回的分数尺度不同，直接相加会让某个检索器因分数范围更大而长期占优。倒数排名融合（RRF）只使用名次，更适合合并异构结果。

对文档 `d`，每个结果列表贡献 `1 / (k + rank)`；`k` 用于降低头部名次差异的敏感度。文档在多个列表中出现会自然累积分数。

```python
from collections import defaultdict

def rrf(result_lists, k=60):
    scores = defaultdict(float)
    for results in result_lists:
        for rank, doc_id in enumerate(results, start=1):
            scores[doc_id] += 1 / (k + rank)
    return sorted(scores, key=scores.get, reverse=True)
```

## 去重与权限先行

融合键应使用稳定文档或切片 ID；同一内容的多个版本先按版本规则去重。每一路检索都必须执行同样的权限过滤，不能在融合后才删除越权结果，否则会浪费候选位并泄露存在性信号。

## 评测增益而非查询数量

查询改写越多，延迟和费用越高，也可能引入偏题候选。用已标注问题比较单查询与融合后的召回率、首个相关结果排名、多样性和尾延迟。保留原始查询、各列表名次与最终贡献，出现错误答案时才能追溯是哪次改写带偏了结果。
