# RAG 数字与实体核验：生成后回查证据

即使检索片段正确，模型仍可能抄错金额、日期、版本号或主体名称。数字与实体核验是在答案交付前，把高风险声明重新绑定到证据，而不是再让模型凭记忆评价自己。

## 提取可核验声明

从候选答案中识别数字、单位、日期、专有名词和“甲高于乙”等关系，并保留所在句子。对每条声明找到引用片段中的精确支持位置；规范化全角符号、千分位和日期格式，但不能把不同币种或百分比与百分点视为相同。

```python
import re

def numbers(text: str) -> list[str]:
    return re.findall(r"(?<!\w)[+-]?\d+(?:\.\d+)?%?", text)
```

正则只能发现候选，最终还需结合单位和语义判断。表格中的行列标题必须与单元格一起引用，否则数值脱离主体。

## 失败时缩小承诺

若数字在证据中找不到、同一实体存在冲突值或来源已过期，应删除该断言、改写为不确定表述，或请求用户选择时间范围；不能自动挑一个“看起来合理”的值。金融、医疗和法律等高风险回答还需要领域规则或人工审核。

记录核验通过率、失败类型和被修改句子，并把常见错误回灌到评测集。核验层只能证明引用与输出一致，不能证明源文档本身真实，因此仍需来源质量与新鲜度控制。
