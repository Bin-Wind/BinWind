# Agent 长任务心跳：区分仍在运行与已经失联

导出、训练和渲染可能长时间没有最终结果。仅看“尚未完成”无法区分正常运行、工作进程崩溃和回调丢失。心跳提供活性证据，但不能替代任务进度或完成校验。

## 心跳记录什么

持久化 `job_id`、工作进程身份、租约到期时间、最近心跳和可选进度摘要。续租使用条件更新，只有当前租约持有者可以延长；接管者获得新的 fencing token，旧进程即使恢复也不能再提交结果。

```sql
UPDATE jobs
SET heartbeat_at = CURRENT_TIMESTAMP,
    lease_until = CURRENT_TIMESTAMP + INTERVAL '30 seconds'
WHERE job_id = :job_id
  AND worker_id = :worker_id
  AND fencing_token = :token;
```

## 合理判断失联

超时阈值至少覆盖正常调度抖动、网络延迟和最长不可中断步骤。一次心跳延迟先标记可疑，连续超过租约才允许接管。进度百分比必须来自可计算工作量；无法估算时报告当前阶段和最近完成的检查点，不伪造线性进度。

## 接管与完成

接管前检查外部任务是否仍在运行，避免重复提交收费或有副作用的工作。每个阶段使用幂等键，结果写入时校验 fencing token。心跳停止不等于失败，最终完成仍需产物摘要、大小和业务验收；监控分别统计失联、超时、取消和任务自身失败。
