# 训练数据回填验收：用不变量发现静默错误

历史特征回填即使任务显示“成功”，也可能因时区、去重键或关联条件写错而产生可用格式下的错误数据。验收不能只看行数，应在计算前写清不会随批次改变的不变量。

## 建立三层检查

先检查结构：主键非空、时间范围正确、枚举值受控。再检查关系：同一实体与时间窗口只能有一条记录，累计量不能小于对应明细。最后比较分布：按日期和来源对比旧版本的缺失率、分位数与实体覆盖率。

```python
def validate(rows):
    keys = {(r["user_id"], r["day"]) for r in rows}
    assert len(keys) == len(rows), "存在重复实体日"
    assert all(r["orders_30d"] >= 0 for r in rows)
    assert all(r["paid_30d"] <= r["orders_30d"] for r in rows)
```

抽样要覆盖边界日期、零活动实体、迟到数据与高值用户，不能只随机抽取“普通行”。为每次回填保存代码版本、输入快照、参数、检查结果和输出哈希。

## 先影子写入再切换

新结果写到独立分区，完成检查后再原子切换读取指针。若分布变化有合理业务原因，把原因与批准者记录下来；不能为了让流水线变绿而临时放宽阈值。上线后继续比较线上查询与回填值，确认离线正确性确实延伸到了服务路径。
