# 推理结果复现：锁定模型、运行时与采样配置

同一个提示词再次执行得到不同答案，不一定是模型“随机”。权重、分词器、聊天模板、运行时版本和采样参数中任一项改变，都可能影响输出。

## 记录最小复现包

每次关键评测至少保存模型产物哈希、分词器版本、模板、完整输入消息、随机种子、温度、top-p、最大长度、停止词和推理镜像摘要。仅记录模型名称不够，因为浮动标签可能指向新文件。

```json
{
  "model_sha256": "…",
  "runtime_image": "registry/app@sha256:…",
  "seed": 20260919,
  "temperature": 0,
  "top_p": 1,
  "max_new_tokens": 256
}
```

即使温度为零，不同硬件内核、并行策略或数值精度也可能造成边界差异。因此验收优先比较结构化字段、关键事实和允许误差，而不是要求所有自由文本逐字相同。

## 做一次真正的回放

在隔离环境中仅使用复现包重新运行，先核对输入 token ID，再比较生成结果。若 token 已不同，问题在分词或模板；token 相同而输出偏离，再检查运行时和计算配置。定期回放一组金样本，能在升级前发现“记录齐全但已无法复现”的假安全感。
