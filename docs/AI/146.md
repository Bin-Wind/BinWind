# RAG 过滤后空结果：区分无权限、无内容与索引延迟

检索返回空列表可能表示知识库没有答案，也可能是权限过滤全部拦截、文档尚未入索引或查询路由走错。把它们都回答成“没有相关内容”，既误导用户，也隐藏系统故障。

## 保留阶段性计数

为查询记录候选召回数、权限过滤后数量、时间与类型过滤后数量，以及索引水位。日志只保存必要元数据，不泄露被拒绝文档的标题或内容。

```text
召回 18 → 权限过滤 0：返回通用无权限提示，不暴露文档存在
召回 0，索引已追平：允许进入无答案流程
召回 0，索引落后：提示稍后重试并告警
```

外部响应应避免用差异过大的文案形成资源枚举侧信道；内部指标则要精确区分原因。管理员诊断视图也必须经过授权。

## 为每种空结果设动作

无内容可建议改写问题，权限为空应引导申请正确访问，索引延迟应等待或查询稳定副本，服务异常则快速失败。为四类场景建立测试夹具，并验证缓存键包含权限与索引版本，避免某个用户的空结果污染其他用户。
