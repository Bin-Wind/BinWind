# 训练作业抢占恢复：用检查点间隔控制返工成本

可抢占算力价格低，但实例可能随时被回收。真正可恢复的训练不能只保存模型权重，还要保存优化器、学习率调度器、随机数状态、数据游标和全局步数。

## 估算检查点间隔

间隔太长会在抢占后重算，太短又让存储与同步占满训练时间。先测量一次保存耗时和历史抢占频率，再用几档间隔做成本对比。

```python
def expected_overhead(interval_min: float, save_min: float,
                      interruptions_per_hour: float) -> float:
    save_cost = save_min / interval_min
    expected_rework = interruptions_per_hour * (interval_min / 2) / 60
    return save_cost + expected_rework

for minutes in (5, 10, 20, 40):
    print(minutes, round(expected_overhead(minutes, 0.4, 0.15), 4))
```

这个简化模型假设抢占在间隔内均匀发生，只适合筛选候选值；最终仍要用真实作业统计校准。

## 做一次故障演练

在非生产训练中主动终止进程，从远端检查点恢复，确认下一批样本、学习率和损失曲线连续。检查点先写临时路径，完成校验后再原子发布清单；清单引用的分片未全部上传时，不得标记为可恢复。
