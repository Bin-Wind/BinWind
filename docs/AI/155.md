# 微调梯度范数基线：用异常尖峰定位坏批次

损失上升可能来自困难样本，也可能来自标签错位、异常长序列或数值溢出。记录裁剪前的梯度范数，可以帮助区分“模型正在学习难例”和“更新已经失控”。

## 先建立正常区间

不要套用固定阈值。用同一模型、精度、批大小与累积步数跑一段稳定训练，记录每次参数更新前的总范数，再按训练阶段比较分位数。

```python
from statistics import median

baseline = [0.82, 0.91, 0.88, 0.95, 0.86, 0.90]
current = [0.87, 0.92, 7.40]
limit = median(baseline) * 5
for step, value in enumerate(current, 1):
    if value > limit:
        print(f"step={step} suspicious_norm={value:.2f}")
```

真实训练中应在 `clip_grad_norm_` 之前记录返回值，并同时保存批次 ID、最大序列长度、有效标签数和损失缩放状态。

## 尖峰后的处理

先暂停晋级并复现该批次，再检查是否存在空标签、极端长度和非有限值。梯度裁剪能限制一次更新，却不会修复脏数据；若尖峰周期性出现，还要检查学习率调度、梯度累积边界和混合精度溢出。
