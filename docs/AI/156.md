# 微调批次长度分桶：减少 Padding 又不打乱样本分布

随机批次中一条超长样本会迫使其他样本补齐大量 Padding。按长度接近的样本分桶能提升吞吐，但若全局严格排序，也可能让训练前后看到完全不同的任务分布。

## 局部排序再随机批次

做法是先全局打乱，再按较大的窗口局部排序，最后切成批次并再次打乱批次顺序。

```python
import random

def bucket_batches(lengths, batch_size=3, window=9, seed=7):
    rng = random.Random(seed)
    ids = list(range(len(lengths)))
    rng.shuffle(ids)
    batches = []
    for start in range(0, len(ids), window):
        block = sorted(ids[start:start + window], key=lengths.__getitem__)
        batches.extend(block[i:i + batch_size]
                       for i in range(0, len(block), batch_size))
    rng.shuffle(batches)
    return batches

print(bucket_batches([9, 80, 12, 45, 44, 10, 70, 15, 39, 41]))
```

## 验收不只看速度

比较每批有效 Token 比例、每秒 Token 数和峰值显存，同时确认不同来源、语言和任务在训练步中的分布没有被长度代理。分布式训练还需保证各 rank 批次数一致，尾批次策略也要写入可复现实验配置。
