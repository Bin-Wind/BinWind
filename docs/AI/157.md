# RAG 同义词扩展：离线验证后再扩大召回

用户说“退款”，文档可能只写“退货款项”；同义词扩展能补足词法检索，但无边界扩展也会把“注销账户”和“退出登录”混在一起。

## 规则必须带作用域

同义词表应记录业务域、方向、版本和维护人。品牌名、缩写可双向扩展；上下位词和有歧义的业务动作更适合单向扩展。

```python
RULES = {
    "支付": {"退款": ["退货款项", "原路退回"]},
    "账号": {"双重验证": ["两步验证", "2FA"]},
}

def expand(domain: str, query: str) -> list[str]:
    variants = [query]
    for term, synonyms in RULES.get(domain, {}).items():
        if term in query:
            variants += [query.replace(term, value) for value in synonyms]
    return list(dict.fromkeys(variants))

print(expand("账号", "如何开启双重验证"))
```

## 用标注集决定是否上线

对每个查询比较扩展前后的 Recall@K、无关结果比例和最终答案正确率，并单独查看零结果查询。线上先影子运行，记录新增命中来自哪条规则；规则误召回时可按版本快速撤回，而不是重新构建所有逻辑。
