# RAG 时间过滤：正确处理截止日期与历史快照

“当前政策”和“去年年底的政策”需要不同证据。仅按文档更新时间排序，会让后来修订的页面覆盖历史事实，也可能把未来才生效的规则提前用于答案。

## 建模有效时间

至少区分内容有效区间与系统收录时间。查询时使用半开区间：`valid_from <= at < valid_to`，没有结束时间的记录可视为持续有效。

```python
from datetime import date

def active(document: dict, at: date) -> bool:
    start = date.fromisoformat(document["valid_from"])
    end = document.get("valid_to")
    return start <= at and (end is None or at < date.fromisoformat(end))

docs = [
    {"id": "v1", "valid_from": "2025-01-01", "valid_to": "2026-01-01"},
    {"id": "v2", "valid_from": "2026-01-01"},
]
print([d["id"] for d in docs if active(d, date(2025, 12, 31))])
```

## 防止时间语义丢失

解析问题中的日期时保留原表达、解析结果与时区；没有日期时再使用明确的“当前时间”。评测集应包含边界日前后、延迟发布、追溯生效和多版本并存案例。答案引用中显示版本与有效期，让读者能核对证据为何适用。
