# RAG 索引写入幂等：重试时不产生重复切片

索引任务在超时后可能已经写入成功。如果重试为同一段文本生成新的随机 ID，检索结果会被重复内容占满，删除文档时也难以清干净。

## 由内容身份生成稳定键

稳定键应包含租户、源文档身份、解析版本和切片边界，而不是数据库自增 ID。内容改变时产生新版本，未改变的切片则复用原键。

```python
import hashlib

def chunk_id(tenant: str, source: str, parser: str,
             start: int, end: int) -> str:
    raw = f"{tenant}\0{source}\0{parser}\0{start}:{end}"
    return hashlib.sha256(raw.encode()).hexdigest()[:24]

print(chunk_id("acme", "handbook.md", "v3", 0, 800))
print(chunk_id("acme", "handbook.md", "v3", 0, 800))
```

## 采用“对账后发布”

每次构建先写带运行 ID 的暂存集合，校验期望数量、唯一键和向量维度，再切换文档版本指针。发布成功后清理旧版本；任务重试时对同一键执行 upsert。故障演练要覆盖“写完但未确认”和“只写了一半”两种状态。
