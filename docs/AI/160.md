# Agent 工具分页：不漏项，也不无限抓取

列表工具常只返回第一页。Agent 若忽略游标会漏数据，若服务端反复返回同一游标又可能陷入循环。分页逻辑需要明确页数、条目数和时间预算。

## 对游标做进度检查

```python
def collect(fetch_page, max_pages=20, max_items=1000):
    cursor = None
    seen = set()
    result = []
    for _ in range(max_pages):
        page = fetch_page(cursor)
        result.extend(page["items"])
        if len(result) >= max_items or not page.get("next_cursor"):
            return result[:max_items]
        cursor = page["next_cursor"]
        if cursor in seen:
            raise RuntimeError("pagination cursor did not advance")
        seen.add(cursor)
    raise RuntimeError("page budget exhausted")
```

工具返回还应说明排序规则和快照语义。若翻页期间数据会变化，优先使用服务端快照令牌或稳定的“时间 + ID”排序，避免插入导致重复或跳项。

## 把截断写进结果

达到预算时不要把部分结果冒充完整结果。Agent 应返回已读取数量、停止原因和继续所需的游标；高风险决策如果依赖全集，则升级给用户或改用批量导出接口。
