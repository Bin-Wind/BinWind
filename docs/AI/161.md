# Agent 任务租约：阻止失联 Worker 继续产生副作用

长任务被重新派发后，旧 Worker 可能只是网络隔离而非真正停止。若新旧实例同时写外部系统，就会发生重复扣款、重复发布或互相覆盖。租约让执行权带有期限和代次。

## 写入前验证栅栏令牌

每次取得租约都递增 `generation`。Worker 的心跳只能延长自己持有的代次，所有副作用请求也必须携带该代次；存储端拒绝旧代次。

```python
class Lease:
    def __init__(self):
        self.generation = 0
        self.owner = None

    def acquire(self, owner: str) -> int:
        self.generation += 1
        self.owner = owner
        return self.generation

    def may_write(self, owner: str, generation: int) -> bool:
        return self.owner == owner and self.generation == generation

lease = Lease()
old = lease.acquire("worker-a")
new = lease.acquire("worker-b")
print(lease.may_write("worker-a", old), lease.may_write("worker-b", new))
```

## 到期不是唯一防线

时钟偏差和暂停进程会让客户端判断不可靠，因此有效性应由协调存储判定。外部系统无法识别栅栏令牌时，还需使用幂等键和业务唯一约束。演练旧 Worker 恢复网络的场景，确认它只能停止并交接。
