# 训练数据快照验收：用行数、哈希与抽样锁定输入

训练参数完全相同，输入数据悄悄变化仍会得到不同模型。把一个目录名写进实验记录不够：上游可能覆盖文件、改变分区，或在重跑时补入迟到数据。训练开始前应生成不可变快照清单，并让作业只读取清单中的对象。

## 清单应记录什么

对每个分片记录稳定 URI、字节数、内容摘要、记录数和 Schema 版本；快照级别再记录生成时间、上游截止时间、过滤规则版本与总行数。对象存储的 ETag 不一定等同于内容哈希，尤其是分段上传文件，因此应明确摘要算法。

```python
import hashlib
from pathlib import Path

def sha256(path: Path) -> str:
    digest = hashlib.sha256()
    with path.open("rb") as stream:
        for chunk in iter(lambda: stream.read(1024 * 1024), b""):
            digest.update(chunk)
    return digest.hexdigest()

for path in sorted(Path("data").glob("*.jsonl")):
    rows = sum(1 for _ in path.open(encoding="utf-8"))
    print(path.name, path.stat().st_size, rows, sha256(path))
```

## 三层验收

首先做结构检查：必需列、类型、枚举和空值比例不能越界。其次做统计检查：分区总数、行数、去重后实体数与关键标签分布要和上一可用快照比较。最后做分层抽样，按来源、语言、时间段和标签抽取可读样本，人工确认过滤与脱敏规则没有反向。

快照验收失败应阻止训练，而不是仅写一条警告。若确需接受异常，保留审批人、理由和新阈值，不能直接改掉历史规则。训练产物的元数据必须引用快照 ID；这样线上模型出现问题时，团队才能重新取回完全相同的输入，而不是依赖“那天大概是这批数据”。
