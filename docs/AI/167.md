# 微调数据权重采样：按目标比例而不是文件大小混合

把多个 JSONL 文件拼接后随机打乱，得到的是按文件行数决定的比例。一个数量巨大的通用数据集可能淹没少量高价值任务数据；重复复制小文件又会增加存储，并让重复程度难以说明。

## 把目标写成概率

先按任务、语言或来源定义数据源，再给出每个源的目标采样权重。例如代码 40%、问答 35%、安全拒答 25%。权重描述的是抽取概率，不必等于原始样本占比。采样器每一步先选择数据源，再从该源读取下一个样本；某源耗尽时应明确是循环、停止还是重新归一化。

```python
import random

sources = ["code", "qa", "safety"]
weights = [0.40, 0.35, 0.25]
rng = random.Random(20260922)

counts = {name: 0 for name in sources}
for _ in range(10_000):
    name = rng.choices(sources, weights=weights, k=1)[0]
    counts[name] += 1

print(counts)
```

## 验收实际进入批次的分布

配置比例不等于训练实际比例。序列打包、长度过滤与分布式分片都可能改变最终 Token 占比，因此同时统计样本数和有效训练 Token 数。对循环使用的小数据源记录每个样本平均出现次数，避免少量数据被过度记忆。

比较实验时锁定随机种子、每源快照和总训练 Token；只改变一组权重，并按各子任务分别评测。若动态调整权重，要记录每个训练区间的配置，而不是只保存最终值。权重采样的价值在于让训练目标显式可审计，而非承诺某个比例天然最优。
