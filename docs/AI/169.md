# RAG OCR 质量门禁：低质量文本不要直接进入索引

扫描 PDF 经过 OCR 后可能出现乱码、断行、页眉重复和表格错位。若这些文本直接切片并向量化，检索仍可能返回“相似”片段，但答案引用的数字和句子已经错误。OCR 质量必须在入库前验收。

## 自动检查可疑页面

按页计算可打印字符比例、字母数字比例、平均词长、重复行比例和异常替换字符数量；同时检查页面是否只有图片却没有文本、文本框是否大面积重叠。不同语言需要不同阈值，中文不能用英文空格词数直接判断。

```python
def page_signals(text: str) -> dict[str, float]:
    total = max(len(text), 1)
    lines = [line.strip() for line in text.splitlines() if line.strip()]
    unique = len(set(lines))
    return {
        "printable_ratio": sum(ch.isprintable() for ch in text) / total,
        "replacement_ratio": text.count("�") / total,
        "duplicate_line_ratio": 0 if not lines else 1 - unique / len(lines),
    }
```

自动信号只能筛选，不能证明文字正确。对低分页面、表格页和包含关键数字的页面做分层抽样，人工对照原图。保留 OCR 引擎、语言包、参数、源文件哈希和页码坐标，使引用能回到原始页面。

## 失败时不要静默降级

低质量页面可以进入隔离队列重跑 OCR 或人工修复，但不能混入正式索引。若只有部分页面合格，索引元数据应明确缺页范围，回答端遇到相关问题时提示证据不完整。修复后使用稳定的文档与页面 ID 替换旧切片并清理缓存，避免新旧文本同时被召回。
