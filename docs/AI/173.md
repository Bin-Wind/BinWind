# Agent 工具默认值：在 Schema 中消除隐含假设

工具参数省略时，如果执行端、模型提示词和文档各自猜一个默认值，同一次调用可能在升级后改变含义。尤其是 `dry_run`、覆盖范围、时区和分页大小，隐含默认值很容易造成意外副作用。

## 默认值必须属于契约

为每个可选字段明确：省略是否合法、默认值是什么、由调用端还是服务端填充。高风险布尔项不要使用容易混淆的双重否定；例如用 `mode: "preview" | "apply"` 比 `skip_dry_run: false` 更清楚。涉及删除、覆盖和通知的模式应默认预览或拒绝，而不是默认执行。

```json
{
  "type": "object",
  "properties": {
    "mode": { "enum": ["preview", "apply"], "default": "preview" },
    "timezone": { "type": "string", "description": "IANA 时区，如 Asia/Shanghai" },
    "limit": { "type": "integer", "minimum": 1, "maximum": 100, "default": 20 }
  },
  "required": ["timezone"],
  "additionalProperties": false
}
```

执行端应把规范化后的完整参数写入审计日志，使复盘者看到实际生效值，而不是只有模型原始输入。服务端升级默认值属于契约变更；若旧调用需要保持行为，就增加版本，不要原地修改。

## 验收省略路径

为每个可选参数测试省略、显式默认、边界值和非法值，并断言省略与显式默认得到相同结果。提示词示例也要覆盖默认行为，但不能把提示词当唯一保护。清晰的默认值让 Agent 少猜一步，也让安全审查可以针对确定行为进行。
