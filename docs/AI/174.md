# Agent 并行汇合超时：保留已完成结果并处理缺席分支

Agent 同时查询库存、价格和物流可以降低总延迟，但若汇合点必须等待所有分支，一个失联服务会拖垮整个任务。相反，超时后丢弃全部结果又浪费已经完成的工作。

## 为分支定义必要性

启动前把分支标成“必须”“可降级”或“仅增强”，并为每个分支设置独立截止时间，再设置小于用户总截止时间的汇合截止时间。必须分支缺席时停止高风险决策；可降级分支缺席时返回带限制的结果；增强分支则可静默省略，但应留下状态。

```python
from dataclasses import dataclass

@dataclass
class BranchResult:
    name: str
    status: str       # succeeded / timed_out / failed
    value: object | None
    required: bool

def can_commit(results: list[BranchResult]) -> bool:
    return all(r.status == "succeeded" for r in results if r.required)
```

汇合结果应保留每个分支的状态、耗时、数据时间戳和错误类别。对仍在运行的分支发送取消信号；若外部调用无法取消，给它幂等键并忽略过期回调，避免迟到结果在决策完成后继续产生副作用。

## 防止不完整结果伪装成完整答案

最终输出明确写出缺失信息和影响，例如“库存已确认，运费服务超时，因此未创建订单”。不要让模型用推测补齐缺席分支。测试时注入慢响应、错误响应和部分成功，验证必须分支阻断提交、可降级分支保留已完成证据。并行的价值来自更快获得独立结果，而可靠性来自汇合点知道何时可以继续、何时必须停下。
