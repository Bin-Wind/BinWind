# RAG 混合检索：关键词、向量与重排

向量检索擅长语义近似，却可能漏掉产品编号、错误码和专有名词；关键词检索精确，但不理解同义表达。混合检索先召回两路候选，再融合并重排，通常比单一路径更稳健。

## 用 RRF 融合排名

倒数排名融合不要求两路分数处于同一尺度：

```python
from collections import defaultdict

def rrf(rankings: list[list[str]], k: int = 60) -> list[str]:
    scores = defaultdict(float)
    for ranking in rankings:
        for rank, doc_id in enumerate(ranking, start=1):
            scores[doc_id] += 1 / (k + rank)
    return sorted(scores, key=scores.get, reverse=True)

keyword = ["doc-3", "doc-1", "doc-8"]
vector = ["doc-1", "doc-5", "doc-3"]
print(rrf([keyword, vector]))
```

`k` 越大，排名靠前的优势越平缓。应在真实查询集上选择参数，而不是沿用默认值。

## 三阶段流程

1. 关键词与向量各召回 20～100 条候选。
2. 合并去重，并应用权限、语言、时间等硬过滤。
3. 用交叉编码器或轻量模型对“查询—段落”对重排，只保留少量上下文。

权限过滤必须发生在内容交给模型之前。过滤后候选不足时，应扩大合规范围重新召回，而不是放宽权限。

## 如何评估

先评召回：答案所在文档是否进入 Top-K；再评排序：相关文档是否足够靠前；最后评生成：回答是否忠于证据。记录每一路贡献与失败查询，才能判断问题发生在召回、融合、重排还是生成阶段。

对精确编号类查询，可提高关键词路径权重；对自然语言描述，则让向量路径提供更多候选。路由规则应由评测数据驱动，并保留一个简单基线用于对照。
