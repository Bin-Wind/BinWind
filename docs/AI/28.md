# AI Agent 记忆设计：短期上下文与长期知识

Agent 的“记忆”不是把所有历史对话无限塞进提示词。可靠设计会区分工作上下文、事件记录和可检索知识，并明确写入与遗忘规则。

## 三层记忆

- **工作记忆**：当前任务、计划、最近观察，随任务结束清理。
- **情节记忆**：发生过什么，按时间保存可审计事件。
- **语义记忆**：从事件提炼出的稳定事实，例如用户明确选择的偏好。

敏感信息默认不进入长期记忆；推断出的偏好应标注置信度和来源，不能伪装成用户陈述。

## 一个可测试的存储接口

```python
from dataclasses import dataclass, field
from datetime import datetime, timezone

@dataclass
class Memory:
    text: str
    source: str
    created_at: str = field(
        default_factory=lambda: datetime.now(timezone.utc).isoformat()
    )

class MemoryStore:
    def __init__(self):
        self.items: list[Memory] = []

    def add(self, text: str, source: str) -> None:
        if text.strip() and not any(x.text == text for x in self.items):
            self.items.append(Memory(text.strip(), source))

    def search(self, query: str) -> list[Memory]:
        terms = set(query.lower().split())
        return [m for m in self.items if terms & set(m.text.lower().split())]
```

生产系统可替换为数据库或向量索引，但接口要支持来源、时间、删除和租户隔离。

## 写入与召回策略

只写入未来确实有复用价值的信息；短期状态、未经确认的推断和一次性秘密不应持久化。召回时先按用户与权限过滤，再按相关性和新鲜度排序，并把来源一并交给 Agent。

最后要提供查看、更正、导出和删除能力。记忆越长并不代表 Agent 越聪明；可控、可解释、可撤销才是可用记忆。
