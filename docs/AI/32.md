# 机器学习实验清单：让一次结果可以重现

“记得当时怎么训练的”不是可复现。一次实验应能从明确输入、环境和命令重新产生可比较的结果，即使最终数值因硬件存在微小差异。

## 最小记录集

至少保存代码提交、数据版本、依赖锁文件、随机种子、完整参数、运行环境、指标和输出模型校验和。下面用标准库生成一份清单：

```python
import hashlib
import json
import platform
from pathlib import Path

model = Path("model.bin")
manifest = {
    "python": platform.python_version(),
    "seed": 42,
    "params": {"epochs": 8, "learning_rate": 2e-4},
    "model_sha256": hashlib.sha256(model.read_bytes()).hexdigest(),
}
Path("run-manifest.json").write_text(
    json.dumps(manifest, ensure_ascii=False, indent=2), encoding="utf-8"
)
```

实际项目还应由 CI 注入 Git SHA 与数据版本，避免手工填写出错。

## 区分产物与来源

模型文件是产物，代码、数据和参数是来源。两者都要追踪，但不必都放进 Git。大文件进入对象存储，仓库中保存不可变地址与哈希。指标应连同评估集版本保存，单独一个准确率没有比较意义。

## 复现实验

在干净环境中定期抽样重跑发布候选：安装锁定依赖、拉取指定数据、执行同一入口、比较容差内指标。无法重现时先停止发布，把缺失信息补回实验清单。
