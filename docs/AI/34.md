# 梯度累积：小显存下保持有效批次

梯度累积把多个微批次的梯度相加后再更新参数，可以降低单步显存占用。有效批次通常等于“单卡微批次 × 累积步数 × 数据并行卡数”。

## 正确缩放损失

下面的 PyTorch 片段展示关键顺序：

```python
optimizer.zero_grad(set_to_none=True)
accumulation_steps = 4

for step, batch in enumerate(loader):
    loss = model(**batch).loss / accumulation_steps
    loss.backward()

    if (step + 1) % accumulation_steps == 0:
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
        optimizer.step()
        optimizer.zero_grad(set_to_none=True)
```

除以累积步数，可让梯度尺度接近一次处理完整大批次。最后不足一个累积周期的数据也要执行更新，生产代码可在循环结束时补一次 `step`。

## 调度器与日志

学习率调度器通常应在优化器真正更新后调用，而不是每个微批次调用。日志同时记录微步和更新步，否则曲线横轴会被放大。梯度裁剪应放在完整累积完成之后；混合精度训练还要先反缩放再裁剪。

## 并非完全等价

含批归一化、随机层或按批次动态采样时，累积与真实大批次可能不同。改变有效批次后，应重新检查学习率、收敛速度和验证集表现，而不是只确认“不再爆显存”。
