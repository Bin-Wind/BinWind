# 微调中的灾难性遗忘：识别与缓解

模型在窄领域数据上微调后，可能擅长新任务却丢失原有的通用能力，这就是灾难性遗忘。只看领域验证集，会把这种退化误判为成功。

## 建立双轨评测

发布前同时保留领域集与通用能力回归集。领域集检查目标提升，回归集覆盖基础指令遵循、格式输出、安全边界和原先关键任务。两组数据都应与训练集去重。

```python
def release_gate(domain_before, domain_after, general_before, general_after):
    domain_gain = domain_after - domain_before
    general_drop = general_before - general_after
    return domain_gain >= 0.03 and general_drop <= 0.01

print(release_gate(0.71, 0.76, 0.82, 0.815))
```

阈值应由业务风险和历史方差决定，上例只展示门禁结构。

## 常用缓解方法

降低学习率和训练轮数，混入经过许可的通用回放样本，或使用 LoRA 等参数高效方法减少整体权重扰动。回放数据不宜简单复制原训练集，应围绕必须保留的能力构造小而稳定的回归集合。

## 定位问题

按任务类型、输入长度和语言切片比较微调前后差值。若领域能力早已见顶而通用能力继续下降，应提前停止。最终选择检查点时，应看多目标权衡，而不是只挑训练损失最低的一个。
