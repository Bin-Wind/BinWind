# 微调数据去重与评测泄漏检查

训练数据中大量重复会放大少数样本，评测题进入训练集则会制造虚假的高分。去重和泄漏检查应在切分数据之前完成，并保留审计记录。

## 规范化与精确去重

先做保守规范化，避免把含义不同的文本错误合并：

```python
import hashlib
import re

def fingerprint(text: str) -> str:
    normalized = re.sub(r"\s+", " ", text.strip())
    return hashlib.sha256(normalized.encode("utf-8")).hexdigest()

rows = ["解释 HTTP 缓存", "解释  HTTP  缓存", "解释 Cookie"]
unique = {fingerprint(row): row for row in rows}
print(list(unique.values()))
```

哈希只解决规范化后完全相同的内容。近重复可用字符 n-gram、MinHash 或嵌入召回候选，再人工抽查阈值两侧。

## 检查切分污染

先按来源文档、用户或会话分组，再将整组分配到训练、验证和测试集。否则同一文档的相邻段落可能跨集合出现。对所有集合两两运行精确与近重复检查，输出命中来源和处理原因。

## 保留证据

记录原始行数、各阶段删除量、规则版本和被删除样本的 ID。不要只保存清洗后的文件；可追溯的清单才能解释指标变化，也便于发现规则误伤。
