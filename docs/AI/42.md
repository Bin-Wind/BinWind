# Agent 故障恢复：用检查点重放长任务

长任务可能因进程重启、网络中断或模型超时而失败。若只能从头开始，不仅浪费成本，还可能重复已经产生副作用的步骤。

## 保存最小检查点

每完成一个可恢复步骤，保存任务 ID、步骤名、输入摘要、输出引用、状态和时间。大结果进入对象存储，检查点只保留地址与校验和。

```python
from dataclasses import asdict, dataclass
import json

@dataclass
class Checkpoint:
    task_id: str
    step: str
    status: str
    output_ref: str

cp = Checkpoint("task-42", "collect", "succeeded", "obj://runs/42.json")
print(json.dumps(asdict(cp), ensure_ascii=False))
```

## 可重放边界

纯读取和确定性计算可直接重跑；外部写入必须使用幂等键或先查询状态。恢复时从最后一个已确认成功的边界继续，不能仅凭“发送过请求”认定成功。

## 版本与过期

检查点记录工作流版本。代码或提示模板变化后，判断旧状态能否迁移；不能迁移时明确终止并重新创建任务。临时授权过期后重新申请，不要把长期密钥塞进检查点。定期进行故障注入，验证任务能在每个步骤中断后安全恢复。
