# LoRA 目标模块选择：先确认参数名再配置

`target_modules` 决定 LoRA 插入哪些线性层。直接照抄另一种模型的 `q_proj`、`v_proj` 配置，可能匹配不到任何层，也可能遗漏影响任务效果的模块。

## 枚举候选层

加载模型后先查看线性层名称及尺寸，再按架构选择：

```python
from torch import nn

def linear_layer_names(model) -> list[str]:
    return [name for name, module in model.named_modules()
            if isinstance(module, nn.Linear)]

# model 加载后执行：
# for name in linear_layer_names(model)[:30]:
#     print(name)
```

注意力投影通常是低成本起点；任务变化较大时可实验加入输出投影或前馈网络。不同库可能把量化线性层包装成其他类型，枚举逻辑要随实现调整。

## 用实验而非口诀决定

固定数据、随机种子、秩和学习率，只改变目标模块，比较验证质量、可训练参数、显存和吞吐。训练启动后打印实际匹配层与可训练参数比例；若为零或远超预期应立即停止。

保存适配器时同时记录基础模型精确版本和目标模块列表。适配器只能安全地加载到与训练时结构一致的基础模型上。
