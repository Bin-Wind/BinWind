# RAG 权限过滤：检索阶段就隔离不可见文档

如果先召回所有文档，再让大模型“不要引用无权限内容”，敏感文本已经进入上下文。访问控制必须发生在检索阶段，并且由可信身份决定。

## 索引权限元数据

每个文档块保存租户、资源编号和访问标签。查询过滤条件由服务端根据登录身份生成，不能接受客户端直接传入任意租户号：

```python
def build_filter(identity: dict) -> dict:
    allowed = set(identity["groups"])
    return {
        "tenant_id": identity["tenant_id"],
        "acl_any": sorted(allowed | {"public"}),
    }
```

向量库若不支持可靠的预过滤，应按租户拆分索引或更换方案，不能依赖召回后的 Python 过滤，因为 Top K 可能全被无权结果占满。

## 防止旁路泄漏

缓存键要包含用户可见范围；引用下载接口再次鉴权；删除权限后清理派生摘要与缓存。日志只记录文档编号和权限判定，不记录敏感正文。

测试至少覆盖跨租户、撤权、共享组变化和恶意过滤参数。用一个无权限“诱饵文档”做持续回归，可以及时发现索引或缓存层的隔离失效。
