# RAG 上下文压缩：保留证据而不是盲目截断

检索返回的段落常含目录、重复说明和与问题无关的句子。把全部内容塞入提示词会增加成本，也可能稀释真正证据。上下文压缩要减少噪声，同时保持可核验出处。

## 两阶段处理

先召回较多候选，再以问题为条件挑选相关句段。每个压缩片段必须携带原文档编号、页码或标题，以及原始字符区间。最终引用仍指向原文，而不是指向模型生成的摘要。

简单的关键词基线也值得保留：

```python
import re

def select_sentences(text: str, terms: set[str], limit: int = 3) -> list[str]:
    sentences = re.split(r"(?<=[。！？])", text)
    ranked = sorted(sentences, key=lambda s: sum(t in s for t in terms), reverse=True)
    return [s for s in ranked if s.strip()][:limit]
```

它不理解语义，却便于解释，可作为学习式压缩器的对照组。

## 评估信息损失

同时测量答案正确率、引用支持率、上下文 Token 数和压缩耗时。专门加入否定句、表格脚注与跨段条件等样本；这些内容最容易被“看起来不重要”的压缩逻辑删除。若证据不足，应返回无法确认，而不是让生成模型补齐缺失信息。
