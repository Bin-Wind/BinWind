# RAG 无答案检测：证据不足时可靠地拒答

知识库问答最大的风险之一，是检索不到答案时模型仍给出流畅猜测。无答案检测应同时检查检索证据和生成结果，不能只靠一句“不要编造”的提示词。

## 校准检索阈值

相似度分数只在同一模型与索引配置内有意义。准备一组“库内可答”和“库外不可答”问题，观察最高分与分差分布，再选阈值。索引或嵌入模型变化后重新校准。

```python
def evidence_decision(scores: list[float], threshold: float) -> str:
    if not scores or max(scores) < threshold:
        return "insufficient"
    return "answer"
```

还要检查 Top K 片段是否来自独立证据、是否覆盖问题中的时间和对象限定。单一高分标题不一定包含答案。

## 设计有用的拒答

拒答应说明缺少哪类信息，并建议用户补充关键词、时间范围或文档，而不是只说“不知道”。生成后再做引用蕴含检查：关键结论若找不到对应证据，删除该结论或整体降级为拒答。

评测集中应保留足量不可答问题，并分别统计错误回答率与错误拒答率。目标不是拒绝越多越好，而是在两种错误之间找到业务可接受的平衡。
