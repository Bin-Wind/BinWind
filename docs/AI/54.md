# Agent 预算控制：限制步数、时间与外部费用

Agent 可能因搜索无结果、工具报错或自我修正形成循环。预算不是简单的超时开关，而是对步数、墙钟时间、Token 和外部费用设置共同边界。

## 集中记账

执行器在每次调用前预扣预算，结束后按实际消耗结算：

```python
from dataclasses import dataclass

@dataclass
class Budget:
    steps_left: int
    cents_left: int

    def reserve(self, estimated_cents: int) -> None:
        if self.steps_left <= 0 or estimated_cents > self.cents_left:
            raise RuntimeError("budget exhausted")
        self.steps_left -= 1
        self.cents_left -= estimated_cents
```

费用估算要偏保守；未知价格的工具默认需要审批，而不是按零成本处理。

## 接近上限时优雅收束

预算剩余不足以完成下一阶段时，Agent 应保存已验证结果、未完成事项和继续所需输入。不要为了“给出答案”跳过校验，也不要无限压缩输出掩盖失败。

为重复工具加循环检测：相同参数连续失败、状态无变化或计划没有新增证据时提前停止。监控按任务类型统计预算耗尽率，区分合理的大任务和异常循环，再调整默认额度。
