# 批量推理管线：分片、幂等与断点续跑

离线打标签、生成摘要或批量嵌入常需处理百万条记录。可靠管线不能依赖一个长进程跑到底，而应把任务切成可重试、可核验的小分片。

## 稳定划分输入

先冻结输入快照，再按稳定主键分片。不要按数据库当前行号分页，数据插入会造成漏读或重复。每个输出记录同时保存输入 ID、输入版本、模型版本和提示词版本。

```python
import hashlib

def shard_for(record_id: str, count: int) -> int:
    digest = hashlib.sha256(record_id.encode()).digest()
    return int.from_bytes(digest[:8], "big") % count
```

同一输入与同一推理配置应生成确定的幂等键。写入采用唯一约束或条件覆盖，重试不会制造两份结果。

## 把完成状态与质量分开

分片状态至少区分待处理、运行中、成功、可重试失败和永久失败。工作进程领取任务时设置租约，崩溃后租约到期可重新领取；只写一个“完成”布尔值很难处理半成品。

恢复时先核对输出条数、唯一 ID 和错误分布，再补跑缺口。最后对结果抽样做内容评测，并把失败样本单独保存。吞吐量达标不代表答案可用；批量推理的验收必须同时覆盖完整性与质量。
