# 混合精度微调：速度提升与数值稳定

混合精度用较低精度执行大部分矩阵运算，同时保留必要的高精度状态，可显著减少显存与计算时间。它不是简单把所有张量转成半精度。

## FP16 与 BF16 怎么选

FP16 精度更细但指数范围较小，梯度过小时需要动态 loss scaling；BF16 指数范围接近 FP32，通常更稳定，但硬件必须原生支持。先查询训练框架和设备能力，再启用对应模式，不要同时设置互斥选项。

```python
import torch

device = "cuda"
model = torch.nn.Linear(32, 1).to(device)
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)
scaler = torch.amp.GradScaler("cuda")

x = torch.randn(16, 32, device=device)
with torch.autocast(device_type="cuda", dtype=torch.float16):
    loss = model(x).square().mean()

scaler.scale(loss).backward()
scaler.unscale_(optimizer)
torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
scaler.step(optimizer)
scaler.update()
```

## 先观察再提速

记录 loss scale、非有限梯度、梯度范数和吞吐。频繁跳过更新通常说明溢出，不应只调大日志间隔掩盖。归一化、损失计算或部分敏感算子可保持 FP32。

用同一随机种子做短程 FP32 基线，对比损失趋势和验证指标；允许微小差异，但不能只凭单次更低 loss 判定更好。最终保存精度配置与硬件信息，确保检查点能够正确恢复。
