# 多轮对话微调：截断、标签掩码与样本边界

多轮对话数据不能直接把所有文本拼起来训练。模板、截断位置和损失掩码共同决定模型在学习谁说的话，以及长对话末尾是否被系统性丢弃。

## 只监督目标回复

通常让用户与系统内容参与上下文，但不计算其预测损失；只对助手回复的 Token 设置标签。填充位和不参与监督的位置使用框架约定的忽略值，例如 `-100`。

```python
def mask_labels(token_ids: list[int], assistant_spans: list[tuple[int, int]]):
    labels = [-100] * len(token_ids)
    for start, end in assistant_spans:
        labels[start:end] = token_ids[start:end]
    return labels
```

跨度必须在套用最终聊天模板并分词后计算。通过解码抽样核对边界，尤其注意角色标记、结束符是否误入或漏掉。

## 截断要保住任务条件

从末尾硬截可能丢失最新答案，从开头硬截又可能丢失系统约束。可按完整轮次裁剪：保留系统消息、当前用户问题和目标回复，再在预算内向前补历史。被截成半句的回复不应进入监督。

统计有效监督 Token 比例、零标签样本数和各轮次长度分布。训练与推理必须使用同一模板；发布前用多轮回归集检查角色混淆、重复结束符和上下文遗忘。
