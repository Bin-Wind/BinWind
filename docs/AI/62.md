# RAG 邻段扩展：命中一个切片后补回必要上下文

检索切片为了提高命中率往往较短，却可能把定义、条件和结论拆开。邻段扩展是在召回命中后，按文档结构补回前后片段，而不是一开始就把所有切片做大。

## 使用结构化邻接关系

每个切片保存文档版本、章节路径、序号与前后邻居 ID。重排完成后，只对高置信命中扩展同章节邻段；跨标题边界默认停止，避免把不相关章节带进来。

```python
def neighbor_ids(hit: dict, radius: int = 1) -> list[str]:
    section = hit["section"]
    index = hit["index"]
    return [
        f"{hit['document_version']}:{section}:{i}"
        for i in range(max(0, index - radius), index + radius + 1)
    ]
```

实际系统应从元数据表读取存在的 ID，并保持文档版本一致。多个命中扩展出重叠区间时先合并，再按原文顺序组装。

## 控制预算与引用

优先为定义不完整、指代词密集或表格跨片的命中扩展。总 Token 超限时，先减少低分命中的邻段，而不是截断最高分证据的中间。

引用应指向原始页码或章节，而不是内部切片编号。用需要跨切片才能回答的问题建立测试集，对比扩展前后的答案完整性、噪声率和上下文长度，确认增加的内容确实解决边界问题。
