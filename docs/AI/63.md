# 提示词回归测试：让模板修改有证据可比

提示词改一个词就可能影响格式、拒答边界和工具选择。靠手工试几个问题无法覆盖回归风险，应把关键行为写成可重复测试。

## 固定输入与判定规则

测试用例包含输入、上下文、预期结构和禁止行为。能确定性判断的项目先用代码校验，例如 JSON Schema、引用数量或是否泄露保密字段；开放式质量再交给人工或经过校准的模型评审。

```python
def validate_answer(answer: dict) -> None:
    required = {"answer", "citations"}
    if set(answer) != required:
        raise AssertionError("响应字段不符合约定")
    if not isinstance(answer["citations"], list):
        raise AssertionError("citations 必须是列表")
    if answer["answer"] and not answer["citations"]:
        raise AssertionError("有事实回答时必须提供引用")
```

## 控制随机性与污染

记录模型版本、模板版本、采样参数和工具模拟结果。对随机输出重复运行，报告通过率与置信区间，而不是比较单个样本。评测集不要直接放进生产提示词或训练数据。

合并前同时展示新旧模板在同一用例集上的差异，按安全、任务成功、格式和成本分栏。关键安全用例设为硬门禁，风格指标只做趋势提示。失败样本保留完整链路，便于判断是提示词、模型还是外部工具变化。
