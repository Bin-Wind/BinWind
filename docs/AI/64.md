# Agent 工具结果校验：不要把外部返回值当成事实

工具可能超时、返回旧缓存、缺字段或混入错误页面。Agent 如果直接把返回文本放进下一步推理，就会把外部故障放大成错误操作。

## 在边界处验证

为每个工具定义成功状态、字段类型、范围和新鲜度。解析失败应得到结构化错误，而不是用空字符串继续：

```python
from dataclasses import dataclass
from datetime import datetime, timezone

@dataclass
class Weather:
    temperature_c: float
    observed_at: datetime

def parse_weather(payload: dict) -> Weather:
    temperature = float(payload["temperature_c"])
    observed_at = datetime.fromisoformat(payload["observed_at"])
    if not -90 <= temperature <= 70:
        raise ValueError("温度超出可信范围")
    if observed_at.tzinfo is None:
        raise ValueError("时间必须带时区")
    return Weather(temperature, observed_at.astimezone(timezone.utc))
```

验证通过只说明格式合理，不代表事实正确。高风险动作还需交叉核对身份、目标和当前状态。

## 区分失败类型

把可重试的网络故障、需要修正参数的校验错误和明确的业务拒绝分开。重试必须有限且具幂等性；权限不足不应通过改写参数绕过。

日志保存工具版本、请求摘要、响应摘要和验证结论，并对敏感字段脱敏。向用户报告时标明信息时间与来源，证据不足就停止或请求确认，不能用流畅文本掩盖不确定性。
