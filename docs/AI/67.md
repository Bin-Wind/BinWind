# 标注一致性抽检：用分层样本发现规则歧义

总体准确率会掩盖少数类和边界样本的问题。抽检应同时覆盖随机样本、高风险类别、低置信样本和近期新增数据，并保留各层权重，避免把“困难样本集”的结果误当成总体质量。

## 先定义可复核的判断单位

为每个标签写清正例、反例、优先级与“不确定”处理方式。两名标注者独立处理同一批样本，再由仲裁者只查看分歧项。分类任务可统计逐类一致率和 Cohen's kappa，但指标不能替代分歧原因分析。

```python
from collections import Counter

pairs = [("投诉", "投诉"), ("咨询", "投诉"), ("其他", "其他")]
matrix = Counter(pairs)
agreement = sum(a == b for a, b in pairs) / len(pairs)
print(f"一致率: {agreement:.1%}")
for pair, count in matrix.items():
    print(pair, count)
```

把分歧归为定义冲突、上下文不足、工具错误或人为疏漏。修改规则后，用同一批“锚点样本”复标，再观察新数据，防止只记住答案。版本化保存规则、样本批次、标注者和仲裁结果，训练数据才有可追溯的质量依据。
