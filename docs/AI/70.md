# 微调学习率调度：预热、衰减与可比较实验

学习率过大可能让损失突然发散，过小则在有限步数内学不到目标行为。预热让优化器从较小步长进入稳定区，后续衰减帮助训练在末期细化，但没有一种曲线适合所有数据与模型。

## 先固定有效批次与总步数

比较学习率前，保持数据顺序、随机种子、有效批次、训练步数和评测集一致。预热通常按总优化步数的比例设置；梯度累积只在真正执行优化器更新时推进调度器。

```python
def linear_warmup_decay(step: int, total: int, warmup: int) -> float:
    if warmup > 0 and step < warmup:
        return (step + 1) / warmup
    remain = max(total - warmup, 1)
    return max(0.0, (total - step) / remain)

print([round(linear_warmup_decay(s, 100, 10), 2) for s in (0, 9, 10, 50, 99)])
```

同时观察训练损失、验证任务指标、梯度范数和参数更新幅度。若增加批次大小，不要机械按比例放大学习率；先用小规模扫描找到稳定区，再扩大训练。保存完整曲线和配置，比只记录“最佳学习率”更可复现。
