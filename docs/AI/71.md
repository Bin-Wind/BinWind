# 梯度检查点：用计算时间换微调显存

反向传播通常需要保存前向过程的中间激活。梯度检查点只保留部分节点，反向时重新计算其余激活，因此降低显存占用，但会增加计算时间。

## 先确认瓶颈确实是激活

记录未启用时的峰值显存、每步耗时、序列长度和批次。若显存主要被优化器状态占用，LoRA、低精度优化器或参数分片可能更有效。启用后保持其他配置不变，确认能否提高序列长度或微批次，并比较总吞吐。

在常见 Transformers 模型中可启用：

```python
model.gradient_checkpointing_enable()
model.config.use_cache = False
```

`use_cache` 面向自回归推理，训练时通常应关闭以免与检查点冲突。自定义网络还要确保被重算区域没有依赖不可复现的副作用；随机层需要框架正确保存随机状态。

不要只看“省了多少 GB”。若重算使单步显著变慢，却没有换来更合适的批次或序列长度，总训练成本可能更高。最终配置应同时记录显存、样本吞吐与验证质量。
