# 微调数据切分：按实体和时间阻断评测泄漏

随机按行切分对话数据看似均匀，却可能把同一用户、同一文档改写或同一事件的近似样本分到训练集和验证集，导致评测虚高。

## 先确定泄漏边界

客服任务可按客户或工单切分，文档问答按源文档切分，代码任务按仓库切分。若目标是预测未来表现，还应按时间切分，并让验证数据晚于训练数据。

```python
from hashlib import sha256

def bucket(entity_id: str, folds: int = 10) -> int:
    digest = sha256(entity_id.encode("utf-8")).digest()
    return int.from_bytes(digest[:4], "big") % folds

rows = [{"user": "u1"}, {"user": "u2"}, {"user": "u1"}]
for row in rows:
    row["split"] = "validation" if bucket(row["user"]) == 0 else "train"
print(rows)
```

稳定哈希保证同一实体始终落在同一侧。切分后再做类别、来源和长度分布报告；必要时调整实体级分配，而不是把单条样本挪回。数据版本变化时保留旧测试集作为纵向基准，并建立全新的时间外测试集观察真实泛化。
