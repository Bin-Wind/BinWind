# RAG 上下文排序：把关键证据放在模型看得见的位置

检索到正确片段不代表模型一定会使用。长上下文中，重复、矛盾或位置靠后的证据可能被忽略。排序目标是让回答所需的少量证据清晰、相邻且可追溯。

## 从相关性变成可回答性

先去除近重复片段，再用重排分数、来源可信度、时效和权限共同筛选。需要多个步骤的问题，可按子问题分组；同一文档的前后片段保持自然顺序。把最高价值证据放在提示词中明确标记的位置，并保留来源 ID。

不要用大量低分片段填满窗口。为每个候选记录进入或被淘汰的原因，并测试“只给黄金证据”“给检索证据”“随机打乱顺序”三组结果。如果黄金证据仍答错，问题多半在提示或模型；若打乱后显著下降，说明排序敏感。

遇到来源冲突时，不要静默挑选一个结论。提示模型指出差异和日期，并让业务规则决定权威来源。评测除了答案正确率，还应检查引用是否真正支持对应句子。
