# Agent 工具超时：截止时间、取消与有限重试

没有超时的工具调用会占住整个任务；层层各设独立长超时，又可能让总时长失控。Agent 应从任务级截止时间向下分配预算，并把剩余时间传给每个工具。

## 只重试可能恢复的失败

网络超时、限流和临时服务不可用可以有限重试；参数错误、权限拒绝和业务校验失败通常不应重试。写操作只有具备幂等键或明确查询到未执行时才安全重放。

```python
from time import monotonic

deadline = monotonic() + 30

def remaining(cap: float) -> float:
    value = deadline - monotonic()
    if value <= 0:
        raise TimeoutError("任务总时限已到")
    return min(value, cap)

print(round(remaining(5), 2))
```

取消后要确认下游是否仍在执行，尤其是付款、发布等动作。工具结果记录尝试次数、错误类别与幂等键，但不记录密钥。预算耗尽时返回已完成状态和可恢复检查点，让后续执行能够继续，而不是从头重复所有外部动作。
