# Agent 并行工具调用：汇合结果时处理冲突

并行查询天气、库存和日历可以降低等待时间，但并行写同一资源会产生覆盖和顺序不确定。只有彼此独立、失败可隔离的操作才适合同时执行。

## 先画读写集合

为每个工具声明读取资源、写入资源、是否幂等和依赖前置结果。写集合相交时改为串行，或使用版本号与条件更新。多个只读结果汇合时，也要保留来源时间；“最新”结果可能在等待期间已经过期。

汇合策略应明确：全部成功、任一成功、达到法定数量，还是允许部分结果。不要把缺失值当作否定结果。一个分支失败时，取消已无意义的分支，并汇报已经完成的外部动作。

测试应主动改变完成顺序，模拟慢响应、重复回调和单分支失败。若只有固定顺序才通过，流程仍存在竞态。对不可逆写操作设置单独审批点，让并行优化永远不越过业务安全边界。
