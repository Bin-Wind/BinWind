# Agent 不确定性升级：知道何时停止自动决策

Agent 的置信表达不一定校准，不能只凭一句“我很确定”决定是否自动执行。升级规则应基于可观察条件：证据缺失、来源冲突、参数歧义、影响范围和动作可逆性。

## 给升级请求足够上下文

需要人工判断时，说明目标、已确认事实、未确定点、已尝试动作、可选方案及各自影响。不要只抛出“请确认”。低风险可逆操作可用默认值继续，高风险写操作必须等待明确授权。

建立三档策略：可自动执行、执行后通知、执行前审批。金额、数据删除、外部发布、权限扩大和法律承诺通常属于最后一档。工具返回为空、格式变化或来源过期时，应按未知处理，不能自动解释成安全。

记录升级是否必要以及人工最终选择，定期检查误拦截与漏拦截。目标不是让人审批一切，而是让自动化覆盖清晰、低风险的部分，把真正需要判断的信息压缩后交给人。
