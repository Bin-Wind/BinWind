# 训练数据 Schema 演进：字段变化也要可回放

训练样本从一张表成长为长期资产后，字段改名、标签枚举调整和特征类型变化都会影响旧模型。不要直接覆盖历史数据；为每批数据记录 schema_version，并把迁移逻辑当作可测试代码管理。

## 先定义兼容边界

新增可选字段通常可以向后兼容，删除字段、改变含义或缩小取值范围则需要新版本。读取器先识别版本，再转换为当前内部结构；遇到未知版本应明确失败，而不是把缺失字段悄悄填成空值。

~~~python
def normalize(sample: dict) -> dict:
    version = sample.get("schema_version", 1)
    if version == 1:
        return {
            "text": sample["prompt"],
            "label": int(sample["target"]),
            "schema_version": 2,
        }
    if version == 2:
        return sample
    raise ValueError(f"unsupported schema_version: {version}")
~~~

迁移测试至少覆盖正常样本、缺字段、非法枚举和旧版本回放。训练产物应同时保存数据快照标识、读取器版本与最终 schema；这样半年后不仅能找到原始文件，也能用同一语义重新构建输入。
