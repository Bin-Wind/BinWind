# 微调早停：把验证指标和停止规则预先写清

训练越久并不一定越好。训练损失继续下降时，模型可能已经开始记忆训练表达，验证集上的任务质量却在变差。早停的关键不是一个回调函数，而是训练前固定判定口径。

## 选择与目标一致的指标

生成任务不要只看 token loss，可同时跟踪格式合规率、任务成功率和关键安全集退化。指标有噪声时使用固定评测集与相同解码参数，并设置最小改善量和耐心轮数，避免一次随机波动就停止。

~~~python
best = float("-inf")
bad_rounds = 0
for score in [0.71, 0.73, 0.729, 0.728]:
    if score > best + 0.002:
        best, bad_rounds = score, 0
    else:
        bad_rounds += 1
    if bad_rounds >= 2:
        print("stop", best)
        break
~~~

保存最佳检查点而非最后检查点，并记录停止原因、阈值和完整曲线。多个指标冲突时预先规定主指标与不可退化护栏，不能训练结束后挑一项最好看的结果。
