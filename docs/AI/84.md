# 从检查点恢复微调：验证的不只是权重

中断后加载模型权重并不等于真正续训。优化器动量、学习率调度器、梯度缩放器、随机数状态和数据游标缺一项，都可能让恢复后的曲线突然跳变或重复读取样本。

## 做一次主动中断演练

检查点应原子写入临时目录，完成所有文件与清单后再重命名为可用版本。清单包含全局步数、已见 token 数、数据版本、代码提交、依赖版本与分布式规模；启动时先校验完整性，再恢复状态。

在短训练中主动于固定步数终止，恢复后比较连续训练与断点训练的学习率、下一批样本标识和若干步损失。完全逐位一致在不同硬件上未必现实，但走势和数据顺序应可解释。

若变更批大小、GPU 数或数据分片方式，应明确这是“从权重开始的新阶段”，不要伪装成无缝续训。保留旧检查点直到新阶段通过验证，并为损坏或不兼容状态提供清晰失败信息。
