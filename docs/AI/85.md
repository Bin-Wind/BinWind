# RAG 检索阈值校准：用已标注问题决定拒答边界

相似度分数没有跨模型、跨索引的统一含义。直接写一个看起来合理的 0.8，可能错过同义表达，也可能把无关文档送进上下文。

## 在开发集上画出取舍

准备包含可回答、不可回答、歧义和相近主题干扰的问题集，为每题标注可接受证据。对不同阈值统计证据召回率、无关片段率与最终答案错误率，并按业务风险选择操作点。

阈值应作用在正确阶段：向量召回分、重排分和最终答案置信不是同一量纲。多路检索时可先各自归一或按排名融合，再为融合结果校准；不要混合原始分数后沿用单路阈值。

线上记录查询类型、最高分、分差、是否拒答和用户反馈，但不记录不必要的敏感正文。索引内容、嵌入模型或切分策略变化后重新校准。可靠的拒答边界来自代表性样本，不来自某个固定常数。
