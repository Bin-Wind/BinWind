# RAG 引用覆盖率：检查结论是否真的有证据

答案带了两个链接，不代表所有关键结论都被支持。引用覆盖率应以“可核验主张”为单位，检查每条主张是否对应到足够具体的证据片段。

## 把答案拆成原子主张

先分离事实、建议和推断。事实性主张需要引用；纯粹的组织语句可以不引用。评测者查看引用片段能否直接支持该主张，以及引用是否来自正确版本、时间和权限范围。

可记录三项指标：有引用的主张比例、引用确实支持主张的比例、证据片段中被答案正确使用的比例。一个引用同时挂在整段末尾时，要防止它只支持其中一句。对数字、日期、限制条件和否定结论提高检查权重。

自动判定适合批量筛查，但高风险领域仍需人工抽样。生成阶段要求模型输出主张与证据 ID 的结构化映射，展示层再转换为脚注；证据找不到时应删减结论或明确不确定，而不是补一个看似相关的链接。
