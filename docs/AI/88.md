# Agent 工具循环检测：识别原地重试与无效往返

Agent 可能反复以相同参数调用失败工具，或在两个工具之间来回切换却没有增加信息。只限制总步数会止损，但不能解释为什么停下。

## 为每一步生成稳定指纹

把工具名、规范化参数、关键结果状态和相关资源版本组合成指纹。连续出现相同指纹，或在短窗口内形成 A-B-A-B 模式时，判定为疑似循环。时间戳、请求 ID 等噪声字段应从指纹中移除。

检测后不要继续盲目重试：先总结已尝试动作、相同失败原因和仍缺少的信息，再选择退避、换方案或请求人工介入。对明确幂等且瞬时失败的工具，可允许少量带抖动重试；权限拒绝和参数校验失败通常不应自动重试。

日志保留循环类型、步数和最终处理，不记录密钥等敏感参数。用历史轨迹回放评估误报，避免把合理的分页调用或逐文件处理当成循环。
