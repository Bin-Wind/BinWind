# Agent 审计日志：让一次自动决策能够复盘

普通应用日志关注错误，Agent 审计日志还要回答：当时看到了什么、为何选择动作、工具实际改变了什么，以及谁批准了高风险步骤。

## 记录事实而非隐藏推理

每一步保存任务 ID、时间、模型与提示版本、工具名、经过脱敏的参数摘要、返回状态、资源版本和审批主体。无需保存模型的隐式思维过程；用简短的决策理由、所依据证据 ID 和策略规则即可支持复盘。

写操作前后都记录：前置日志表明意图，工具返回或外部事件表明结果。为记录建立不可变 ID 与链式关联，重试沿用同一幂等键，才能区分一次动作的重复响应与两次真实修改。

访问审计日志本身也要授权和留痕，并设定保留、加密与删除规则。定期抽样检查敏感字段泄漏和缺失步骤；真正可用的审计日志应能重建事件时间线，而不是堆满无法关联的文本。
