# Agent 人工交接包：停止自动化时留下可执行上下文

需要人工介入时只说“失败了”会迫使接手者从头调查。交接包应简洁地说明目标、当前状态、已验证事实、做过的动作和下一项需要决定的事情。

## 区分事实、推断与建议

事实附来源或工具结果标识；推断明确写出假设；建议列出风险与可回退方案。包含受影响资源、最后成功检查点、未完成写操作和是否仍有后台任务。密钥、完整个人数据和无关日志不能进入交接包。

交接触发条件应预先配置，例如连续权限失败、预算即将耗尽、互相冲突的高置信证据，或需要承担业务责任的选择。触发后冻结新的高风险动作，只允许完成安全收尾与状态读取。

用演练验证交接质量：让未参与任务的人仅凭交接包继续处理，记录其仍需追问的信息。不断补齐结构化字段，但保持首页能在一分钟内读完；详细轨迹通过链接按需展开。
