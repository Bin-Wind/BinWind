# 训练数据契约：让缺列与取值漂移在训练前失败

训练脚本若到中途才发现字段缺失，会浪费算力，也可能把空值静默当成正常样本。数据契约应在读取入口明确必需字段、类型、取值范围与跨字段约束，并随数据版本一起保存。

~~~python
def validate(row: dict) -> None:
    required = {"text", "label", "created_at"}
    missing = required - row.keys()
    if missing:
        raise ValueError(f"missing fields: {sorted(missing)}")
    if not isinstance(row["text"], str) or not row["text"].strip():
        raise ValueError("text must be non-empty")
    if row["label"] not in {0, 1}:
        raise ValueError("label must be 0 or 1")
~~~

先在抽样数据上快速检查，再对正式快照执行全量验证。报告同时记录失败数量、示例行标识和契约版本，但避免输出敏感正文。新增可选字段可以兼容旧读取器；改变字段含义或标签集合时应提升版本，并为旧快照保留迁移测试。

契约只证明数据符合约定，不证明数据正确。还需监控类别比例、文本长度、重复率和时间分布，并把允许波动写成门禁。超出范围时停止训练并调查，不要自动把阈值扩大到“通过”。
