# 微调梯度裁剪：先诊断爆炸，再限制更新幅度

长序列、异常样本或过高学习率可能让梯度范数突然增大，随后损失变成 NaN。梯度裁剪能限制单步更新，但不应掩盖持续的数据或数值问题。

采用梯度累积时，应在完成反向传播并反缩放之后、优化器更新之前裁剪。记录裁剪前范数与触发比例；若大多数步骤都触发，优先检查学习率、损失缩放、样本长度和标签掩码。

~~~python
optimizer.zero_grad()
loss.backward()
norm = torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
optimizer.step()
print(float(norm))
~~~

最大范数没有通用答案，应在固定数据与随机种子下比较损失曲线、任务指标和触发频率。分布式训练还要确认框架是在全局梯度上裁剪，而不是各设备各算一套。出现非有限范数时应跳过更新、保存样本标识并停止调查，不能继续训练到检查点被污染。
