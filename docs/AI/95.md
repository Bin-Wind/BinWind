# 微调数据污染哨兵：发现评测样本混入训练集

仅用文件名分开 train 与 eval，无法阻止同一内容的改写、截断版本或模板副本跨集合出现。污染会让评测分数看似提升，却不能代表泛化。

先对规范化文本计算精确摘要：统一换行和无意义空白，但保留可能影响任务的大小写与标点。再用字符 n-gram、MinHash 或嵌入召回查找近似重复，由人工复核高相似候选。对代码和表格应使用适合其结构的规范化规则，不能一律删掉格式。

在评测集中加入少量只用于检测的哨兵样本或独特短语，训练数据入库时扫描命中；哨兵本身不能进入提示或公开语料。报告按来源、实体和时间分层，防止同一客户、同一文档的不同片段泄漏。

发现污染后重新切分并从未接触污染数据的基座开始训练。删除几条评测题后继续沿用已经看过答案的检查点，仍然不能恢复可信度。
