# LoRA 秩选择：用任务增益而不是参数量猜答案

LoRA 的秩决定适配矩阵容量。秩太小可能学不下任务差异，太大则增加显存、存储与过拟合风险；没有一个对所有层和任务都最优的固定值。

用同一数据切分、训练步数和有效批次，对少量候选秩做控制实验。除主任务指标外，同时记录可训练参数、峰值显存、吞吐和基础能力退化。若更高秩只降低训练损失而不改善验证指标，应优先保留较小配置。

rank 与 alpha 要作为一组记录，目标模块也必须一致，否则实验无法归因。可以先覆盖注意力投影，再依据误差类型决定是否扩展到 MLP；不要一开始给所有线性层相同大秩。

最终产物保存基座模型精确版本、目标模块列表、rank、alpha 与训练模板。加载时逐项校验，避免把适配器挂到结构相似但并不兼容的基座上。
