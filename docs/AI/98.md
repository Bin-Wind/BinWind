# RAG 文档新鲜度：让过期证据退出答案

知识库中的旧制度和新制度可能语义同样相似。若索引只按相关度排序，模型很可能引用已经失效但表述完整的旧文档。

入库时保存生效时间、失效时间、版本、业务状态和权威来源。查询阶段先按权限和有效期过滤，再做召回与重排；用户明确询问历史时，才切换到对应时间截面。没有可靠日期的内容应标为待治理，而不是默认最新。

更新采用新版本先入库、校验可检索、再将旧版本标记失效的顺序，避免空窗。删除或撤回文档时同步清理向量、关键词索引和答案缓存，并监控各存储的版本水位。

构造包含“当前规定”“截至某日”“旧版与新版差异”的回归题。答案引用应展示版本或生效日期，让读者能判断证据是否适用于当前问题。
