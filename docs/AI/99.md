# RAG 父子切片：小块召回，大块提供上下文

切片过大时向量主题被稀释，过小时又丢失定义、表头和例外条款。父子切片把检索单元与送给模型的上下文分开：对子块建立索引，命中后返回其所属父块。

父块应是可独立理解的章节或表格，子块保留 parent_id、顺序和标题路径。召回多个同父子块时只展开一次父块；若父块仍太长，可围绕命中位置取有边界的窗口，而不是任意字符截断。

评测需分别看子块命中率、父块证据完整度与最终上下文长度。父块扩大可能提高答案完整性，也会增加噪声和成本，因此要在真实问题集上比较。权限、版本与有效期元数据必须同时存在于父子两级，并在展开时再次校验。

文档更新后先重建父子映射，再原子切换索引版本，避免子块指向已经删除的父内容。
