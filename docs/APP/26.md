# 本地优先笔记的备份与迁移方案

本地优先笔记把文件掌握在自己手中，但“文件在电脑上”不等于已有备份。可靠方案要同时应对误删、磁盘损坏、同步冲突和未来更换应用。

## 先确认数据边界

找到知识库真实目录，确认附件、模板、主题、插件配置和应用数据库分别存在哪里。随机抽取几篇带图片、链接和标签的笔记，在纯文本编辑器中打开，判断哪些信息依赖专有格式。

## 采用 3-2-1 思路

保留至少三份副本、使用两种介质、其中一份异地。一个实用组合是：工作目录 + 自动版本历史 + 定期离线硬盘。云同步主要解决多设备一致，不应被当作唯一备份；同步会把误删也迅速传播。

## 迁移演练

每季度在临时目录做一次导出与恢复：

1. 导出 Markdown 或应用支持的开放格式。
2. 复制附件，并检查相对链接。
3. 对文件数量和总大小做前后比对。
4. 抽查标题、中文文件名、表格、代码块和嵌入图片。
5. 用另一款编辑器打开核心笔记。

## 降低锁定风险

正文尽量使用标准 Markdown，附件使用稳定相对路径；把复杂数据库视图当作增强层，而非唯一内容。记录插件清单和特殊语法用途。加密备份要同时保存恢复说明，但密码与备份文件分开管理。

真正的可迁移性不是“有导出按钮”，而是你已经在另一处成功还原过完整资料。
