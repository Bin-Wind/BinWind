# PDF 阅读与批注工作流

高亮很多不等于真正吸收。一个可持续的 PDF 工作流应把“收集、阅读、批注、提炼、引用”分开，并确保离开当前应用后仍能找到原文位置。

## 收集阶段

文件名使用稳定规则，例如 `作者-年份-短标题.pdf`；同时保存来源链接、获取日期和版本。论文优先记录 DOI 等稳定标识，合同与规范则记录修订号。不要只把网页标题截图当作来源。

## 批注语义

限制颜色数量，并为每种颜色定义固定含义：核心论点、证据、疑问、待行动。批注文字写下“为什么重要”，而不是重复划线内容。长文每个章节结束后用自己的话写两三句摘要。

## 提炼模板

```markdown
# 文献标题

- 来源：
- 版本与日期：
- 核心问题：
- 一句话结论：
- 关键证据：页码 + 摘要
- 我的质疑：
- 可执行事项：
```

引用时保留页码或段落位置，并回到原 PDF 核对上下文。扫描版文档经过 OCR 后，专有名词和数字尤其需要人工校验。

## 选择工具的标准

先看批注是否使用标准 PDF 注释、能否导出、是否支持 OCR 与全文搜索，再看跨设备同步。定期抽取一个带批注文件，在另一款阅读器打开；如果批注只能留在应用数据库里，就增加独立导出步骤。
