# 云盘同步冲突处理：避免覆盖正确版本

同步冲突通常发生在多台设备离线编辑、程序尚未写完文件或账号空间不足时。看到“冲突副本”后不要立刻删除，应先冻结修改并确认时间线。

## 安全处理顺序

1. 暂停相关设备的同步，复制所有冲突版本到临时备份目录。
2. 比较修改时间、文件大小和实际内容，不只相信文件名。
3. 文本文件使用差异工具合并；二进制文件逐个打开确认。
4. 选定主版本后另存新文件，再恢复同步并观察其他设备。

## 降低冲突概率

大型项目数据库和频繁变动的构建目录不适合普通文件同步；使用应用自身协作机制或版本控制。编辑大型文件前确认同步完成，避免两台设备同时修改。保持足够本地与云端空间，并关注客户端报错。

## 同步不是备份

误删和损坏会被同步到所有设备。重要资料仍需独立、带历史版本的备份，并定期恢复抽查。解决一次冲突后记录原因和保留版本，避免团队成员再次覆盖。
