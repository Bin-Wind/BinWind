# RSS 阅读工作流：把信息流变成可处理的收件箱

RSS 的价值不是订阅越多，而是把来源、筛选和阅读节奏交还给自己。先从真正会定期阅读的十几个来源开始，避免第一天就导入几百个站点。

## 三层目录

把订阅分为“必读”“浏览”和“低频参考”。必读每天清空，浏览只看标题，低频参考依赖搜索而非逐条阅读。来源名称保持原站点名，分类表达你的处理方式，不必复制网站主题。

## 一次处理

打开一条内容后立刻选择：读完归档、稍后读、转成任务或删除。稍后读列表设容量上限和每周清理时间；需要行动的文章只提取一个明确任务，不要让收藏夹变成第二个未读箱。

对高频关键词使用规则加标签，对噪声关键词静音，但每月抽查过滤结果，避免把重要内容一起挡掉。跨设备使用时确认已读状态与标签是否同步，并定期导出 OPML 备份订阅清单。

衡量工作流是否有效，只看“本周读完并产生价值的内容”，不要追求未读数字归零。无法持续阅读的来源，取消订阅比建立更复杂的过滤器更省心。
