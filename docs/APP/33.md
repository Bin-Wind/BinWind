# OCR 文档整理：从拍照到可检索档案

OCR 能把图片里的文字变成可搜索文本，但识别结果不是原件。合同、票据和证件应同时保留清晰原图或 PDF，文本层只用于检索与辅助复制。

## 拍摄决定上限

纸面铺平，镜头与页面平行，使用均匀光线避免阴影和反光。完整拍入四角，正文清晰到放大后可辨；多页文件按顺序连续拍摄。先裁边和校正透视，再执行识别。

## 校验关键字段

对姓名、金额、日期、账号和条款编号逐项对照原图。表格、手写体、竖排和低对比印章是常见误识别区域。重要文件不能只抽查首尾页。

文件名可用 `YYYY-MM-DD_类型_对象_简述.pdf`，并把来源、页数和校验状态写进元数据。敏感文件优先使用本地 OCR；使用云服务前确认数据保存、训练用途与删除政策。

最后在另一台设备用几个关键字检索并打开原页，验证索引真的可用。对档案做独立备份，OCR 软件库和云同步都不能替代备份。
