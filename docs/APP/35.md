# 密码管理器迁移：不丢字段也不留下明文副本

更换密码管理器的风险不只在“能否导入”，还包括自定义字段丢失、重复条目和导出文件残留。迁移前应先确认新工具支持所需平台、共享方式和恢复机制。

## 小样本验证格式

先更新旧库并完成一次备份，再选十条代表性记录测试：普通登录、两步验证种子、附件、自定义字段、安全笔记和共享条目都要覆盖。比较导入后的 URL、用户名、备注、文件夹与时间字段。

正式迁移时在受信任设备离线操作。CSV 往往是明文且无法保存所有类型；若两端支持加密专用格式，应优先使用。不要把导出文件放进云盘、邮件附件或自动备份目录。

## 切换后逐项验收

检查条目总数只是第一步，还要随机登录关键账户、验证自动填充与移动端同步，并确认家庭或团队成员的共享权限。重复记录先保留一段观察期，不要在迁移当天批量删除。

确认新库稳定后，从旧工具退出其他会话、按计划取消订阅，并安全删除本机明文导出及回收站副本。最重要的账户可以逐步轮换密码。最后测试新工具的恢复码或紧急访问流程，并把恢复材料保存在与主密码不同的安全位置。
