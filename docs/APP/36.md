# 通知审计：把打断改造成有层级的信号

通知过多时，真正重要的提醒也会被忽略。与其逐个关闭，不如先用一周记录打断来源，再按“必须立即处理、稍后批量处理、无需出现”分层。

## 从系统设置开始

保留安全告警、行程变化、家人联系等时间敏感通知；邮件、社交动态和普通项目更新进入摘要或只显示角标；营销、重复渠道和无行动价值的信息直接关闭。

同一事件若同时从邮件、聊天和项目工具到达，只保留最靠近行动入口的一个渠道。群聊默认静音，通过关键词、提及或重要联系人例外提升优先级。

## 设计安静时段

设置工作专注、睡眠和个人时间模式，并只允许少量联系人或应用穿透。紧急联系人应知道真正紧急时的备用方式，不能把所有消息都设成例外。

每天安排一到两个批量处理窗口，避免关闭通知后又持续主动刷新。锁屏隐藏敏感预览，尤其是验证码、健康和工作内容。

一周后复盘漏掉的信息与无用打断：若某提醒经常被略过，关闭或改为摘要；若确实错过行动，再恢复最小必要渠道。目标不是零通知，而是每次出现都值得注意。
