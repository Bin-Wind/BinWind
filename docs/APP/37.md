# 快捷键体系：用少量高频动作建立肌肉记忆

一次背几十个快捷键通常不会提高效率。应从每天重复、鼠标路径长且结果明确的动作开始，每周只新增两三个。

## 建立跨应用骨架

先掌握查找、保存、切换标签页、关闭窗口、撤销与重做等通用动作，再学习编辑器、浏览器或设计工具里的领域操作。遇到冲突时优先保持常用应用一致，不必追求每个默认键都保留。

建立一张简短清单，按场景而不是应用罗列，例如：

- 导航：应用、窗口、标签页与工作区切换；
- 编辑：移动、选择、复制和格式化；
- 执行：搜索命令、运行、提交或导出；
- 恢复：撤销、重开关闭标签、查看历史。

把清单放在桌面或启动器里，使用一周后删除从未触发的条目。

## 自定义要可迁移

全局快捷键容易与应用和输入法冲突。修改后立即测试中英文输入、远程桌面和常用软件，并记录原键与新键。可导出的配置进入私有同步仓库，但不要同步包含令牌的设置文件。

统计效率时看是否减少上下文切换，而不是按下次数。难记、低频或容易误触的动作继续用菜单，让界面承担记忆成本。
