# 应用退出计划：在迁移前验证数据真正可带走

选择应用时不仅要看导入能力，还要确认退出路径。能点击“导出”不代表数据完整、格式开放或以后可以恢复。

## 做一次小规模往返测试

创建包含正文、附件、标签、日期、链接和非 ASCII 文件名的测试数据，导出后检查目录结构、编码、元数据和附件引用。再导入到空白环境或备用工具，验证搜索、排序和链接是否仍可用。

区分内容备份与账户备份：数据库快照可能只能由原应用恢复，PDF 适合阅读却不利于继续编辑。关键资料至少保留一种开放格式和原始附件。加密导出要记录解密方式，但密钥不要与备份放在同一处。

正式迁移前冻结或记录变更窗口，迁移后抽查数量、哈希和重点项目。旧账户先降级或只读保留，确认账单和自动续费状态，再按需要删除。每半年做一次导出演练，能在服务故障或政策变化前发现锁定风险。
