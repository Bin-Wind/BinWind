# 全局搜索工作流：先缩小范围再精确命中

文件、邮件和笔记越多，靠目录逐层翻找越慢。高效搜索来自稳定的关键词、范围过滤和结果复核，而不是记住每个文件的位置。

## 从唯一线索开始

先输入人名、项目代号、错误片段或少见短语，再加入日期、文件类型、发件人或所在应用等过滤条件。完全匹配无结果时逐步放宽，不要一开始堆很多同义词。常用查询保存为智能文件夹或搜索器别名。

命名时保留用户未来会搜索的词：主题、日期、对象和状态。OCR 能让扫描件可检索，但金额、编号和姓名应抽查；搜索命中只说明文本相似，不保证文件是最新版。

隐私敏感目录要确认是否进入云端索引、剪贴板历史和第三方启动器。定期检查无结果查询，从中改进命名与标签；若一个标签从未被用来检索，就不值得持续维护。
