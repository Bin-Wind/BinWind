# 应用更新前检查：版本、备份与回退条件

重要应用更新不应只看“有新版本”。先阅读官方发布说明，确认支持的操作系统、数据库或插件版本，并区分安全修复、功能升级和需要迁移的数据格式。

更新前记录当前版本、账号同步状态和关键扩展，完成一份可实际恢复的备份。云同步不是完整备份：误删和损坏也可能同步到所有设备。团队应用先在测试账号或次要设备验证登录、导入导出与核心工作流。

明确回退条件，例如启动失败、关键数据不可见或性能超过可接受阈值。若新版本会不可逆迁移数据，就保留旧版本可读的导出，并确认厂商是否支持降级，不能假设重新安装即可回到原状。

更新后核对版本号、数据数量、权限和后台同步，再观察一段时间。自动更新可以保留，但关键生产工具应安排维护窗口并保留变更记录。
