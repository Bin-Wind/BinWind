# 跨设备同步验收：区分上传完成与真正可用

本机显示“已同步”只说明客户端认为队列已清空，不代表另一台设备能正确读取。用一组带唯一名称的测试数据，分别覆盖新建、修改、删除、附件和离线冲突。

先在设备 A 完成修改并等待明确同步状态，再在设备 B 冷启动应用核对内容、时间和附件可打开性。随后让两台设备离线修改同一字段，恢复网络后观察产品是合并、保留两份还是覆盖，并确认历史记录能解释结果。

测试还应包含账号切换、设备时区不同、存储空间不足和应用被系统挂起。敏感内容要确认传输与本地存储保护符合需求，退出账号后缓存是否按产品承诺清理。

验收记录应用版本、设备、网络和时间，不用真实机密作为样本。若同步是核心工作流，应定期导出独立备份；同步提高便利性，但不等于长期归档。
