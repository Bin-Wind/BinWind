# 默认应用整理：让链接、文件与协议去正确入口

系统可能分别为网页、邮件、地图、PDF、图片和各种文档维护默认应用。只更改浏览器，不会自动改变其他文件与协议的打开方式。

先列出每天最常遇到的五类入口，从真实文件或链接测试当前行为。选择默认应用时看是否能完整处理格式、是否支持无障碍与离线需求，以及工作账号和个人账号是否会混用，不要只按启动速度判断。

更改后分别测试双击文件、应用内“打开”、网页深链接和分享菜单。部分应用会在更新后再次请求成为默认项，应阅读范围再确认。工作设备若受组织策略管理，不要用第三方工具强行覆盖。

保留一个稳定的备用查看器，用于主应用损坏或格式兼容问题。每次系统迁移后复查默认项，避免文件被意外上传到不合适的云服务或链接进入错误账号环境。
