# 浏览器扩展审计：从权限、更新来源到替代方案

扩展能读取网页、修改请求或访问剪贴板，权限往往比普通网站更持久。每季度做一次扩展审计，可以减少长期忘记的高权限组件。

## 建立清单

记录扩展名称、用途、安装来源、最后使用时间和权限。重点检查“读取和更改所有网站数据”、下载管理、代理、剪贴板以及无痕模式访问。一个扩展声称的用途与权限不匹配时，先禁用再调查。

查看发布者、官方主页、更新记录和最近更新时间，但不要仅凭商店评分判断安全。组织设备还要核对管理员强制安装策略，不能私自移除安全组件。

## 逐个收紧

浏览器支持时，将网站访问从“所有网站”改为“点击时”或指定域名。删除重复功能和长期未用扩展；能用书签、浏览器内置能力或一次性网页工具完成的任务，不必永久安装插件。

## 验证与恢复

移除前导出确有必要的配置，但不要留下包含令牌的明文备份。重启浏览器并验证登录、下载和开发工具等关键流程。若发现可疑跳转、广告注入或账号异常，除移除扩展外，还应在可信设备上撤销会话、更新凭证并检查同步到其他设备的扩展列表。

审计结果应写明保留理由和下次复查日期，让“暂时需要”不会变成永久授权。
