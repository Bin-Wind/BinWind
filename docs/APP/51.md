# 邮件导出验收：迁移前确认正文、附件与文件夹都可用

邮件客户端显示“导出完成”，不等于归档可恢复。不同格式对标签、文件夹、附件和联系人支持不同，迁移前应先做小样本恢复测试。

## 选择范围与格式

明确导出的是全部邮箱、指定文件夹，还是按日期截取。MBOX 常用于按邮箱保存邮件流，EML 更适合单封文件；联系人和日历通常需要另外导出。服务商专有格式要确认目标工具能否导入。

先清理垃圾箱不是必需步骤，但要记录导出时点、账号和包含范围。归档中可能含敏感信息，应保存到加密位置，不上传到未经批准的转换网站。

## 抽样验收

选择带大附件、非 ASCII 主题、长会话、不同日期和自定义文件夹的邮件。在隔离的测试配置中导入，核对发件人、收件人、时间、正文编码、附件可打开以及已读/星标状态。再搜索几个已知短语，确认索引之外的原始内容确实存在。

## 切换与保留

迁移期间记录最后同步时间，避免新到邮件遗漏。新系统使用一段时间后再按组织保留策略处理旧账号；不要因一次抽样成功立刻删除唯一来源。归档文件计算摘要，并至少保留一份独立备份和恢复说明。真正的完成标准是能在目标环境找到并打开需要的邮件。
