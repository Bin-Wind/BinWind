# 设备丢失响应清单：先锁定账号，再恢复工作环境

手机或电脑丢失时，焦虑容易导致遗漏。事先准备按顺序执行的清单，可以在不破坏取证和恢复机会的前提下快速止损。

## 先确认人身与物理安全

疑似被盗时不要独自追踪或前往陌生地点，按当地流程联系警方或场所管理方。使用厂商的“查找设备”服务标记丢失、显示联系信息并锁定设备。远程抹除是重要手段，但可能终止后续定位，应根据数据敏感度和组织政策决定。

## 处理账号入口

从可信设备修改主邮箱、密码管理器和单点登录等关键入口，撤销丢失设备会话与应用令牌。通知移动运营商处理 SIM/eSIM，防止短信验证码被接管。工作设备立即联系 IT 或安全团队，由其执行 MDM 锁定、证书撤销和事件记录。

## 恢复而不是盲目重建

确认备份时间和可用性，再配置替代设备。二次验证恢复码和备用硬件密钥应存放在另一地点，不能都在丢失设备上。恢复后检查登录历史、转发规则、支付记录和新建 API 密钥。

最后记录时间线、已撤销项目和仍待观察的账号。复盘设备加密、自动锁屏、通知预览和备份是否有效，并更新清单。不要公开设备序列号、恢复码或实时精确位置。
