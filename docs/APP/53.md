# 账户恢复演练：确认备用入口真的可用

设置备用邮箱、手机号或恢复码不等于能够恢复账户。号码停用、邮箱也被锁定、恢复码只存在原设备上，都会在真正丢失设备时形成闭环故障。

## 画出恢复链

从“主设备不可用”开始，列出每一步需要的设备、账号、验证码和人工审核材料。两个账号若互相作为唯一恢复邮箱，并没有提供独立路径。至少保留一种位于不同设备或地点、且不依赖主密码管理器解锁的恢复方式。

在服务允许的范围内执行演练：检查备用联系方式是否更新，确认恢复码能被找到且格式完整，但不要为了测试随意触发高风险锁定。企业账号应由管理员提供正式演练流程和紧急联系人。

## 安全保存证据

恢复码视同密码，只保存加密副本或离线纸质副本，不放进普通笔记、截图同步或邮件草稿。记录生成日期与剩余状态；使用一个后按服务规则重新生成或标记作废。

每半年以及换号、换机、离职或家庭角色变化后复查。演练记录只写“路径通过/失败”和待修复项，不抄录真实验证码、证件号或完整恢复码。
