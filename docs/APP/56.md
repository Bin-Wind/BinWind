# 浏览器配置文件隔离：把工作账号与个人账号分开

只开不同窗口不会隔离 Cookie、扩展和登录状态。浏览器配置文件拥有独立的站点数据、历史记录与扩展集合，更适合分开工作、个人和测试身份。

先创建用途明确的配置文件，使用不同主题色和头像降低误操作。工作配置只安装必要扩展，并按组织政策启用同步；个人密码、书签和支付资料不要导入受管理的工作配置。

外部链接可能默认打开到最近使用的配置文件。处理敏感操作前检查窗口标识、当前账号和地址栏域名，不依赖头像颜色作为唯一防线。需要同时登录管理员与普通用户测试时，为高权限账号再使用独立配置，而非无痕窗口长期代替隔离。

定期检查扩展权限、同步范围和不再使用的配置文件。删除配置前先导出确需保留的数据并确认同步状态；本地删除不一定会删除云端账号数据。配置文件隔离减少串号风险，但不能取代设备加密、系统账户和最小权限。
