# 应用通知权限盘点：按行动价值而不是数量清零

关闭所有通知会漏掉登录告警和日程提醒，全部保留又会让重要信号被促销淹没。盘点时应按“看到后是否需要行动、多久内行动”分类。

先查看系统通知设置与应用内设置，两处可能分别控制声音、角标、锁屏内容和通知类别。保留安全告警、即时协作和时间敏感提醒；摘要、推荐与营销可改为静默、定时汇总或关闭。

锁屏预览要考虑旁观泄露，工作消息和验证码可设置为解锁后显示。多个设备同时提醒时，只让最常用设备发声，其余保留静默记录。勿扰模式需配置允许来电与紧急联系人，并实际测试一次。

一周后复核误报与漏报：记录哪些通知促成了行动，哪些从未打开。新应用安装后及时调整默认权限。通知管理的目标是提高信号可见度，不是追求通知中心永久为空。
