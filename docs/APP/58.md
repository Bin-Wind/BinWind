# 删除云端账号前的导出清单：先验证能恢复的数据

“下载我的数据”按钮不代表导出内容完整或可再次使用。删除账号前，应先列出文件、照片、联系人、日历、购买记录和共享关系，再逐项确认导出范围。

启动导出后记录请求时间、格式、预计有效期和下载入口。下载完成先校验文件能解压、数量大致相符，并随机打开不同年份与类型的内容。专有格式要转换或保留可读取它的软件说明，附件与元数据也要检查。

共享给他人的文件可能随账号删除而失效，需要先转移所有权或另行交付；使用该账号登录的第三方服务应改绑独立凭据。订阅取消、账号停用和数据删除通常是不同动作，分别取得确认记录。

至少保存两份经过验证的备份，其中一份不依赖即将删除的账号。等待服务声明的恢复宽限期结束前，不要销毁唯一备份。最终再次登录确认无待处理账单、设备或恢复入口，再执行删除。
