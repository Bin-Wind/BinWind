# 离线模式验收：断网后不仅要能打开

应用首页能在飞行模式显示，不代表离线功能完整。验收应覆盖读取、编辑、排队、冲突和重新联网后的收敛过程。

## 建立场景矩阵

先记录哪些数据承诺离线可用、缓存多久、哪些操作必须联网。分别测试启动前断网、使用中断网、弱网超时和认证过期。离线时隐藏还是禁用功能要有一致规则，并明确最后同步时间，避免把旧数据显示成最新。

## 验证重连

离线编辑多条记录后，在另一设备修改同一对象，再恢复网络。观察队列是否按依赖顺序重放、重复点击是否幂等、冲突是否保留双方内容。上传失败要能重试或导出，不能永远卡在模糊的“同步中”。

最后强制退出并重启，确认待同步队列仍存在；再模拟服务器拒绝、配额耗尽和版本升级。离线模式的完成条件是用户知道哪些已经安全保存、哪些仍在设备上等待。
