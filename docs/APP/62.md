# 账号恢复演练：在真正丢失设备前验证备用路径

开启双重验证后，如果验证码只存在于同一部手机，手机丢失就可能同时失去密码管理器、邮箱和验证器。恢复方案必须在账号仍可用时配置并验证，而不是事故发生后临时寻找。

## 建立独立的恢复链

先查看服务官方安全设置，确认支持的恢复码、备用验证器、安全密钥或可信联系人。生成恢复码后放在与主设备分开的安全位置；不要截图后留在同一相册，也不要通过普通聊天发送。备用邮箱本身要有独立强密码和双重验证。

列一张最小清单：账号、主要验证方式、备用方式、恢复资料位置和最后验证日期。清单不记录完整密码或恢复码，只记录保管位置。对工作账号，还需确认管理员恢复流程和离职后的权限归属。

## 做一次不破坏账号的演练

使用无痕窗口或备用设备登录，确认密码可取得、第二因素可用，并验证恢复码页面能访问；不要在唯一已登录设备上贸然退出。若服务允许查看剩余恢复码，确认数量但不在日志中复制内容。

演练后撤销临时会话，检查登录通知，并更新日期。设备、手机号或团队成员变化时重新盘点。恢复能力和防攻击是同一设计的两面：备用路径足够可用，同时也要避免它成为绕过强验证的最弱入口。
