# 默认应用整理：按文件与链接类型逐项验证

安装新软件后，PDF、图片或网页链接可能被悄悄交给不合适的应用。一次性点击“设为默认”也未必覆盖所有格式：`.jpg`、`.png`、`mailto:` 和普通网页属于不同关联。

## 先做关联清单

列出常用类型及期望应用，例如网页、邮件、PDF、图片、音频、压缩包和代码文件。按操作系统的“默认应用”设置逐项修改，不使用来源不明的注册表脚本或所谓一键修复工具。工作设备受组织策略管理时，先确认是否允许更改。

修改后用一个不含隐私的测试文件验证双击行为，再从浏览器测试 `mailto:`、地图或会议链接。注意“打开方式”中的一次性选择和永久默认设置可能是两件事；安装更新后也可能再次询问。

## 保留安全边界

脚本、可执行文件和未知附件不应因为关联方便而自动运行。预览应用仍需及时更新，默认打开不等于文件可信。云盘占位文件还可能先触发下载，测试时留意网络和空间。

记录少量真正需要的关联即可，不要为了整齐修改每个罕见扩展名。每次安装大型办公或媒体软件后快速复核，比问题出现时逐个追查更省事。
