# 照片权限盘点：优先使用有限访问而非全量开放

很多应用只需上传一张头像，却请求读取整个照片库。现代移动系统通常支持“选择的照片”或系统照片选择器，让应用只接触用户明确选中的项目。

## 按任务授予最小范围

在系统隐私设置中查看拥有照片权限的应用，将不再使用的权限关闭；只需偶尔上传的应用优先改为有限访问。需要持续备份或整理相册的应用才可能合理需要全量权限，但仍应核对开发者、隐私说明和同步目的地。

有限访问后，应用可能无法看到新拍照片，需要再次选择，这是边界生效的正常结果。若应用反复要求全量权限，先确认核心功能是否真的依赖；拒绝后仍应能完成与相册无关的功能。

## 权限之外还有副本

撤销权限不会自动删除应用已上传到云端的照片，也不会清理聊天、缓存或共享相册中的副本。需要删除时分别检查应用账号数据、云端回收站与共享对象，并遵循平台保留规则。

每季度或在旅行、项目结束后盘点一次。工作照片与私人照片混用时，考虑使用受管理空间或专用账号。权限盘点的目标不是拒绝一切，而是让应用拿到完成当前任务所需的最小照片集合。
