# 主题阅读法：用一组书建立知识地图

主题阅读不是把同类书单从头读到尾，而是围绕一个问题，让多位作者相互对话。它适合概念复杂、观点分歧明显的领域。

## 从问题开始

把“我想了解心理学”改成可回答的问题，例如“习惯改变中，环境设计与意志力各起什么作用？”问题决定选书边界，也帮助你拒绝无关内容。

## 建立三层书目

第一层是综述或教材，用来获得术语与历史脉络；第二层选择立场不同的代表作；第三层加入案例、传记或批评作品。先读目录、序言、索引和结论，判断每本书能回答哪一部分，不必平均分配时间。

## 统一比较表

阅读时按同一组字段记录：

| 字段 | 要回答的问题 |
| --- | --- |
| 核心主张 | 作者到底认为是什么？ |
| 证据 | 数据、案例还是逻辑推演？ |
| 前提 | 哪些条件被默认成立？ |
| 反例 | 在什么情况下不适用？ |
| 关系 | 支持、补充还是反驳其他作者？ |

不要急着统一术语。不同作者使用同一个词时可能含义不同，也可能用不同词表达相近概念。先保留差异，再建立自己的对照定义。

## 形成输出

最终按问题组织文章，而不是按“第一本书、第二本书”写摘要。每个结论标明来自哪位作者、证据强弱和你的判断。仍无法回答的部分进入下一轮书目。主题阅读的成果应是一张可修订的知识地图，而非完成数量。
