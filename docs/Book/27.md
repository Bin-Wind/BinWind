# 非虚构阅读中的事实核验

非虚构作品也会选择材料、压缩因果并带入作者立场。核验不是默认作者撒谎，而是区分事实、解释和修辞，让自己的判断建立在可追踪证据上。

## 给陈述分类

阅读时把关键句分为：可查事实、数据结论、因果解释、价值判断和个人经历。个人经历可以真实，却不能自动代表总体；相关性数据也不能单独证明因果。

## 追到原始来源

先看注释与参考文献，找到原论文、官方统计、判决书或档案。核对标题、作者、年份与页码，确认二手引用没有截断限定条件。遇到百分比时至少追问：分母是什么、时间范围多长、样本如何选取、是否经通胀或人口调整。

## 交叉验证

优先寻找独立来源，而不是多个转载同一篇报道。对有争议主题，阅读立场不同但证据透明的分析。若只能找到作者自引或来源已失效，应把结论标记为待核，而不是补上一个听起来合理的解释。

## 核验笔记

```text
陈述：
书中页码：
来源类型：原始 / 二手 / 未提供
核验结果：支持 / 部分支持 / 冲突 / 无法确认
关键限定：
链接或文献标识：
```

把“事实是否准确”和“作者解释是否有说服力”分开评分。一本书可能事实扎实但解释单一，也可能叙事精彩却证据薄弱。明确不确定性，比仓促裁定真伪更可靠。
