# 弃读的判断：什么时候应该放下一本书

弃读不是阅读失败。注意力有限，把时间从不合适的书转向更有价值的材料，本身就是选择能力。关键是区分“暂时困难”与“目标不匹配”。

## 先问阅读目的

为了放松、解决问题、系统学习或参与讨论，容忍度并不相同。工具书只读相关章节很正常；经典作品若目标是理解其影响，可以先借助导读再决定是否继续。

## 设置检查点

给书一个明确试读额度，例如三章或六十页。到点后记录：我获得了什么、阻力来自内容还是状态、继续阅读的预期收益是什么。不要因已经投入时间而自动追加投入。

## 三种退出方式

永久弃读适用于内容失实或价值明显不足；暂缓适用于当前知识和精力不匹配；跳读适用于局部章节有用。记录退出原因和页码，未来重遇时无需从头判断。

阅读计划应允许空位。若每次弃读都立刻补入更多书，压力并不会减少。一本书没有在此刻服务你的问题，并不等于它毫无价值。
