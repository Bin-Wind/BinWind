# 引文笔记：保留原文、出处与自己的判断

只收藏一句漂亮的话，几个月后往往不知道它在回应什么。可复用的引文笔记应同时保存原文、定位、上下文和你的解释。

## 最小模板

```text
原文：保持必要长度，不截断关键限定词
出处：作者、书名、版本、章节、页码或电子位置
上下文：作者正在回答什么问题
我的理解：这句话为何重要
用途：可能支持或反驳哪个主题
```

直接摘录使用引号并保持原貌；删节要明确标记。自己的转述与原文分开，避免日后把记忆中的改写误当成作者原话。

## 纸书与电子书

纸书记录版次和页码；电子书位置可能随字号变化，可补充章节名与段落开头。引用译著时同时记录译者。准备公开发表前，回到原书核对文字、语境和版权使用边界。

## 从收藏到使用

定期按问题而非书名整理引文。把相互支持和冲突的片段并排，写下自己的判断。引文是证据，不是结论；没有上下文的名句不应替代论证。
