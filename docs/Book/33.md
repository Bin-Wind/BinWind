# 人物索引卡：读懂多人物与多时间线小说

家族史、史诗和侦探小说常在别名、亲属关系与时间跳转中制造阅读负担。人物索引卡的目标是减少查找，不是提前把人物命运剧透给自己。

## 只记已知事实

每张卡写首次出现页、称呼与别名、当前关系、关键物件和最近状态。推测用问号标记，与文本明确事实分开。人物死亡、身份反转等信息只在读到后补充。

关系复杂时画小型关系图：人物为节点，连线写“兄妹”“雇佣”“怀疑”等动词，并在关系变化处标页码。多时间线作品另建事件表，用“故事内日期—章节—事件”排列，不要按叙述出现顺序误当真实顺序。

## 保持轻量

只为反复出现或容易混淆的人建卡，路人角色留在章节边注。每读完一部分用两分钟更新，若整理时间超过阅读时间，就删掉不帮助理解的字段。

读完全书后再用索引回看伏笔和叙述误导。此时把“当时的推测”和“最终事实”并列保留，会比一张事后全知视角的完美关系图更有分析价值。
