# 有声书主动阅读：在通勤中留下可用记忆

有声书适合通勤、步行和家务，但注意力会被环境切走。主动阅读不是频繁暂停做完整笔记，而是建立低摩擦的标记与回顾闭环。

## 选择合适内容

情节清晰、论述线性或已经读过的书更适合音频；包含大量公式、图表和频繁脚注的作品优先看纸面。先试听旁白速度、角色区分和音质，不合适的演播会显著增加理解成本。

## 三步留痕

听到关键处只做书签并录一句自己的提示，例如“第三章：作者把习惯分成触发与反馈”。每次结束后口头复述一个观点或一段情节；当天再从书签中挑最多三条写进笔记。保留章节与时间戳，方便回听上下文。

播放速度以能复述为准，而不是越快越好。陌生概念、密集论证和人物初次登场时主动降速；重复材料可以加速。

一周后不看笔记尝试说出核心内容，再决定哪些值得重听或转读文本。记不住并不一定是注意力差，也可能说明这本书不适合纯音频媒介。
