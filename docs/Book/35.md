# 索引式阅读：用书后的关键词地图回查论证

非虚构书的索引不是装饰，它展示作者如何命名概念、人物与事件。阅读前浏览索引，能快速判断一本书覆盖什么，也能在写作时精确回到相关页。

## 从问题反查条目

先把自己的问题写成三到五个关键词，再查看索引中的主条目、同义词和“参见”关系。记录相关页码，但不要只摘一句话；至少回读所在小节，确认作者是在主张、引用、反驳还是举例。

一个实用记录格式是：

- 关键词与页码；
- 本段在全书论证中的作用；
- 直接证据或来源注释；
- 自己的问题与反例；
- 需要交叉核验的另一条目。

同一概念在相隔很远的章节反复出现时，把页码排成序列，观察定义是否变化。这比线性重读整本书更容易发现论证结构。

## 识别索引的边界

不是所有版本都有同样页码，电子书位置码也可能不同。引用时保留作者、书名、译者、版次与章节信息，不能只留页码。

索引由作者或编者选择，遗漏不等于书中没有。文学作品、短篇合集或没有专业索引的书，可自己建立人物、意象和主题卡片。索引式阅读服务于回查，第一次阅读仍需理解上下文。
