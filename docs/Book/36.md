# 阅读疲劳恢复：在注意力下降时调整任务难度

连续读不进去，不一定是意志力不足。睡眠、环境、材料难度和阅读目标不匹配，都会让注意力迅速耗尽。恢复的第一步是分清原因。

## 做一次小诊断

读十分钟后合上书，用两句话复述。如果无法复述，检查生词密度、背景知识和论证跳跃；如果能复述却不愿继续，可能是主题价值不足或当前精力不合适。

按状态切换阅读模式：

- 精力高：读理论密集章节，做结构笔记；
- 精力中：读叙事性材料，只标关键页；
- 精力低：回顾旧笔记、有声书重听或整理书单。

把目标从“读 50 页”改为“理解一个小节并写一句问题”。20～30 分钟后休息，离开屏幕和座位，让注意力真正切换。

## 允许降级与弃读

难书可先读导论、目录和可靠的背景材料，再回到原文。若一本书连续多次没有回答你的问题，把放弃原因和已读章节记下，未来需要时仍可回查。

长期疲劳要优先处理睡眠、视力和身体状态；持续不适应寻求专业帮助。阅读计划应随生活容量变化，保持稳定关系比完成数字更重要。
