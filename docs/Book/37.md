# 版本信息卡：让引文在多年后仍能定位

只记一句摘抄和页码，换版本后往往找不到原文。为每本书建立版本信息卡，可以区分原作、译本、修订版和电子版定位差异。

## 保存最小书目信息

纸书记录作者、完整书名、译者或编者、出版社、出版年份、版次与 ISBN；电子书再记录文件版本、章节和位置码类型。有 DOI 的学术著作可一并保存。

摘录建议同时保留：

- 原文与前后必要语境；
- 章节标题和页码或位置；
- 摘录日期；
- 自己的转述与用途；
- 原文、转引或译文标记。

看到“作者 A 引用作者 B”时，若没查到 B 的原始来源，就明确标为转引，不能让笔记看起来像直接阅读过原作。

## 比较译本而不只比一句话

译本差异要结合目标：学术使用重术语一致与注释，文学阅读还要看节奏、语气和删节情况。选取同一段与目录、译者序、注释体系一起比较。

文件名可采用“作者-短书名-译者-年份”，但 ISBN 等完整信息放在卡片字段中。定期导出为开放格式，确保即使更换笔记软件，引文仍可独立理解和定位。
