# 反向提纲：读完一章后还原作者的论证骨架

划线容易积累句子，却未必理解它们如何组成论证。反向提纲是在读完后用自己的话写出每一节“做了什么”，再连接成整章结构。

## 每段只回答一个功能问题

标记背景、问题、主张、证据、反例、限定和结论。随后把相邻段落压缩成一两句，检查是否出现没有证据的跳跃，或同一概念在不同位置改变含义。

不要边读边完整重写，那会打断理解并诱发抄录。先完成一个自然小节，再合上书回忆主线；想不起来的地方才回看。文学作品也能使用反向提纲，但关注点变为视角、时间、冲突和意象变化，而非证明步骤。

最后写下“作者最强的证据是什么”“结论在哪些条件下成立”“我仍不同意什么”。提纲不求覆盖所有细节，它的价值是让你能检验并复述结构，而不是拥有更长的摘要。
