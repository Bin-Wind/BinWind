# 难书预读：先建立地图再进入正文

面对术语密集或结构复杂的书，从第一页逐字硬读容易在局部迷失。预读不是跳过内容，而是先建立问题、结构和阅读优先级。

## 用三十分钟扫描外围信息

阅读封面说明、目录、序言、章节开头与结尾，再查看索引中反复出现的概念。写下作者试图回答的问题、各章可能承担的作用，以及自己最关心的两三个问题。二手导读可提供背景，但要与原书观点分开记录。

第一遍以抓主张和概念关系为目标，暂时标记不懂的细节；第二遍只回到关键章节查定义、证据和反例。每遇到术语先根据上下文尝试解释，再查作者是否给出特殊定义，避免把日常含义直接套入。

预读后也可能发现该书不适合当前目标。此时可只读相关章节、寻找更基础的入门材料或暂缓阅读。合理调整难度不是失败，而是在保护后续理解质量。
