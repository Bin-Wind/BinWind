# 跨书概念表：比较相同词语背后的不同定义

主题阅读中，不同作者常用同一个词表达不同概念，也可能用不同术语描述相近现象。直接把摘录堆在一起，会制造表面共识。

## 每一行都能回到原文

建立包含作者、书名版本、术语、原文定义、自己的转述、例子、适用范围和页码的表格。没有明确下定义时标为“根据语境推断”，不要把自己的概括伪装成作者原话。

比较时先问：分析层级是否相同？对象、时间尺度和价值判断是否一致？两个结论冲突，可能只是前提不同。为每组概念写一个最小反例，检验你是否把定义理解得过宽。

最终输出不是术语大全，而是一张能回答研究问题的关系图：哪些观点互补、哪些真正矛盾、哪些缺乏可比性。新增书籍时更新现有概念行，而不是再建一套孤立笔记。
