# 版本与译本比较：先确认文本差异再评价表达

比较两本“同名书”前，先核对原著版本、出版年份、译者、删节情况和所依据的底本。新版可能增加序言、修订数据或改变章节，差异不一定来自翻译水平。

选取术语密集段、叙事段和容易产生歧义的段落各一处，逐句对照。记录关键词如何处理、指代是否清楚、语气是否保留，并回到原文或可靠注释确认，不能只凭“更顺口”判断准确性。

评价时区分目标：研究用途重视版本可追溯和术语稳定，通读可能更重视流畅与注释负担。不要用单个精彩或生硬句子代表整本书，也不要忽略编辑、校对和排版对阅读的影响。

最终保存书目信息和样段页码，写明自己的用途与取舍。这样结论是“哪一版更适合这次阅读”，而不是制造脱离场景的绝对排名。
