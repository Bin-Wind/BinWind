# 书目初筛：用目录、索引与参考文献判断是否值得精读

主题阅读面对几十本候选书时，逐本从第一页读起成本很高。初筛的目标不是提前评价整本书，而是判断它能否回答当前问题、提供何种证据，以及值得投入多少时间。

## 十五分钟扫描

先读版权页确认版本与出版时间，再看目录理解结构。阅读序言或导论，写下作者的问题、范围和方法。翻到结论检查实际回答，再用索引查找自己的三个关键词，看它们是核心章节还是偶然出现。

学术或非虚构作品可抽查参考文献：来源是否可追溯，是否覆盖关键争论与近年研究。大众写作没有长书目并不自动不可靠，但关键事实应能找到出处。

## 记录一个初筛卡

卡片只写当前问题、可能有用的章节、证据类型、明显局限和下一步。结论限定为“对本次任务的价值”，不要把未精读的印象写成完整书评。

## 决定阅读深度

将候选分为精读、选读、查阅和暂缓。精读用于核心论证，选读只覆盖相关章节，查阅作为定义或数据来源。不同立场至少保留一项强代表作，避免初筛只留下符合预期的材料。

读完第一章后重新评估分类。初筛是资源分配工具，不是永久判决；研究问题变化时，同一本书的价值也会变化。
