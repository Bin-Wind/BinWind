# 边注迁移：换版本后保留思考而不是照搬页码

重读同一本书的新版、译本或电子版时，旧边注的页码常常失效。有效迁移应以文本锚点和问题为核心，而不是把每条划线机械复制。

## 建立可定位锚点

每条重要笔记保留章节标题、段落开头的短语、版本信息和原页码。短语只用于个人定位，不要在公开笔记中大段复制受版权保护的原文。电子书位置号也应附章节，因为设备或排版变化可能改变位置。

## 三类处理

仍支持当前问题的笔记迁移到新位置；已被新证据修正的笔记保留旧判断并追加日期与变化原因；只有情绪反应、无法解释用途的划线可以不迁移。迁移是一次筛选，不是保存数量竞赛。

## 比较版本差异

译本变化时并排查看关键术语，记录译者选择，不急于判定谁“更准确”。增删章节、前言作者和注释体系也属于版本差异。引用时使用实际阅读版本的页码和书目信息，不能拿旧版页码配新版文字。

完成后抽查十条锚点，确认别人拿到同一版本也能定位。把无法定位的笔记放入待核验区，不要凭记忆补原文。这样多年后的重读仍能看见观点如何变化。
