# 反驳性阅读：主动寻找能推翻作者结论的证据

认同一本书时，读者容易只收集支持句；不认同时，又可能只挑语气问题。反驳性阅读要求先准确重述作者最强论证，再寻找真正会改变结论的反例。

## 先写可检验主张

把一章压缩成“在条件 C 下，因为证据 E，所以结论 P”。区分描述事实、因果解释和价值判断。若无法写出作者可能认可的版本，说明还没有理解到可以反驳的程度。

接着列出结论成立需要的隐含假设，例如样本具有代表性、指标能测到目标、替代解释较弱。为每个假设寻找书内反证、作者引用的原始研究，以及立场不同但可信的来源。

## 记录什么会改变判断

反例不等于个案。写清它攻击的是普遍性、因果机制还是适用边界，并说明需要多强的证据才会调整自己的看法。若作者已限定范围，就不能拿范围外案例当作直接推翻。

最后给主张标记“保留、缩小、修正或拒绝”，同时记录不确定性。目标不是赢过作者，而是让自己的相信程度对证据敏感；找不到反证时，也不等于主张已经被证明。
