# 章节问题闭环：读前提问，读后用页码回答

带着问题阅读能提高注意力，但问题若从不回收，也只是在页边堆积问号。问题闭环把每个问题关联到答案、证据位置和仍未解决的部分。

## 三种问题

读前根据目录提出结构问题：本章要解释什么、与前章如何连接。阅读中记录澄清问题：术语如何定义、例子支持哪条主张。读后再提出迁移问题：结论在另一个场景是否成立。

每个问题只写一句，并标记状态：已回答、部分回答、书内无答、需要外部核验。答案用自己的话概括，附章节和页码作为定位；公开笔记避免大段复制受版权保护的文字。

## 限制问题数量

每章保留三到五个真正影响理解的问题。事实型小疑问可集中查证，不要让即时搜索切断整段阅读。章节结束后先凭记忆回答，再回书核对，能区分“看过”与“已经理解”。

全书读完后，将反复出现的未决问题合并，作为书评、讨论或下一本书的入口。若问题永远没有答案，记录缺失原因，而不是凭作者声望自动补全。
