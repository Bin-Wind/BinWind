# 阅读证据等级：区分作者主张、转述与原始材料

非虚构作品常把访谈、统计、历史档案和他人研究写进同一段叙事。阅读时若不区分证据层级，容易把作者的解释误记成已经证实的事实。

## 给笔记标明来源角色

使用简单标签：`A` 表示作者主张，`P` 表示书中引用的一手材料，`S` 表示二手研究，`R` 表示读者自己的推论。标签不是质量评分，而是提醒这句话来自哪里、应该去哪里核验。

查看脚注是否真的支持正文：来源可能只证明时间点，却没有证明因果；二手转引还可能省略限定条件。重要结论尽量追到原始出版物，记录版本、页码、表格编号和访问日期。

## 评估而不武断排名

一手材料可能有偏见，统计研究也可能口径不合。结合来源与事件的距离、样本选择、测量方法、利益关系和能否被独立复核判断。文学、回忆录与学术著作的证据标准不同，不应用同一把尺子粗暴打分。

写书评时明确“作者认为”“受访者回忆”或“数据显示”，避免把层级抹平。若原始材料不可得，就保留未核验标记，而不是因为引用链很长就假定可靠。
