# 术语表阅读：先统一作者的词义再讨论观点

同一个词在不同作者手中可能有不同边界。直接用日常含义阅读专业著作，容易把定义分歧误认为事实冲突。

开始时从前言、术语表和首次定义处摘录核心词，记录原文页码、作者给出的正例与反例。用自己的话写一句工作定义，再标出它与常见用法的差别。不要只抄一句加粗定义，后续章节可能继续修正范围。

阅读中遇到同词多义，用符号区分，例如“模型₁=理论表示”“模型₂=可运行算法”。作者换词表达同一概念时也建立别名，避免把措辞变化误判成新主张。

完成一章后用术语关系图复述论证：哪些是上位概念、哪些互斥、哪些只是相关。讨论或写作时先声明采用哪位作者、哪一版的定义。术语表不是背诵清单，而是让争论落在同一语义边界上的工具。
