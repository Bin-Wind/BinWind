# 引文上下文核对：避免一句话脱离作者论证

一句醒目的引文可能是作者在转述对手、提出疑问，甚至随后就被反驳。引用前至少阅读它所在段落、前后页与章节结论。

记录引文时同时保存作者、书名、版本、页码、章节和用途，并写一句“这句话在论证中承担什么角色”。区分作者本人主张、引用他人、例子、假设和讽刺语气。电子书位置号会随排版变化，能取得页码时优先记录版本对应页码。

若二手文章引用一本无法取得的书，不要把二手转述伪装成亲自核对的原文。应明确写“转引自”，并尽力找到原版。翻译引文还要核对译者与版本，自译时注明。

成稿后反向检查：删除引号外的解释，读者是否会得到与原章节相反的印象？若会，就补充限定、改为转述或放弃这条引文。准确引用的目标是忠实呈现论证，不是借名句增强权威感。
