# 章节摘要压缩：从一页笔记提炼到三句话

笔记越长不等于理解越深。压缩练习迫使读者区分核心主张、关键证据和适用边界，而不是按顺序复述每个段落。

读完一章先合上书，写一页自由回忆，再回书中用页码补正。随后压缩成三句话：作者要回答什么问题；用什么主要理由作答；结论在哪些条件下成立。例子只有在不可替代时才进入三句话。

再写一个能推翻或削弱结论的反例，并标注作者是否已回应。若无法压缩，通常是章节包含多个子论证，可先画树状结构，再分别总结。若压缩后只剩空泛口号，则需要补回机制或证据。

隔一周只看三句话，尝试重建论证，再用原书核对遗漏。最终摘要旁保留版本与页码，使它既适合复习，也能追溯证据。压缩不是丢弃细节，而是建立通往细节的索引。
