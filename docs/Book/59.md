# 因果主张阅读：从相关性追问到替代解释

看到“X 导致 Y”时，先把作者真正声称的因果方向写成一句话，并标出证据来自实验、自然实验、观察数据还是个案。不同证据能排除的替代解释并不相同。

## 画一张最小因果图

列出 X、Y，以及可能同时影响二者的第三因素。例如阅读时间与成绩相关，既可能是练习产生作用，也可能由已有能力、家庭资源或选课差异共同驱动。再问作者如何处理反向因果、样本选择和测量误差。

## 区分三个问题

第一，样本内是否存在差异；第二，这个差异能否归因于 X；第三，结论能否推广到其他人群和时间。统计显著不能自动回答后两问。记录效应大小、置信区间和实际意义，不只摘抄“有影响”。

读完后用表格写下主张、识别策略、关键假设、替代解释和需要的新证据。目标不是逢因果必反对，而是清楚知道结论依赖哪些可检验条件。
