# 脚注追踪：判断论据来自原始材料还是层层转述

脚注不只是补充阅读清单，也是论证的证据链。遇到关键数字、引语或历史判断时，沿注释追到作者实际使用的来源，能发现转述是否改变了限定条件。

## 给来源分层

先区分原始材料、同行研究、综述、新闻与另一位作者的转述。记录页码、版本和作者声称该来源支持什么。若脚注只指向整本书，使用索引或电子检索定位相关段落，不要把“列入参考文献”当成已提供证据。

## 核对上下文

查看引文前后段落、数据口径和研究对象，确认原作者是在支持、质疑还是仅讨论该观点。遇到“转引自”时把两层都记下；找不到原文则明确标注未核验，而不是悄悄把二手材料升级为一手证据。

不必追踪每一条脚注。优先选择支撑核心结论、看起来反常或被多次引用的证据。最终形成一张短证据表，比堆积几十个链接更能帮助复盘。
