# 跨作者概念对照：先对齐定义，再比较立场

两位作者使用同一个词，可能指不同范围；使用不同词，也可能讨论同一机制。直接比较结论容易制造假冲突，先做概念对照更可靠。

## 建立对照表

为每位作者分别记录术语原文、明确定义、典型例子、反例和它在论证中的作用。不要急着用自己的统一定义覆盖原文。若定义散落在多章，保留页码并注明是否为你的归纳。

## 在同一问题上测试

选择一个具体案例，分别用两套概念解释：各自关注什么、忽略什么、会提出怎样的行动建议。这样能区分真正的理论分歧、研究尺度差异和只是命名不同。

最后写三段结论：共同前提、不可兼容之处、可以互补的部分。对照的目标不是选出赢家，而是避免把词语相似当成观点相同，也避免把词语不同误判为完全对立。
