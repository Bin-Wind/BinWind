# 论证地图：把结论、理由与反例画在同一页

长篇论述容易让读者记住例子，却忘了例子究竟支持哪个结论。论证地图把作者的主张拆成节点和关系，帮助区分“作者说了什么”与“为什么应相信”。

## 从一个句子开始

先写出本章最核心、可以被反驳的结论。它不应只是主题词，例如“教育”，而应是完整命题。随后为每条直接理由建立节点，并标明它是支持、反对，还是限制结论适用范围。

证据与理由分开：统计数据、案例和引文是证据；“这些证据为何能推出结论”才是推理桥梁。作者回应的反例也放入地图，连接到被它挑战的具体理由，不要统一堆在“反方观点”角落。

```text
主结论
├─ 支持理由 A
│  ├─ 数据证据
│  └─ 隐含前提
├─ 支持理由 B
└─ 反例 C
   └─ 作者的限制条件
```

## 用地图发现缺口

检查每个大结论是否有支撑、证据是否只证明相关性、隐含前提是否合理，以及反例是否真的被回答。地图不是要把所有句子抄一遍；保留会改变结论可信度的节点即可。

完成后用地图写一段中立摘要，再写自己的判断。若你不同意作者，指出断裂的具体连接，而不是只说“观点偏颇”。这会让批评更可检验，也更容易与其他书的论证对照。
