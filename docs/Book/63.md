# 数字主张复算：检查分母、单位与时间窗口

书中出现“增长 50%”时，数字看似精确，却可能遗漏基数、样本和时间范围。复算不是怀疑所有数字，而是把一个有说服力的表达还原成可验证的计算。

## 先抄完整主张

记录原句、页码、数据来源与上下文，然后问四个问题：分子是什么、分母是什么、单位是什么、起止时间是什么。增长从 2 到 3 是 50%，但绝对增加只有 1；风险从万分之二到万分之三也是相对增加 50%。

百分比与百分点不能互换。比例从 20% 上升到 25%，是增加 5 个百分点，相对增长 25%。均值还可能被极端值拉动，若原始来源提供中位数或分布，应一并查看。

## 建一个最小复算表

表格至少包含原始值、换算公式、结果和来源版本。统一币种与价格基准时注明汇率日期和是否考虑通胀；跨地区比较人口数据时确认是总量还是人均。

复算结果不同，不要立刻判断作者造假。差异可能来自修订数据、四舍五入、不同时间窗口或口径。回到脚注和原始报告，写明你能复现的口径与仍不确定的地方。数字阅读的重点是理解结论对口径有多敏感，而不只是验证计算器能否得到同一个小数。
