# 版本差异阅读：序言、注释与修订记录都算证据

同一本书的初版、修订版和不同译本可能并非只有封面变化。作者会补充案例、撤回断言，译者会改变术语，编辑也可能重排章节。引用或比较观点前，应先确认手中是哪一版。

## 建立版本身份

记录书名、作者、译者、出版社、出版年份、版次与 ISBN。电子书还要记录平台和更新日期，因为页面编号与内容可能动态变化。优先阅读新版序言、译者说明、修订说明和注释政策，它们会解释为何变动。

选择与你研究问题有关的章节做对照，不必逐字扫描全书。把差异分为事实更新、论证调整、术语翻译、结构重排和排版修正。新增段落要看它是否改变原结论，删除内容也可能表明作者后来收窄了主张。

## 引用时让读者能找到

引用必须指向实际阅读的版本。若讨论观点演变，同时给出两个版本及对应页码或章节；电子书位置不稳定时补充章节标题和段落开头。二手引文若无法确认版本，应明确标注而不是伪装成已核对原文。

版本差异不是噪声，它揭示知识如何被修订。尤其在技术、法律和历史材料中，新版不一定自动更适合研究：初版可能更接近当时语境，修订版则反映后来证据。选择版本应服务于问题，而不是只选最新封面。
