# CompletableFuture 异步编排与异常处理

`CompletableFuture` 适合组合相互独立的异步任务。难点不在启动任务，而在明确执行器、超时、失败传播与结果合并。

## 并行获取并合并

```java
import java.util.concurrent.*;

public class FutureDemo {
    public static void main(String[] args) {
        ExecutorService pool = Executors.newFixedThreadPool(4);
        try {
            var user = CompletableFuture.supplyAsync(() -> "Ada", pool);
            var score = CompletableFuture.supplyAsync(() -> 98, pool);

            String result = user.thenCombine(score, (name, value) -> name + ": " + value)
                .orTimeout(2, TimeUnit.SECONDS)
                .exceptionally(error -> "fallback: " + error.getClass().getSimpleName())
                .join();

            System.out.println(result);
        } finally {
            pool.shutdown();
        }
    }
}
```

`thenApply` 转换单个结果；`thenCompose` 串联返回 Future 的异步步骤；`thenCombine` 合并两个互不依赖的结果。

## 选择执行器

不传执行器时，`supplyAsync` 默认使用公共 ForkJoinPool。服务端项目最好为不同工作负载提供有界执行器，避免一个慢接口拖垮全部异步任务。CPU 与阻塞 I/O 不应混用同一池。

## 异常语义

`exceptionally` 用于恢复，`whenComplete` 适合记录结果但不改变它，`handle` 同时转换成功和失败。调用 `join()` 会把异常包装为未检查异常，`get()` 则抛出受检异常。

超时完成不一定会中断底层 I/O；客户端本身仍需设置连接与读取超时。异步编排的完成标准不仅是主流程返回，还包括被取消任务能释放资源。
