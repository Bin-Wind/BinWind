# Java try-with-resources：自动关闭资源

实现 `AutoCloseable` 的对象可以放进 try-with-resources。无论代码正常结束还是抛出异常，资源都会按声明的相反顺序关闭。

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;

public class ReadFirstLine {
    public static void main(String[] args) throws IOException {
        Path path = Path.of("demo.txt");
        try (BufferedReader reader = Files.newBufferedReader(path)) {
            System.out.println(reader.readLine());
        }
    }
}
```

相比在 `finally` 中手工关闭，它能正确保留主体异常。如果关闭资源时又发生异常，后者会成为 suppressed exception，可通过 `getSuppressed()` 查看。

自定义资源只需实现接口：

```java
final class Timer implements AutoCloseable {
    private final long start = System.nanoTime();
    public void close() {
        System.out.println("elapsed ns: " + (System.nanoTime() - start));
    }
}
```

`close()` 应可安全调用并尽量快速完成。资源有依赖时，后声明依赖者，使它在关闭阶段先退出。
