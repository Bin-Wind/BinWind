# Java Optional：表达可能缺失的返回值

`Optional<T>` 适合用作方法返回值，明确告诉调用方结果可能不存在。它不应替代所有 `null`，也通常不适合作为实体字段或方法参数。

```java
import java.util.List;
import java.util.Optional;

public class OptionalDemo {
    static Optional<String> findEmail(List<String> rows, String user) {
        return rows.stream()
                .filter(row -> row.startsWith(user + ":"))
                .map(row -> row.substring(row.indexOf(':') + 1))
                .findFirst();
    }

    public static void main(String[] args) {
        var rows = List.of("alice:a@example.com", "bob:b@example.com");
        String email = findEmail(rows, "alice")
                .orElseThrow(() -> new IllegalArgumentException("user not found"));
        System.out.println(email);
    }
}
```

有廉价默认值用 `orElse`；默认值计算昂贵用惰性的 `orElseGet`；缺失属于业务错误时用 `orElseThrow`。用 `map` 转换存在的值，用 `flatMap` 避免嵌套。

不要调用 `isPresent()` 后立刻 `get()`。集合没有结果时返回空集合通常比 `Optional<List<T>>` 更清楚。
