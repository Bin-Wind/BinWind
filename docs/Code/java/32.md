# Java equals 与 hashCode：让值对象在集合中行为一致

`HashSet` 和 `HashMap` 先用哈希值定位，再用相等性确认。如果两个对象 `equals` 为真却有不同 `hashCode`，集合查询会出现难以理解的结果。

不可变值对象可以直接使用 `record`：

```java
import java.util.HashSet;
import java.util.Set;

record Email(String value) {
    Email {
        value = value.trim().toLowerCase();
        if (!value.contains("@")) throw new IllegalArgumentException("invalid email");
    }
}

class Main {
    public static void main(String[] args) {
        Set<Email> emails = new HashSet<>();
        emails.add(new Email("USER@example.com"));
        System.out.println(emails.contains(new Email("user@example.com")));
    }
}
```

普通类重写时应使用相同字段实现 `equals` 与 `hashCode`，并保证对称、传递和稳定。不要把会变化的字段作为哈希键的一部分：对象入集合后字段变化，它可能再也无法被正确找到。

实体对象若以数据库编号判断身份，要明确“尚未持久化时”的相等策略；不要让两个编号都为 `null` 的新实体自动相等。
