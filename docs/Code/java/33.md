# Java ExecutorService：有界并发与可靠关闭

线程池能复用线程，但无界任务队列会在生产速度超过消费速度时吃光内存。明确线程数、队列容量和拒绝策略，才能形成背压。

```java
import java.time.Duration;
import java.util.concurrent.*;

class Main {
    public static void main(String[] args) throws InterruptedException {
        ThreadPoolExecutor pool = new ThreadPoolExecutor(
            4, 4, 0L, TimeUnit.MILLISECONDS,
            new ArrayBlockingQueue<>(100),
            new ThreadPoolExecutor.CallerRunsPolicy()
        );
        try {
            for (int i = 0; i < 20; i++) {
                int id = i;
                pool.submit(() -> System.out.println(id));
            }
        } finally {
            pool.shutdown();
            if (!pool.awaitTermination(Duration.ofSeconds(5))) pool.shutdownNow();
        }
    }
}
```

`CallerRunsPolicy` 让提交者亲自执行溢出任务，从而减慢上游；它不一定适合事件循环线程，因此要按架构选择。任务内部应正确处理中断，并为外部调用设置超时。

关闭流程先停止接收新任务，再等待已提交任务，最后才尝试中断。监控活动线程、队列长度、拒绝次数和任务耗时，不能只看线程池是否“还活着”。
