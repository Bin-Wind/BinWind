# Java HttpClient：超时、状态码与响应体处理

JDK 自带的 `HttpClient` 足以完成常见 HTTP 调用。可靠客户端必须区分连接超时、请求超时和非 2xx 响应。

```java
import java.net.URI;
import java.net.http.*;
import java.time.Duration;

class Main {
    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newBuilder()
            .connectTimeout(Duration.ofSeconds(3)).build();
        HttpRequest request = HttpRequest.newBuilder(URI.create("https://example.com/"))
            .timeout(Duration.ofSeconds(5))
            .header("Accept", "text/html")
            .GET().build();
        HttpResponse<String> response = client.send(
            request, HttpResponse.BodyHandlers.ofString());
        if (response.statusCode() / 100 != 2) {
            throw new IllegalStateException("HTTP " + response.statusCode());
        }
        System.out.println(response.body().length());
    }
}
```

客户端应复用以共享连接池。大响应不要总用 `ofString()`，可改用文件或输入流处理器并限制可接受大小。异步接口返回 `CompletableFuture`，仍要处理超时、取消和异常。

自动重试只针对明确的暂时错误，并限制次数；POST 等写操作需要幂等保障。日志可记录主机、路径模板、状态码和耗时，避免记录认证头与敏感查询参数。
