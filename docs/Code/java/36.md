# ConcurrentHashMap.computeIfAbsent：并发缓存的边界

`computeIfAbsent` 能把“没有就创建”合为一次按键原子操作，避免普通 `HashMap` 在并发下损坏，也减少重复的检查逻辑。

```java
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.ConcurrentMap;

public class WordIndex {
    private final ConcurrentMap<String, String> normalized = new ConcurrentHashMap<>();

    public String normalize(String input) {
        return normalized.computeIfAbsent(input, key ->
            key.strip().toLowerCase(java.util.Locale.ROOT)
        );
    }
}
```

映射函数应短小、无副作用且不能返回 `null`。它可能因异常或并发竞争再次执行，因此不要在里面扣款、发消息或做无法重复的写操作。计算期间也不要递归修改同一个键。

对于慢速网络加载，直接在映射函数中阻塞会让该键相关操作等待。可缓存 `CompletableFuture`，但失败的 Future 必须按策略移除，否则一次暂时故障会被永久缓存。

`ConcurrentHashMap` 没有容量和过期机制。数据集合无限增长时应使用成熟的有界缓存库，并明确最大条目、过期、失败和监控策略。
