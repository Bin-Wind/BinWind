# Java BigDecimal：正确表示和计算金额

`double` 采用二进制浮点，很多十进制小数无法精确表示。金额计算应使用 `BigDecimal`，并把币种、舍入和最小单位写进业务规则。

```java
import java.math.BigDecimal;
import java.math.RoundingMode;

public class Invoice {
    static BigDecimal total(String unitPrice, int quantity, String taxRate) {
        BigDecimal subtotal = new BigDecimal(unitPrice)
            .multiply(BigDecimal.valueOf(quantity));
        BigDecimal tax = subtotal.multiply(new BigDecimal(taxRate));
        return subtotal.add(tax).setScale(2, RoundingMode.HALF_UP);
    }

    public static void main(String[] args) {
        System.out.println(total("19.90", 3, "0.06"));
    }
}
```

优先从字符串或整数创建，避免 `new BigDecimal(0.1)` 把浮点误差带入。`divide` 遇到无限小数会抛异常，必须指定精度与舍入方式。

`equals` 同时比较数值与 scale，所以 `1.0` 与 `1.00` 不相等；只比较数值大小使用 `compareTo`。最终入库可用最小货币单位整数，或固定精度十进制列，并始终单独保存币种。税额是逐行舍入还是汇总后舍入必须遵循业务或法规约定。
