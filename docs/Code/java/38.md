# Java EnumMap：用枚举键表达有限状态表

键的取值来自同一个枚举时，`EnumMap` 比通用 `HashMap` 更直接，并按枚举声明顺序迭代。它不接受 `null` 键。

```java
import java.util.EnumMap;
import java.util.Map;

public class Main {
    enum Status { CREATED, PAID, SHIPPED }

    public static void main(String[] args) {
        Map<Status, String> labels = new EnumMap<>(Status.class);
        labels.put(Status.CREATED, "已创建");
        labels.put(Status.PAID, "已支付");
        labels.put(Status.SHIPPED, "已发货");

        for (Status status : Status.values()) {
            System.out.println(status + ": " + labels.get(status));
        }
    }
}
```

若每个枚举值都必须有映射，初始化后遍历 `Status.values()` 验证缺项，避免 `get` 静默返回 `null`。共享映射在构造完成后可用 `Map.copyOf` 暴露只读视图。状态转移包含行为时，应考虑封装为方法，而不是把越来越复杂的业务规则塞进多张 Map。
