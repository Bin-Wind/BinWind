# Java Files.walk：遍历目录时正确关闭文件流

`Files.walk` 返回惰性 `Stream<Path>`，遍历期间可能持有打开的目录句柄，因此应使用 try-with-resources。

```java
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.stream.Stream;

public class Main {
    public static void main(String[] args) throws IOException {
        Path root = args.length == 0 ? Path.of(".") : Path.of(args[0]);
        try (Stream<Path> paths = Files.walk(root)) {
            paths.filter(Files::isRegularFile)
                 .filter(path -> path.toString().endsWith(".md"))
                 .limit(20)
                 .forEach(System.out::println);
        }
    }
}
```

符号链接默认不跟随；启用跟随后要准备处理循环。大目录中先过滤再执行昂贵操作，并避免把所有路径 `toList()` 后才处理。权限错误可能中断遍历，需要跳过单个目录时可改用 `Files.walkFileTree`，在访问失败回调中记录并继续。
