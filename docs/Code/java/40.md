# Java ThreadLocal：线程池中用完必须清理

`ThreadLocal` 为当前线程关联值，但线程池会长期复用线程。一次请求若不清理，下一次任务可能读到旧用户上下文，也会延长对象生命周期。

```java
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;

public class Main {
    private static final ThreadLocal<String> REQUEST_ID = new ThreadLocal<>();

    public static void main(String[] args) throws Exception {
        ExecutorService pool = Executors.newFixedThreadPool(1);
        try {
            pool.submit(() -> {
                REQUEST_ID.set("req-42");
                try {
                    System.out.println(REQUEST_ID.get());
                } finally {
                    REQUEST_ID.remove();
                }
            }).get();
        } finally {
            pool.shutdown();
        }
    }
}
```

清理应与设置出现在同一层 `finally` 中。异步任务切换线程后不会自然继承该值；不要依赖 `InheritableThreadLocal` 解决线程池传播。重要业务参数应显式传递，ThreadLocal 更适合日志追踪等横切上下文。
