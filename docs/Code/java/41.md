# Java List.copyOf：在边界创建不可变快照

把调用方传入的可变列表直接保存到对象里，会让外部修改悄悄改变内部状态。List.copyOf 可在构造时创建不可变快照。

~~~java
import java.util.ArrayList;
import java.util.List;

public class Main {
    record Order(List<String> items) {
        Order { items = List.copyOf(items); }
    }
    public static void main(String[] args) {
        var source = new ArrayList<>(List.of("tea"));
        var order = new Order(source);
        source.add("cake");
        System.out.println(order.items());
    }
}
~~~

copyOf 会拒绝 null 列表和 null 元素，这能让错误尽早暴露。不可变只覆盖列表结构；元素对象仍可能可变，需要在领域边界深拷贝或使用不可变值对象。返回字段时无需再次复制，但不要用它替代并发协议。
