# ScheduledExecutorService：固定频率与固定延迟的区别

周期任务要先决定是追随墙上时刻，还是在每次完成后等待。scheduleAtFixedRate 尝试维持起始节奏；scheduleWithFixedDelay 则从上次结束后再计时。

~~~java
import java.util.concurrent.Executors;
import java.util.concurrent.TimeUnit;

public class Main {
    public static void main(String[] args) throws Exception {
        var scheduler = Executors.newSingleThreadScheduledExecutor();
        scheduler.scheduleWithFixedDelay(
            () -> System.out.println(System.currentTimeMillis()),
            0, 200, TimeUnit.MILLISECONDS);
        Thread.sleep(550);
        scheduler.shutdown();
        scheduler.awaitTermination(1, TimeUnit.SECONDS);
    }
}
~~~

任务抛出未捕获异常后，后续执行会被抑制，因此应在任务边界记录并处理预期故障。长任务不会在同一周期实例上并发，但会造成积压或漂移。需要跨进程唯一执行时仍要使用分布式锁或调度平台。
