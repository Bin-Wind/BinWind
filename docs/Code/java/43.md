# Java 解压路径校验：阻止 Zip Slip 越界写入

ZIP 条目名可能包含 ../ 或绝对路径。直接 resolve 后写文件，攻击者就可能覆盖目标目录之外的文件。

~~~java
import java.nio.file.Path;

public class Main {
    static Path safeTarget(Path root, String entry) {
        Path base = root.toAbsolutePath().normalize();
        Path target = base.resolve(entry).normalize();
        if (!target.startsWith(base)) {
            throw new IllegalArgumentException("entry escapes target directory");
        }
        return target;
    }
    public static void main(String[] args) {
        System.out.println(safeTarget(Path.of("out"), "docs/readme.txt"));
    }
}
~~~

正式解压还要限制条目数量、单项与总展开大小，防止 ZIP 炸弹；符号链接也需要单独策略。先写入隔离临时目录，全部校验成功后再发布。不要仅检查字符串是否含有两个点，规范化后的路径边界才可靠。
