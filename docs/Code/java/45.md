# Java Files.mismatch：快速定位两个文件是否不同

校验本地复制结果时，Files.mismatch 会返回第一个不同字节的位置；完全相同则返回 -1。它适合快速比较，不等同于可跨机器保存的完整性摘要。

~~~java
import java.nio.file.Files;
import java.nio.file.Path;

public class Main {
    public static void main(String[] args) throws Exception {
        Path left = Files.writeString(Path.of("left.txt"), "hello\n");
        Path right = Files.writeString(Path.of("right.txt"), "hello\n");
        long position = Files.mismatch(left, right);
        System.out.println(position == -1 ? "same" : "diff at " + position);
    }
}
~~~

比较前确认路径指向普通文件，并处理文件在读取期间变化的可能。安全下载、长期归档或不可信来源验证仍应使用 SHA-256 等摘要，并通过可信渠道获得期望值。文件相同也不代表元数据、权限和扩展属性一致，这些需要单独检查。
