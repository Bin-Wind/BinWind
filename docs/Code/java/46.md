# Java Duration：让超时参数带上单位

用裸 long 表示超时，很容易把秒当成毫秒。java.time.Duration 把数值和单位绑定，并能在应用边界统一校验。

~~~java
import java.time.Duration;

public class Main {
    static int toMillis(Duration timeout) {
        if (timeout.isNegative() || timeout.isZero()) {
            throw new IllegalArgumentException("timeout must be positive");
        }
        return Math.toIntExact(timeout.toMillis());
    }

    public static void main(String[] args) {
        Duration timeout = Duration.ofSeconds(3);
        System.out.println(toMillis(timeout));
    }
}
~~~

转换到旧 API 前检查范围，toMillis 可能超过 int。配置文件中优先接受带单位的格式，并在启动时解析失败，而不是默认为零。Duration 表示时间长度，不适合表达带月份的日历周期；“下个月同一天”应使用 Period 或明确的日期规则。
