# Java ProcessBuilder：安全传参与超时回收

`ProcessBuilder` 接收参数列表，不需要把用户值拼进一整条 shell 命令。为避免大量输出塞满管道，示例把输出重定向到临时文件，并为进程设置期限。

~~~java
import java.nio.file.Files;
import java.nio.file.Path;
import java.time.Duration;
import java.util.concurrent.TimeUnit;

public class RunProcess {
    public static void main(String[] args) throws Exception {
        Path output = Files.createTempFile("command-", ".log");
        Process process = new ProcessBuilder("java", "-version")
            .redirectErrorStream(true)
            .redirectOutput(output.toFile())
            .start();

        Duration limit = Duration.ofSeconds(5);
        if (!process.waitFor(limit.toMillis(), TimeUnit.MILLISECONDS)) {
            process.destroy();
            if (!process.waitFor(1, TimeUnit.SECONDS)) {
                process.destroyForcibly();
                process.waitFor();
            }
            throw new RuntimeException("command timed out");
        }

        System.out.println("exit=" + process.exitValue());
        System.out.println(Files.readString(output));
        Files.deleteIfExists(output);
    }
}
~~~

可执行文件应来自可信配置并尽量使用明确路径；动态输入只作为独立参数。按需构造最小环境变量集合，避免把父进程密钥传给不受信程序。

`destroy()` 不保证整个子进程树都退出。运行复杂工具时可结合 `ProcessHandle.descendants()`、容器或服务管理器处理进程组，并在审计日志中保存退出码、超时与输出文件位置。
