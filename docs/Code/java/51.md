# Java Files.walk：遍历目录时正确关闭资源

`Files.walk` 返回惰性的 `Stream<Path>`，底层可能持有已打开的目录句柄。它必须放在 try-with-resources 中关闭；只调用终止操作并不等于资源一定及时释放。

```java
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;
import java.util.stream.Stream;

public class MarkdownFiles {
    static List<Path> find(Path root) throws IOException {
        try (Stream<Path> paths = Files.walk(root, 8)) {
            return paths
                    .filter(Files::isRegularFile)
                    .filter(path -> path.toString().endsWith(".md"))
                    .sorted()
                    .toList();
        }
    }
}
```

第二个参数限制最大深度，可防止意外扫描巨大目录树。默认不会跟随符号链接；若启用 `FOLLOW_LINKS`，要准备处理环路与越界路径。

## 惰性流的边界

不要从方法返回仍依赖已关闭目录的 `Stream`。示例在资源范围内收集成列表后再返回。文件树很大时，不应全部收集；可在 `try` 内逐项消费并把结果写到下游。

遍历期间文件可能被删除或权限改变，异常会在消费流时出现，而不一定在创建流时出现。批量改写前先验证根路径，处理每个文件时再次确认目标边界，并为失败项留下明确记录。
