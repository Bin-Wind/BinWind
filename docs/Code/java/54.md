# Java Phaser：协调会动态加入的分阶段任务

`CountDownLatch` 的参与者数量固定，而 `Phaser` 允许任务在运行中注册或退出，适合“读取—计算—汇总”这类多阶段并行流程。

```java
import java.util.concurrent.Phaser;

public class PhaseDemo {
    public static void main(String[] args) throws InterruptedException {
        Phaser phaser = new Phaser(1); // 主线程

        for (int id = 1; id <= 3; id++) {
            phaser.register();
            int workerId = id;
            Thread.startVirtualThread(() -> {
                try {
                    System.out.println("读取 " + workerId);
                    phaser.arriveAndAwaitAdvance();
                    System.out.println("计算 " + workerId);
                } finally {
                    phaser.arriveAndDeregister();
                }
            });
        }

        phaser.arriveAndAwaitAdvance();
        phaser.arriveAndDeregister();
    }
}
```

若运行环境不支持虚拟线程，可换成普通 `new Thread(...).start()`。关键是注册与注销严格配对，并把注销放在 `finally` 中；否则某个任务异常退出会让其他参与者永久等待。

## 超时与失败传播

`arriveAndAwaitAdvance()` 没有超时。需要截止时间时，先 `arrive()` 获取阶段号，再用 `awaitAdvanceInterruptibly` 等待并设置超时。一个工作线程失败后还应通过共享失败状态通知其他线程停止，不能只让它自己注销。

阶段编号会前进，所有任务必须对每一阶段含义达成一致。流程固定且参与者不变时，更简单的并发工具通常更易维护。
