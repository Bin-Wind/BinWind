# Java Files.createTempFile：安全创建并清理临时文件

自己拼接时间戳生成临时文件名会遇到冲突，也可能落到错误目录。`Files.createTempFile` 由文件系统原子创建唯一文件，并返回实际路径。

```java
import java.nio.charset.StandardCharsets;
import java.nio.file.*;

public class TempReport {
    public static void main(String[] args) throws Exception {
        Path workDir = Files.createTempDirectory("report-");
        try {
            Path draft = Files.createTempFile(workDir, "draft-", ".txt");
            Files.writeString(draft, "ready\n", StandardCharsets.UTF_8);
            System.out.println(Files.size(draft));
        } finally {
            try (var paths = Files.walk(workDir)) {
                paths.sorted((a, b) -> b.getNameCount() - a.getNameCount())
                     .forEach(path -> {
                         try { Files.deleteIfExists(path); }
                         catch (Exception error) { System.err.println(error); }
                     });
            }
        }
    }
}
```

临时目录中可能包含敏感内容，应按平台设置严格权限，并避免把完整路径写入公开日志。默认系统临时目录不一定满足磁盘容量、加密或同文件系统原子移动的要求；发布文件时最好在目标目录旁创建临时文件，写完、刷新并校验后再移动。

`deleteOnExit` 只有 JVM 正常退出才执行，长进程还会一直保存待删除路径。可靠程序应在 `finally` 中主动清理，并由后台任务处理崩溃遗留且超过安全年龄的文件。
