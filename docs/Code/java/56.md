# Java HexFormat：可靠转换十六进制文本与字节

Java 17 的 `HexFormat` 能完成字节数组与十六进制文本转换，避免手写循环遗漏前导零或错误处理有符号 byte。

```java
import java.util.HexFormat;

public class HexDemo {
    public static void main(String[] args) {
        HexFormat hex = HexFormat.of();
        byte[] bytes = {0, 15, 16, (byte) 255};
        String encoded = hex.formatHex(bytes);
        System.out.println(encoded);              // 000f10ff
        System.out.println(hex.parseHex(encoded).length);
    }
}
```

需要分隔符时可用 `HexFormat.ofDelimiter(":")`，大小写也应在协议边界固定。`parseHex` 遇到非法字符或不匹配格式会抛出 `IllegalArgumentException`，外部输入应捕获并返回清晰错误。

十六进制只是编码，不提供加密、签名或保密性。比较消息摘要时还需使用适合的常量时间比较方法，不能因为字符串看起来随机就把它当安全令牌。
