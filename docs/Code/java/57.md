# Java CompletableFuture.orTimeout：为异步阶段设置截止时间

`CompletableFuture.orTimeout` 会在指定时间内未完成时让同一个 future 以 `TimeoutException` 异常完成，适合阻止调用方无限等待。

```java
import java.util.concurrent.*;

public class TimeoutDemo {
    public static void main(String[] args) {
        CompletableFuture<String> task = CompletableFuture.supplyAsync(() -> "ok")
            .orTimeout(500, TimeUnit.MILLISECONDS);
        System.out.println(task.join());
    }
}
```

超时完成不等于底层工作已经取消。数据库查询、HTTP 请求或线程任务仍需使用各自的取消与超时能力，并在中断后正确清理资源。若希望超时时提供默认值，可使用 `completeOnTimeout`，但要避免把真实故障伪装成正常空数据。

多阶段调用应传播总截止时间，而不是每层重新获得完整超时。处理 `CompletionException` 时检查其 cause，区分超时、业务失败与取消，才能决定是否重试。
