# Java Cleaner：为本地资源提供最后一道清理防线

`Cleaner` 可在对象不可达后安排清理动作，适合本地内存等非 Java 资源的兜底释放。它不能保证及时执行，所以主要路径仍应实现 `AutoCloseable` 并使用 try-with-resources。

```java
import java.lang.ref.Cleaner;

final class Handle implements AutoCloseable {
    private static final Cleaner CLEANER = Cleaner.create();
    private static final class State implements Runnable {
        public void run() { System.out.println("released"); }
    }
    private final Cleaner.Cleanable cleanable = CLEANER.register(this, new State());
    public void close() { cleanable.clean(); }
}

public class CleanerDemo {
    public static void main(String[] args) {
        try (Handle ignored = new Handle()) { System.out.println("using"); }
    }
}
```

清理状态类不能捕获 `Handle`，否则引用环会阻止清理。`clean()` 只执行一次，可让显式关闭与兜底共享逻辑。数据库事务、锁和临时文件等需要确定释放时机的资源，不应依赖 Cleaner。
