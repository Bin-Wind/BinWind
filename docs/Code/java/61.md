# Java ArrayDeque：维护有界的最近记录

需要保留最近 N 条事件时，`ArrayDeque` 比频繁删除 `ArrayList` 首元素更合适。它不接受 `null`，也不是线程安全容器。

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class RecentEvents {
    private final int capacity;
    private final Deque<String> events = new ArrayDeque<>();

    RecentEvents(int capacity) {
        if (capacity <= 0) throw new IllegalArgumentException("capacity must be positive");
        this.capacity = capacity;
    }

    void add(String event) {
        if (events.size() == capacity) events.removeFirst();
        events.addLast(event);
    }

    public String toString() { return events.toString(); }

    public static void main(String[] args) {
        RecentEvents log = new RecentEvents(3);
        for (String value : new String[]{"A", "B", "C", "D"}) log.add(value);
        System.out.println(log);
    }
}
```

并发场景可在更高层加锁，确保“检查容量—删除—追加”是一个原子操作。若记录必须持久保存或不能丢失，内存双端队列只是缓存，不应充当消息队列。
