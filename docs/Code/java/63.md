# Java Files.mismatch：定位两个文件的首个差异字节

Java 12 起，`Files.mismatch` 可以比较两个文件并返回首个不同字节的位置。两个文件完全相同返回 `-1`；若公共前缀相同但长度不同，则返回较短文件的长度。

```java
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;

public class FileMismatchDemo {
    public static void main(String[] args) throws IOException {
        Path left = Files.createTempFile("left-", ".txt");
        Path right = Files.createTempFile("right-", ".txt");
        try {
            Files.writeString(left, "alpha\nbeta\n");
            Files.writeString(right, "alpha\nBeta\n");

            long position = Files.mismatch(left, right);
            System.out.println("first mismatch: " + position);
        } finally {
            Files.deleteIfExists(left);
            Files.deleteIfExists(right);
        }
    }
}
```

## 字节位置不是字符位置

返回值按字节计算。UTF-8 中文字符可能占多个字节，不能直接用它作为字符串索引。若要给用户展示行列，应在发现位置后按同一字符集读取附近内容，并谨慎处理位置落在多字节字符中间的情况。

`Files.mismatch` 适合快速判断本地文件内容是否一致，但不是持久身份。文件在比较期间被修改时结果没有稳定快照保证；先锁定或复制待比较对象。跨机器长期校验可计算并保存密码学摘要，同时记录算法。比较敏感文件前也要处理不存在、权限不足和符号链接等情况，不要把所有 I/O 异常解释成“文件不同”。
