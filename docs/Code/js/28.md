# Intl API：可靠处理日期、数字与列表

国际化格式不应靠字符串拼接。`Intl` 使用运行环境的本地化数据，能统一处理数字、货币、日期、相对时间和列表。

## 数字与货币

```js
const money = new Intl.NumberFormat('zh-CN', {
  style: 'currency',
  currency: 'CNY'
})

console.log(money.format(123456.78))
```

金额计算仍应使用最小货币单位或可靠十进制定点方案；`Intl` 只负责展示，不负责解决浮点精度。

## 明确时区

```js
const formatter = new Intl.DateTimeFormat('zh-CN', {
  dateStyle: 'long',
  timeStyle: 'short',
  timeZone: 'Asia/Shanghai'
})

console.log(formatter.format(new Date('2026-09-08T06:00:00Z')))
```

不指定 `timeZone` 会使用设备默认值，同一时间在服务器和用户浏览器上可能显示不同。存储时保留时间点和必要的业务时区，展示时再本地化。

## 相对时间与列表

```js
const relative = new Intl.RelativeTimeFormat('zh-CN', { numeric: 'auto' })
console.log(relative.format(-1, 'day'))

const list = new Intl.ListFormat('zh-CN', { style: 'long', type: 'conjunction' })
console.log(list.format(['搜索', '筛选', '导出']))
```

格式化器创建有成本，重复渲染时应按语言与选项缓存实例。测试不要硬编码所有环境的空格字符细节；重点验证 locale、时区和语义结果。
