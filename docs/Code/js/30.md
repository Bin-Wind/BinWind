# URL 与 URLSearchParams：可靠处理地址和查询参数

手工拼接 URL 容易漏掉编码、问号和已有参数。标准 `URL` API 能解析相对地址，并对查询参数做一致编码。

```js
function buildSearchUrl(base, keyword, page = 1) {
  const url = new URL('/search', base)
  url.searchParams.set('q', keyword)
  url.searchParams.set('page', String(page))
  return url.toString()
}

console.log(buildSearchUrl('https://example.com/app/', '咖啡 & 茶', 2))
```

`set` 会替换同名参数，`append` 可保留多个值：

```js
const params = new URLSearchParams()
params.append('tag', 'javascript')
params.append('tag', 'web')
console.log(params.getAll('tag'))
```

查询参数不是安全边界。把 URL 值插入 HTML、SQL 或文件路径前，仍需按目标上下文校验和转义。处理回跳地址时只允许可信 origin 或站内相对路径，避免开放重定向。
