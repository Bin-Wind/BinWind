# Web Worker：把 CPU 计算移出主线程

大量计算会阻塞浏览器渲染和输入响应。Web Worker 在独立线程运行脚本，主线程通过消息传递数据，适合解析、压缩和纯计算任务。

`worker.js`：

```js
self.addEventListener('message', event => {
  const numbers = event.data
  const total = numbers.reduce((sum, value) => sum + value, 0)
  self.postMessage({ total })
})
```

页面脚本：

```js
const worker = new Worker('./worker.js', { type: 'module' })
worker.addEventListener('message', event => {
  console.log('result:', event.data.total)
  worker.terminate()
})
worker.addEventListener('error', error => {
  console.error('worker failed', error.message)
})
worker.postMessage([1, 2, 3, 4])
```

Worker 不能直接操作 DOM。普通对象通过结构化克隆传递，大型 `ArrayBuffer` 可放入 transfer list 转移所有权，避免复制。启动 Worker 也有成本，小任务留在主线程更快。
