# Map 与 WeakMap：为对象关联状态的两种方式

普通对象会把键转换为字符串，`Map` 则允许对象、数字等任意键，并保留插入顺序。需要遍历、统计或显式删除的缓存适合 Map。

```javascript
const visits = new Map()
function record(userId) {
  visits.set(userId, (visits.get(userId) ?? 0) + 1)
}
record('u-1')
console.log([...visits.entries()])
```

`WeakMap` 的键只能是对象，并且不会阻止键对象被垃圾回收，适合保存 DOM 节点或实例的附加状态：

```javascript
const metadata = new WeakMap()
const element = document.createElement('button')
metadata.set(element, { clicks: 0 })
metadata.get(element).clicks += 1
```

WeakMap 不能遍历，也没有 `size`，这是弱引用语义的结果，不适合需要列出所有记录的业务数据。两者都不是自动淘汰缓存；Map 缓存还需容量上限、过期策略和命中统计。
