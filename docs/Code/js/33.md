# IntersectionObserver：高效判断元素是否进入视口

在 `scroll` 事件中反复读取布局信息容易造成卡顿。`IntersectionObserver` 让浏览器批量报告元素与视口的交叉状态，适合懒加载和曝光统计。

```javascript
const observer = new IntersectionObserver((entries, instance) => {
  for (const entry of entries) {
    if (!entry.isIntersecting) continue
    const image = entry.target
    image.src = image.dataset.src
    instance.unobserve(image)
  }
}, { rootMargin: '200px 0px', threshold: 0.01 })

document.querySelectorAll('img[data-src]').forEach(image => observer.observe(image))
```

`rootMargin` 提前 200 像素开始加载，减少用户看到空白的概率。若要统计“可见一半并持续一秒”，需要在回调中结合计时，单次进入不能直接算有效曝光。

组件销毁时调用 `unobserve` 或 `disconnect`。浏览器原生图片懒加载可直接使用 `loading="lazy"`；只有需要自定义阈值、容器或业务埋点时才引入观察器。
