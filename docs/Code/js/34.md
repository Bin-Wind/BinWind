# 自定义事件：用 EventTarget 解耦页面模块

浏览器原生 `EventTarget` 可以让同一页面中的模块发布和订阅事件，无需安装事件总线库。事件名和载荷仍应形成清晰契约。

```javascript
const bus = new EventTarget()

function onCartUpdated(event) {
  console.log(`cart items: ${event.detail.count}`)
}

bus.addEventListener('cart:updated', onCartUpdated)
bus.dispatchEvent(new CustomEvent('cart:updated', {
  detail: { count: 3 },
}))
bus.removeEventListener('cart:updated', onCartUpdated)
```

移除监听器必须传入注册时的同一函数引用。组件可以接收 bus 作为依赖，测试时创建独立实例，避免所有页面共享一个隐式全局对象。

事件是同步分发的：监听器中的长计算会阻塞发布者，异常处理也要在边界上明确。需要请求响应、跨页面持久化或跨进程通信时，应该选择更合适的接口，而不是把事件总线扩展成不可追踪的控制流。
