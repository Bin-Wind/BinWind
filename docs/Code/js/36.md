# MutationObserver：可靠观察 DOM 结构变化

轮询 DOM 会浪费资源，也容易错过短暂变化。`MutationObserver` 可在节点、属性或文本发生变化后批量通知。

```javascript
const list = document.querySelector("#messages");

const observer = new MutationObserver((records) => {
  const added = records.flatMap((record) => [...record.addedNodes]);
  for (const node of added) {
    if (node.nodeType === Node.ELEMENT_NODE) {
      console.log("新增元素", node);
    }
  }
});

observer.observe(list, {
  childList: true,
  subtree: true,
});

window.addEventListener("pagehide", () => observer.disconnect(), { once: true });
```

只开启真正需要的选项。`attributes: true` 配合 `attributeFilter` 可减少噪声；观察旧值会增加开销。回调在微任务检查点批量执行，不要假设每次 DOM 操作立即收到通知。

回调中修改被观察区域可能再次触发观察器，应设置明确条件或临时断开。框架应用通常优先使用自身响应式状态，MutationObserver 更适合第三方组件、富文本编辑器或外部脚本留下的 DOM 边界。
