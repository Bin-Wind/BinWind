# 异步生成器：按页拉取并逐条消费数据

分页 API 常让调用方手写游标循环。异步生成器可以隐藏翻页细节，同时保留按需请求与自然背压。

```javascript
async function* listAll(fetchPage) {
  let cursor;
  do {
    const page = await fetchPage(cursor);
    if (!Array.isArray(page.items)) throw new TypeError("items 必须是数组");
    for (const item of page.items) yield item;
    cursor = page.nextCursor;
  } while (cursor);
}

const fetchPage = async (cursor) => ({
  items: cursor ? ["第三项"] : ["第一项", "第二项"],
  nextCursor: cursor ? null : "page-2",
});

for await (const item of listAll(fetchPage)) {
  console.log(item);
}
```

调用方执行到下一项时才会继续拉取，因此不会默认把全部页面放进内存。消费者提前 `break` 时生成器会关闭；若内部持有连接，可用 `try/finally` 释放。

生产实现要检测重复游标，避免服务端错误造成无限循环，并加入有限重试、取消信号和最大页数。游标通常是不透明字符串，不要解析或自行递增。需要并行预取时限制窗口大小，否则会重新失去背压。
