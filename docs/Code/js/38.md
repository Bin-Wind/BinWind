# Intl.Segmenter：按语言规则切分单词和字素

用字符串长度或空格切分文本，对中文、emoji 和组合字符都不可靠。`Intl.Segmenter` 可按区域规则切分字素、单词或句子。

```js
const text = '你好，JavaScript 👨‍👩‍👧‍👦！';
const segmenter = new Intl.Segmenter('zh-CN', { granularity: 'grapheme' });
const graphemes = [...segmenter.segment(text)].map(item => item.segment);

console.log(graphemes);
console.log('用户可见字符数:', graphemes.length);
```

字素切分适合光标移动和可见字符计数；单词切分会返回 `isWordLike`，可过滤标点；句子切分适合阅读界面，但不能代替完整自然语言分析。

运行前可检测 `Intl.Segmenter` 是否存在，并为旧环境提供降级。即使按字素计数，数据库和接口限制仍需明确按字节、码点还是用户可见字符执行，前后端保持一致。
