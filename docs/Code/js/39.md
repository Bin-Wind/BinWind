# ResizeObserver：观察元素尺寸而不是轮询窗口

组件尺寸可能因容器、字体或内容改变，单听 `window.resize` 无法覆盖。`ResizeObserver` 直接观察目标元素的内容盒变化。

```js
const card = document.querySelector('.card');

if (card) {
  const observer = new ResizeObserver(entries => {
    for (const entry of entries) {
      const width = entry.contentRect.width;
      entry.target.classList.toggle('card--compact', width < 320);
    }
  });
  observer.observe(card);

  // 组件销毁时执行：
  // observer.disconnect();
}
```

回调中修改尺寸相关样式可能再次触发观察，形成循环；只在跨过阈值时改变状态，并优先考虑 CSS 容器查询。批量布局计算可集中到 `requestAnimationFrame`。

观察器持有目标引用，单页应用组件卸载时应 `unobserve` 或 `disconnect`。不要在每次回调里创建新的观察器，也不要把像素级连续变化直接发送到后端。
