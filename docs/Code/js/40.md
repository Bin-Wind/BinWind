# BroadcastChannel：在同源标签页间同步状态

同一站点打开多个标签页时，可以用 `BroadcastChannel` 广播登出、主题或缓存失效事件，无需轮询 `localStorage`。

```js
const channel = new BroadcastChannel('session-events');

channel.addEventListener('message', event => {
  if (event.data?.type === 'logout') {
    console.log('另一个标签页已退出登录');
    location.assign('/login');
  }
});

document.querySelector('#logout')?.addEventListener('click', () => {
  channel.postMessage({ type: 'logout' });
  channel.close();
});
```

消息只发送给同源且使用同名频道的其他上下文，不会持久化，也不提供服务端同步。消息数据经过结构化克隆，不能携带函数或 DOM 节点。

页面离开时调用 `close()`。安全事件仍应由服务端令牌失效保证，广播只负责快速更新其他标签页界面；旧标签页错过消息后也必须在下一次 API 请求中被拒绝。
