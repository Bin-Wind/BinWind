# URLSearchParams：安全构造和读取查询参数

查询字符串需要正确处理空格、中文、重复键和保留字符。URL 与 URLSearchParams 能避免手工拼接时漏编码或多写问号。

~~~js
const url = new URL('https://example.com/search');
url.searchParams.set('q', '咖啡 & 茶');
url.searchParams.append('tag', '入门');
url.searchParams.append('tag', '实践');
console.log(url.href);
console.log(url.searchParams.getAll('tag'));
~~~

set 会替换同名值，append 保留重复项；后端与前端要约定数组编码方式。不要把 searchParams.toString 的结果再整体 encodeURIComponent。读取布尔值和数字时显式校验，缺失、空字符串与非法数字应区分。查询参数不是可信输入，进入数据库或页面前仍需验证。
