# FormData：保留重复字段并正确提交文件

表单不仅有单值文本，还可能包含多选框、同名字段和文件。FormData 会按控件顺序保留这些条目，适合直接构造 multipart/form-data 请求。

~~~js
const form = document.querySelector('form');
const data = new FormData(form);
data.append('tag', '实践');

for (const tag of data.getAll('tag')) {
  console.log(tag);
}

const response = await fetch('/api/articles', {
  method: 'POST',
  body: data,
});
if (!response.ok) throw new Error(`HTTP ${response.status}`);
~~~

用 fetch 提交 FormData 时不要手动设置 Content-Type；浏览器会生成包含 boundary 的正确头部。get 只返回第一个同名值，多选字段应使用 getAll。FormData 不会自动验证业务规则，服务端仍要限制文件类型、大小、字段数量和权限。调试时逐项打印，不要把 File 对象误转为 JSON。
