# requestAnimationFrame：分帧合并界面更新

滚动、指针移动等事件可能在一帧内触发多次。每次都读取布局并修改 DOM 会造成重复计算。requestAnimationFrame 可把更新合并到浏览器下一次绘制前。

~~~js
const indicator = document.querySelector('.scroll-indicator');
let scheduled = false;

window.addEventListener('scroll', () => {
  if (scheduled) return;
  scheduled = true;
  requestAnimationFrame(() => {
    const max = document.documentElement.scrollHeight - innerHeight;
    const progress = max > 0 ? scrollY / max : 0;
    indicator.style.transform = `scaleX(${progress})`;
    scheduled = false;
  });
}, { passive: true });
~~~

先批量读取尺寸，再批量写样式，避免读写交错触发布局抖动。动画回调在后台标签页会降频或暂停，因此不能用它计算业务计时；根据回调时间戳计算视觉进度。组件销毁时取消尚未执行的帧，并尊重用户的减少动态效果偏好。
