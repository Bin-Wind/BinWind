# AbortSignal.any：合并超时与用户取消

一次请求可能同时受页面卸载、用户点击取消和业务超时约束。AbortSignal.any 可把多个信号合成一个，任一信号触发都会取消下游操作。

~~~js
const userController = new AbortController();
const signal = AbortSignal.any([
  userController.signal,
  AbortSignal.timeout(3_000),
]);

try {
  const response = await fetch('/api/report', { signal });
  if (!response.ok) throw new Error(`HTTP ${response.status}`);
} catch (error) {
  if (signal.aborted) console.log('cancelled:', signal.reason);
  else throw error;
}
~~~

合并后通常无法仅从 AbortError 判断是哪一个源触发，应读取 signal.reason，或在源信号上记录明确原因。兼容旧浏览器时可手动转发 abort 事件，并在完成后移除监听器。取消只表示客户端不再等待，写请求是否生效仍需用幂等键和状态查询确认。
