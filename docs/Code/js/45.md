# Intl.RelativeTimeFormat：本地化“几分钟前”

自己拼接“1 minutes ago”容易出现复数、语序和方向错误。Intl.RelativeTimeFormat 根据语言环境生成相对时间文本。

~~~js
const formatter = new Intl.RelativeTimeFormat('zh-CN', { numeric: 'auto' });

function relativeMinutes(target, now = Date.now()) {
  const minutes = Math.round((target - now) / 60_000);
  return formatter.format(minutes, 'minute');
}

console.log(relativeMinutes(Date.now() - 5 * 60_000));
~~~

先按产品规则选择秒、分、时或天的粒度，再传对应单位；不要把 36 小时盲目舍入成“2 天”而隐藏精确期限。重要操作同时提供绝对日期，并用 time 元素的 datetime 保存机器可读值。长时间停留页面需按合理间隔刷新，标签页不可见时暂停计时器。
