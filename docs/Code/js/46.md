# Element.closest：从事件目标找到组件边界

事件委托能用一个监听器处理动态列表，但 event.target 可能是按钮内部的图标或文字。closest 可沿祖先链找到带行为标记的元素。

~~~js
const list = document.querySelector('[data-list]');

list.addEventListener('click', (event) => {
  const button = event.target.closest('[data-remove]');
  if (!button || !list.contains(button)) return;
  const row = button.closest('[data-row]');
  if (row) row.remove();
});
~~~

contains 检查很重要：closest 可能越过预期局部边界，尤其监听器挂在 document 时。行为用 data 属性表达，不要依赖容易因样式重构改变的 class。键盘操作应使用原生 button，让 Enter、Space 和焦点行为自动可用；事件委托不能替代语义 HTML。
