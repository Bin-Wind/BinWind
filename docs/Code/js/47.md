# PerformanceObserver：异步采集长任务记录

浏览器支持 Long Tasks API 时，可以用 `PerformanceObserver` 观察阻塞主线程超过阈值的任务，而不必自己轮询时间。它适合发现交互卡顿的时间段，再结合业务标记定位原因。

~~~javascript
if (PerformanceObserver.supportedEntryTypes?.includes('longtask')) {
  const observer = new PerformanceObserver(list => {
    for (const entry of list.getEntries()) {
      console.log({
        start: Math.round(entry.startTime),
        duration: Math.round(entry.duration)
      })
    }
  })

  observer.observe({ type: 'longtask', buffered: true })
  window.addEventListener('pagehide', () => observer.disconnect(), { once: true })
}
~~~

该条目并非所有浏览器都支持，因此必须做能力检测。采集到的持续时间说明主线程被占用，不会直接告诉你是哪行代码；可在关键流程使用 `performance.mark`，并结合性能剖析复现。

上报时采样并限制字段，不收集用户输入或完整 URL。优化目标也不能只剩“没有长任务”，应同时观察交互延迟与真实业务完成时间。
