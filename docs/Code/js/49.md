# queueMicrotask：合并同一轮同步更新

多个同步调用都想安排一次收尾工作时，`queueMicrotask` 可以把它放到当前调用栈结束后、浏览器进入下一轮任务前执行。加一个标志即可合并重复调度。

~~~javascript
const pending = new Map()
let scheduled = false

function record(key, value) {
  pending.set(key, value)
  if (scheduled) return

  scheduled = true
  queueMicrotask(() => {
    scheduled = false
    const batch = Object.fromEntries(pending)
    pending.clear()
    console.log('flush', batch)
  })
}

record('name', 'BinWind')
record('theme', 'dark')
record('name', '小风')
~~~

微任务会在渲染和下一个计时器之前清空。若回调不断继续排微任务，页面会长时间无法渲染，因此重计算或大批量处理应交给新的任务、动画帧或 Worker。

回调抛出的异常按普通异常报告，这与用已解决 Promise 模拟微任务的拒绝行为不同。它适合很短的状态归并，不适合延迟到“用户稍后可见”的业务队列。
