# addEventListener 的 signal：统一撤销一组 DOM 监听器

`addEventListener` 支持传入 `AbortSignal`。将同一组件注册的监听器绑定到一个 controller，销毁时调用一次 `abort()`，比逐个保存回调引用更不易漏清理。

```javascript
function mountToolbar(root) {
  const controller = new AbortController();
  const { signal } = controller;

  root.addEventListener('click', (event) => {
    const button = event.target.closest('button[data-action]');
    if (button) console.log(button.dataset.action);
  }, { signal });

  window.addEventListener('resize', () => {
    root.dataset.compact = String(window.innerWidth < 640);
  }, { signal, passive: true });

  return () => controller.abort();
}
```

## controller 不能复用

`AbortController` 一旦中止就永久处于 aborted 状态。组件再次挂载时必须创建新实例；向已中止 signal 注册的监听器不会恢复。

`once: true` 适合只处理第一次事件，`signal` 适合生命周期结束时整体撤销，两者可以组合。`passive: true` 表示监听器不会调用 `preventDefault()`，仅应在确实无需阻止默认行为时使用。

清理监听器不等于清理所有资源。计时器、Observer、网络请求也要分别取消，或共享同一个 signal 给支持它们的 API。
