# CSS.escape：安全构造选择器中的动态标识

DOM 的 `id` 可以包含空格、冒号等在 CSS 选择器里有特殊含义的字符。把数据源提供的 ID 直接拼进 `querySelector`，可能抛出语法错误或匹配错误元素。`CSS.escape` 会把一个标识符片段转义成可用形式。

```javascript
function findById(id) {
  return document.querySelector(`#\${CSS.escape(id)}`);
}

const element = findById('section:2026/09');
console.log(element);
```

如果目标只是按 ID 查找，`document.getElementById(id)` 更直接，也不需要构造选择器。`CSS.escape` 的价值在于动态值确实位于选择器标识符位置时。

## 只转义值，不转义整个选择器

属性字符串的语法与标识符不同，不应把 `CSS.escape` 当作通用安全模板。更稳妥的是先查询有限范围的元素，再读取 `dataset` 做严格相等比较，或使用能够正确处理属性值的封装。

转义只解决 CSS 解析，不等于 HTML、URL 或 JavaScript 上下文安全。动态值进入不同上下文时必须使用对应 API，不能拿同一个转义函数到处复用。
