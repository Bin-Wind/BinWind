# Object.hasOwn：安全判断对象自己的属性

`key in object` 会沿原型链查找，而直接调用 `object.hasOwnProperty` 可能被同名字段覆盖，也不适用于无原型对象。`Object.hasOwn` 明确判断对象自身是否拥有该属性。

```javascript
const settings = Object.create(null)
settings.theme = 'dark'

console.log(Object.hasOwn(settings, 'theme')) // true
console.log(Object.hasOwn(settings, 'toString')) // false
```

判断“字段存在”不能写成 `if (settings.theme)`，因为 `false`、`0` 和空字符串都可能是合法值。读取外部 JSON 时，先确认值是非空对象，再检查自己的属性和字段类型。

```javascript
function readLimit(value) {
  if (value === null || typeof value !== 'object') return 10
  if (!Object.hasOwn(value, 'limit')) return 10
  if (!Number.isInteger(value.limit) || value.limit < 1) {
    throw new TypeError('limit 必须是正整数')
  }
  return value.limit
}
```

这不会防止原型污染本身。把不可信键复制到普通对象时仍应拒绝危险键、使用明确 Schema，或采用 `Map`/无原型对象保存纯字典数据。
