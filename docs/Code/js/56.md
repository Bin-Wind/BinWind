# Promise.any：采用第一个成功结果而不是第一个结束结果

`Promise.any` 在任一输入成功时完成，适合向多个等价只读来源请求同一资源。失败的请求不会阻止之后的成功结果。

```javascript
const from = (name, delay, ok) => new Promise((resolve, reject) => {
  setTimeout(() => ok ? resolve(name) : reject(new Error(name)), delay)
})

const winner = await Promise.any([
  from('mirror-a', 10, false),
  from('mirror-b', 20, true)
])
console.log(winner)
```

只有全部失败时才会拒绝，并抛出 `AggregateError`，可检查其 `errors` 汇总诊断。空数组也会立即以 `AggregateError` 拒绝。

成功后其他任务不会自动取消；网络请求应分别持有 `AbortController`，选出结果后取消剩余请求。不要用它并发执行会产生副作用的操作，否则多个请求可能都成功写入。服务之间若数据版本不同，还需先定义“任一成功”是否真的可接受。
