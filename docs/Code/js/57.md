# Intl.ListFormat：按语言习惯拼接名称列表

手写 `items.join('、')` 无法处理不同语言中的连接词、标点和“或”关系。`Intl.ListFormat` 会依据区域设置生成适合展示的列表。

```javascript
const items = ['设计', '开发', '测试']
const andList = new Intl.ListFormat('zh-CN', {
  style: 'long',
  type: 'conjunction'
})
console.log(andList.format(items))
```

`type` 可设为 `conjunction`、`disjunction` 或 `unit`；`style` 支持 `long`、`short` 和 `narrow`。若需要给每个名称添加链接，用 `formatToParts()` 获取文本和元素片段，不要先格式化再按标点拆分。

区域设置来自产品语言，而不应随服务器默认环境漂移。格式化结果用于展示，不适合作为持久化格式、缓存键或协议字段；业务数据仍保存为数组。
