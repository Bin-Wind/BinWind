# URLSearchParams.sort：稳定规范化查询参数顺序

同一组查询参数可以有不同排列。需要生成可读缓存键或测试快照时，可用 `URLSearchParams.sort()` 按参数名稳定排序。

```javascript
const params = new URLSearchParams('page=2&tag=vue&q=stream&tag=js')
params.sort()
console.log(params.toString())
// page=2&q=stream&tag=vue&tag=js
```

排序会保留同名参数之间的原始顺序，因此 `tag=vue&tag=js` 仍可表达有序多值。`get()` 只返回第一个值，需要全部值时使用 `getAll()`。

URL 编码有自己的空格与字符规则，不能把排序后的字符串直接当作任意签名协议的规范形式；签名方必须共同定义编码、重复键、空值和 Unicode 处理。操作会原地修改对象，若原顺序仍有意义，应先复制：`new URLSearchParams(params)`。
