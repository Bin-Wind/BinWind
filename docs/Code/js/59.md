# JavaScript DataView：按指定字节序读写二进制字段

`DataView` 适合解析协议头或文件格式，因为每次读写都能明确字节偏移和端序。它不会替你检查业务范围，但越界访问会抛出 `RangeError`。

```js
const buffer = new ArrayBuffer(8)
const view = new DataView(buffer)

view.setUint16(0, 0xCAFE, false) // 大端序
view.setUint32(2, 1500, true)   // 小端序
view.setUint16(6, 7, true)

console.log(view.getUint16(0, false).toString(16))
console.log(view.getUint32(2, true))
console.log([...new Uint8Array(buffer)])
```

解析前先验证最小长度，再按协议逐字段移动偏移。字符串需要单独使用 `TextDecoder`，不能假设一个字符等于一个字节。网络协议通常采用大端序，但应以格式规范为准。
