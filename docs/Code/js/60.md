# JavaScript queueMicrotask：安排轻量的同轮后续工作

`queueMicrotask` 会在当前调用栈结束后、浏览器处理下一个任务前运行。它适合统一同步与异步分支的通知顺序，但不适合长计算或无界递归。

```js
function createBatcher(flush) {
  let queued = false
  const values = []
  return value => {
    values.push(value)
    if (queued) return
    queued = true
    queueMicrotask(() => {
      queued = false
      flush(values.splice(0))
    })
  }
}

const add = createBatcher(items => console.log('flush', items))
add('A')
add('B')
console.log('scheduled')
```

输出先是 `scheduled`，再是合并后的批次。微任务不断追加微任务会阻止渲染和定时器执行；需要让出事件循环时应选择任务队列机制。回调抛出的异常也要按运行环境统一处理。
