# JavaScript TextDecoder：流式解码被拆开的 UTF-8 字符

网络分块可能刚好切在一个多字节字符中间。分别解码每块会出现替换字符，`TextDecoder` 的流式模式能保留未完成字节并与下一块拼接。

```js
const bytes = new TextEncoder().encode('A风B')
const chunks = [bytes.slice(0, 2), bytes.slice(2, 3), bytes.slice(3)]
const decoder = new TextDecoder('utf-8', { fatal: true })

let text = ''
for (const chunk of chunks) {
  text += decoder.decode(chunk, { stream: true })
}
text += decoder.decode()
console.log(text)
```

`fatal: true` 会让无效 UTF-8 抛错，适合不允许静默替换的输入。最后一次无参数 `decode()` 不可省略，否则末尾未完成序列不会被验证。字符解码后仍需限制总长度，避免流式输入无限增长。
