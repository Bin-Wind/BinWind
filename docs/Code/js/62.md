# JavaScript crypto.randomUUID：生成临时唯一标识

浏览器的 `crypto.randomUUID()` 会生成符合 UUID v4 格式的随机标识，适合给前端草稿、请求追踪和尚未保存的列表项分配本地 ID。

```javascript
function createDraft(title) {
  return {
    id: crypto.randomUUID(),
    title,
    createdAt: new Date().toISOString(),
  }
}

const drafts = [createDraft('第一条'), createDraft('第二条')]
console.log(drafts)
```

它通常要求安全上下文，也就是 HTTPS 或本地开发环境。使用前可检测能力，并根据目标运行环境提供经过审查的兼容方案；不要用 `Math.random()` 拼接来替代安全随机源。

## 唯一标识不是权限凭证

UUID 适合降低碰撞概率，但不代表对象存在、属于当前用户或允许访问。服务端收到 ID 后仍要验证身份和授权，也应以数据库唯一约束处理极低概率碰撞。若 ID 会出现在 URL 中，不要把邮箱、时间等敏感信息编码进去。

离线创建后同步到服务端时，约定是保留客户端 ID，还是由服务端返回正式 ID，并建立映射。React/Vue 列表键可以使用稳定的业务 ID，但不要在每次渲染时重新调用 `randomUUID()`，否则键不断变化会导致组件反复销毁重建。
