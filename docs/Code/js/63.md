# JavaScript sendBeacon：页面离开时发送少量遥测

页面卸载时启动普通 `fetch`，请求可能在导航完成前被取消。`navigator.sendBeacon` 会把少量数据排入后台发送队列，适合非关键的退出遥测或性能摘要。

```javascript
function sendSessionSummary(summary) {
  const body = new Blob(
    [JSON.stringify(summary)],
    { type: 'application/json' },
  )

  const queued = navigator.sendBeacon('/telemetry/session', body)
  if (!queued) {
    console.warn('遥测未进入发送队列')
  }
}

document.addEventListener('visibilitychange', () => {
  if (document.visibilityState === 'hidden') {
    sendSessionSummary({ durationMs: performance.now() })
  }
})
```

返回 `true` 只表示浏览器接受了排队，不表示服务器处理成功。Beacon 使用 POST，调用方不能读取响应，也不能自由设置请求头；需要确认结果、上传大文件或执行业务事务时不适用。

页面可能多次进入隐藏状态，因此事件要有会话 ID 和序号，服务端按幂等键去重。遥测内容应最小化并遵守用户同意与隐私设置，不把令牌、表单内容或完整 URL 查询参数直接发送。

现代页面比 `unload` 更适合监听 `visibilitychange`，因为后者可能影响返回缓存且在移动端不可靠。关键数据应在操作发生时就持久化，不能把 Beacon 当作最后一刻的可靠提交机制。
