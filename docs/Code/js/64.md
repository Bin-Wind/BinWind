# JavaScript AbortSignal.timeout：为异步操作设置截止时间

只用 `Promise.race` 返回超时错误，并不会停止底层网络请求。`AbortSignal.timeout(ms)` 会在指定时间后中止支持 `AbortSignal` 的操作，适合给 `fetch` 设置截止时间。

```javascript
async function fetchJson(url, timeoutMs = 3000) {
  const response = await fetch(url, {
    signal: AbortSignal.timeout(timeoutMs),
  })
  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`)
  }
  return response.json()
}

try {
  const data = await fetchJson('/api/profile', 2000)
  console.log(data)
} catch (error) {
  if (error.name === 'TimeoutError') {
    console.error('请求超过截止时间')
  } else {
    throw error
  }
}
```

超时是总截止时间的一部分。DNS、连接、响应头与读取正文是否全部受控，要按具体 API 和运行环境验证。取消客户端等待也不保证服务端停止处理，因此有副作用的请求仍需幂等键。

若还要支持用户主动取消，可用 `AbortSignal.any([userSignal, AbortSignal.timeout(2000)])` 合并信号，并根据各信号状态判断原因。创建大量超长超时信号会留下计时资源直到触发，生命周期复杂时可手动使用 `AbortController` 并在 `finally` 中清理定时器。兼容旧环境前先检查目标浏览器支持范围。
