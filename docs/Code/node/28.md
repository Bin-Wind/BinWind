# 使用 node:test 编写零依赖测试

现代 Node.js 内置 `node:test` 测试运行器，适合无需额外框架的单元测试与轻量集成测试。

## 第一个测试

创建 `price.js`：

```js
function discounted(cents, percent) {
  if (!Number.isInteger(cents) || cents < 0) throw new TypeError('invalid cents')
  if (percent < 0 || percent > 100) throw new RangeError('invalid percent')
  return Math.floor(cents * (100 - percent) / 100)
}

module.exports = { discounted }
```

创建 `price.test.js`：

```js
const test = require('node:test')
const assert = require('node:assert/strict')
const { discounted } = require('./price')

test('applies an integer discount', () => {
  assert.equal(discounted(1000, 20), 800)
})

test('rejects invalid percent', () => {
  assert.throws(() => discounted(1000, 101), RangeError)
})
```

运行 `node --test`。需要覆盖率时可使用 `node --test --experimental-test-coverage`，具体可用性取决于 Node 版本。

## 异步与清理

测试函数可以返回 Promise 或声明为 `async`。使用测试上下文的 `after`、`afterEach` 注册清理，确保服务端口、临时文件和数据库连接在失败时也释放。

## 保持可靠

测试不要依赖执行顺序、真实时间和公网服务。对超时与重试使用可控的假实现；集成测试需要真实依赖时，用独立数据库和唯一数据前缀。失败信息应指出行为差异，避免只断言模糊的“truthy”。
