# AsyncLocalStorage：贯穿异步调用的请求上下文

Node.js 服务中的一次请求会跨越多个异步函数。逐层传递请求 ID 很繁琐，`AsyncLocalStorage` 可在同一异步调用链中保存上下文。

```js
import http from 'node:http'
import { AsyncLocalStorage } from 'node:async_hooks'
import { randomUUID } from 'node:crypto'

const context = new AsyncLocalStorage()

function log(message) {
  const requestId = context.getStore()?.requestId ?? 'unknown'
  console.log(JSON.stringify({ requestId, message }))
}

http.createServer((req, res) => {
  context.run({ requestId: req.headers['x-request-id'] ?? randomUUID() }, () => {
    setTimeout(() => {
      log('request completed')
      res.end('ok')
    }, 10)
  })
}).listen(3000)
```

保存为 `server.mjs` 后用 `node server.mjs` 运行。上下文只放小型元数据，不要存请求体或可变的大对象。入口必须用 `run` 建立隔离作用域，不能用全局变量保存当前请求。

某些自定义回调库可能丢失异步上下文，遇到请求 ID 串线时应加入并发测试并检查边界。
