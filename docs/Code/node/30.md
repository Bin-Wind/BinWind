# Node.js Stream 背压：用 pipeline 安全传输大文件

写入端速度低于读取端时，如果持续读入内存，进程会不断积压数据。Stream 的背压机制会让上游暂停；`pipeline` 能正确传播错误并清理流。

```js
import { createReadStream, createWriteStream } from 'node:fs'
import { pipeline } from 'node:stream/promises'
import { createGzip } from 'node:zlib'

await pipeline(
  createReadStream('input.log'),
  createGzip(),
  createWriteStream('input.log.gz')
)

console.log('compressed')
```

保存为 `compress.mjs`，准备 `input.log` 后执行 `node compress.mjs`。`pipeline` 会等待所有阶段完成；任一阶段失败时 Promise 拒绝。

若 `writable.write(chunk)` 返回 `false`，必须等待 `drain` 再继续。直接监听 `data` 并无条件写入，等于绕开背压。

`highWaterMark` 是开始施加背压的缓冲阈值，不是硬内存上限。网络响应还要监听客户端中断，及时停止上游读取。
