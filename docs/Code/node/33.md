# Node.js EventEmitter：监听器生命周期与错误处理

`EventEmitter` 适合进程内的松耦合通知，但监听器忘记移除会持有闭包引用，重复注册还会让一次事件执行多次。

```javascript
import { EventEmitter, once } from 'node:events'

const bus = new EventEmitter()
function onCompleted(job) {
  console.log(`completed: ${job.id}`)
}

bus.on('completed', onCompleted)
bus.emit('completed', { id: 'job-7' })
bus.off('completed', onCompleted)

const controller = new AbortController()
const waiting = once(bus, 'ready', { signal: controller.signal })
bus.emit('ready', { port: 3000 })
console.log((await waiting)[0])
```

需要移除监听器时必须保留同一个函数引用，临时事件用 `once`。为长期组件提供显式 `close()`，统一解除监听器和定时器。

`error` 事件若没有监听器会导致进程抛出异常；应在组件边界处理并决定恢复或退出。事件名与载荷可以形成文档化契约，但 EventEmitter 不会自动校验载荷，也不能替代跨进程消息队列。
