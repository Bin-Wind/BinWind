# Node.js 加密随机数：生成令牌而不是拼接时间戳

密码重置码、会话令牌和 API 密钥需要不可预测。`Math.random()` 和时间戳适合模拟，不适合安全凭证。

```javascript
import { createHash, randomBytes, timingSafeEqual } from 'node:crypto'

function issueToken() {
  const token = randomBytes(32).toString('base64url')
  const digest = createHash('sha256').update(token).digest()
  return { token, digest }
}

function verifyToken(candidate, expectedDigest) {
  const actual = createHash('sha256').update(candidate).digest()
  return actual.length === expectedDigest.length &&
    timingSafeEqual(actual, expectedDigest)
}

const issued = issueToken()
console.log(verifyToken(issued.token, issued.digest))
```

数据库只保存摘要，原始令牌仅在签发时返回一次；泄漏数据库时攻击者不能直接使用摘要登录。令牌同时需要过期时间、用途和使用状态，密码重置令牌成功使用后立即作废。

比较固定长度摘要可使用 `timingSafeEqual`，但它不是完整认证方案。用户密码应交给专门的慢哈希算法与成熟库处理，不要直接用 SHA-256。
