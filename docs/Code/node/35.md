# Node.js readline：用异步迭代逐行处理大文件

`readFile` 会把整个文件载入内存。日志、CSV 或导出数据很大时，可把文件流交给 `readline`，利用异步迭代逐行消费。

```javascript
import { createReadStream } from "node:fs";
import { createInterface } from "node:readline";

async function countErrors(path) {
  const input = createReadStream(path, { encoding: "utf8" });
  const lines = createInterface({ input, crlfDelay: Infinity });
  let count = 0;

  try {
    for await (const line of lines) {
      if (line.includes("ERROR")) count += 1;
    }
    return count;
  } finally {
    lines.close();
    input.destroy();
  }
}

console.log(await countErrors(process.argv[2]));
```

`crlfDelay: Infinity` 可统一处理 Windows 换行。流错误会使迭代抛出异常，调用方仍需决定重试或失败。

逐行不等于内存永远安全：输入可能包含数百 MB 的单行。处理不可信文件时应限制总大小，并使用能限制行长的解析方案。若循环内进行慢速异步工作，天然会形成读取背压；不要无界收集 Promise 又失去这个优势。
