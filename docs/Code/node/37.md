# Node.js 路径边界：安全解析用户提供的文件名

简单拼接 `root + "/" + input` 会接受 `../` 等路径穿越。应先解析到绝对路径，再确认结果仍位于批准目录中。

```javascript
import path from "node:path";

function withinRoot(root, userPath) {
  if (path.isAbsolute(userPath)) throw new Error("不接受绝对路径");
  const base = path.resolve(root);
  const target = path.resolve(base, userPath);
  const relative = path.relative(base, target);

  if (relative === "" || (!relative.startsWith("..") && !path.isAbsolute(relative))) {
    return target;
  }
  throw new Error("路径越界");
}

console.log(withinRoot("./uploads", "images/avatar.png"));
```

字符串前缀判断不可靠：`/data/files-old` 也以 `/data/files` 开头。`path.relative` 会按平台规则处理分隔符。

这段检查仍无法完全防止符号链接把路径引到目录外。处理不可信写入时，使用专用隔离目录、拒绝跟随符号链接，并在打开文件时利用平台支持的安全标志；容器或低权限账户提供最后一道边界。文件名还需限制长度、保留名和允许扩展名。
