# Node.js util.parseArgs：用标准库解析命令行参数

简单 CLI 不必手写 `process.argv` 下标。`node:util` 的 `parseArgs` 可以声明参数类型、短名称与是否允许重复。

```js
import { parseArgs } from 'node:util';

const { values, positionals } = parseArgs({
  options: {
    port: { type: 'string', short: 'p', default: '3000' },
    verbose: { type: 'boolean', short: 'v', default: false },
  },
  allowPositionals: true,
  strict: true,
});

const port = Number(values.port);
if (!Number.isInteger(port) || port < 1 || port > 65535) {
  throw new Error('--port 必须是 1 到 65535 的整数');
}
console.log({ port, verbose: values.verbose, files: positionals });
```

解析类型不等于完成业务验证：字符串仍需转数字并检查范围。错误时返回非零退出码，帮助文本写明默认值和示例。令牌等秘密优先从环境变量或标准输入读取，避免出现在进程列表与 shell 历史中。
