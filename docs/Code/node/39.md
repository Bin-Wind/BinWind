# Node.js AbortSignal.timeout：为异步请求设置截止时间

网络请求若没有截止时间，连接异常时可能长时间占用资源。现代 Node.js 可用 `AbortSignal.timeout` 为支持 AbortSignal 的 API 设置超时。

```js
async function loadJson(url) {
  const response = await fetch(url, {
    signal: AbortSignal.timeout(3000),
  });
  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`);
  }
  return response.json();
}

try {
  console.log(await loadJson('https://example.com/data.json'));
} catch (error) {
  console.error(error.name, error.message);
  process.exitCode = 1;
}
```

超时、主动取消和网络失败可能有不同错误名称，调用方应按语义分类。超时只停止本地等待，不保证远端写操作撤销；写请求重试前需要幂等键。响应体解析也包含在异步流程中，超时预算应覆盖连接、首字节和读取全过程。
