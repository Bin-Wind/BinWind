# Promise.allSettled：收集批量任务的全部结果

批量检查多个独立资源时，一个失败不应遮住其余结果。`Promise.allSettled` 等待所有任务结束，并为每项返回成功或失败状态。

```js
const jobs = [
  Promise.resolve({ id: 1, ok: true }),
  Promise.reject(new Error('服务暂不可用')),
  Promise.resolve({ id: 3, ok: true }),
];

const results = await Promise.allSettled(jobs);
for (const [index, result] of results.entries()) {
  if (result.status === 'fulfilled') {
    console.log(index, result.value);
  } else {
    console.error(index, result.reason.message);
  }
}
```

它不会限制并发，也不会取消无意义的剩余任务。输入很多时应配合并发池；任务彼此依赖或必须全部成功时，`Promise.all` 或显式事务更合适。失败原因可能包含敏感响应，日志只记录必要字段，并最终用汇总状态决定退出码。
