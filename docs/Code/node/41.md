# AbortController：把取消信号传到异步边界

请求超时后若底层工作仍继续，会浪费连接与 CPU。AbortController 提供统一信号，让调用链中的 fetch、计时器或自定义任务及时退出。

~~~js
import { setTimeout as delay } from 'node:timers/promises';

const controller = new AbortController();
setTimeout(() => controller.abort(new Error('deadline exceeded')), 50);
try {
  await delay(500, undefined, { signal: controller.signal });
} catch (error) {
  if (error.name === 'AbortError') console.log('cancelled');
  else throw error;
}
~~~

取消不是失败重试的同义词。接到信号后停止启动新工作，释放资源，并把原因向上传播。组合用户取消与超时时可使用 AbortSignal.any（需确认运行时版本），或手动转发信号。写操作若已提交，还需靠幂等键查询最终状态。
