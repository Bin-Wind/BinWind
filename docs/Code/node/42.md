# AsyncLocalStorage：跨异步调用保留请求上下文

显式传递 requestId 最清楚，但日志调用层层传参很繁琐。AsyncLocalStorage 可为同一异步调用链保存少量追踪上下文。

~~~js
import { AsyncLocalStorage } from 'node:async_hooks';

const context = new AsyncLocalStorage();
function log(message) {
  console.log(context.getStore()?.requestId ?? 'no-request', message);
}
await Promise.all(['a', 'b'].map(requestId =>
  context.run({ requestId }, async () => {
    await Promise.resolve();
    log('done');
  })
));
~~~

把 store 视为不可变小对象，不要塞入请求体、用户会话或可变业务状态。测试并行请求是否串号，第三方回调脱离上下文时在边界显式绑定。它适合日志与追踪，不应替代函数参数中的业务依赖。
