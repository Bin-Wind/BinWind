# worker_threads：把 CPU 密集任务移出事件循环

压缩、解析和纯计算若长时间占用主线程，会让所有网络请求一起变慢。worker_threads 适合把 CPU 工作放到独立 JavaScript 线程。

~~~js
import { Worker } from 'node:worker_threads';

const worker = new Worker(
  'const { parentPort, workerData } = require("node:worker_threads"); parentPort.postMessage(workerData * workerData)',
  { eval: true, workerData: 12 }
);
worker.once('message', value => console.log(value));
worker.once('error', error => console.error(error));
await new Promise(resolve => worker.once('exit', resolve));
~~~

实际服务应复用有界 worker 池，避免每个请求创建线程。消息会复制数据，大对象可考虑 Transferable，但转移后原线程不能再使用该缓冲区。设置任务超时、队列上限与退出处理；I/O 密集工作通常仍用异步 API 更合适。
