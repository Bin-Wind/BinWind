# fs.mkdtemp：为一次任务创建隔离临时目录

固定使用 /tmp/job 容易让并发任务互相覆盖，也可能遇到预先放置的文件。fs.mkdtemp 会在给定前缀后追加随机字符并原子创建目录。

~~~js
import { mkdtemp, rm, writeFile } from 'node:fs/promises';
import { join } from 'node:path';
import { tmpdir } from 'node:os';

const dir = await mkdtemp(join(tmpdir(), 'report-'));
try {
  await writeFile(join(dir, 'result.txt'), 'ok\n', 'utf8');
  console.log(dir);
} finally {
  await rm(dir, { recursive: true, force: true });
}
~~~

前缀应位于系统临时目录内，并使用 path.join 保留目录分隔符。把外部文件名拼入路径前仍要做边界校验。清理放在 finally，但重要产物必须先复制或原子发布到持久位置；进程被强制终止时 finally 不一定执行，因此还需定期清理过期目录。
