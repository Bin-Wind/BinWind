# timers/promises：可取消的异步等待

把 setTimeout 包成手写 Promise 容易忘记清理计时器。node:timers/promises 提供可 await 的延迟，并支持 AbortSignal。

~~~js
import { setTimeout as delay } from 'node:timers/promises';

const controller = new AbortController();
setTimeout(() => controller.abort(), 20);
try {
  await delay(200, 'done', { signal: controller.signal });
} catch (error) {
  if (error.name === 'AbortError') console.log('cancelled');
  else throw error;
}
~~~

重试等待应接受调用方的取消信号，服务关闭或请求截止后立即退出。延迟不是精确定时器，事件循环繁忙时只会更晚触发；业务期限应比较单调时钟或绝对 deadline。不要用长时间 sleep 保持进程存活，调度任务应交给可靠的外部调度器。
