# process.getActiveResourcesInfo：排查进程为何没有退出

测试已经结束但 Node.js 进程仍挂着，通常是计时器、服务器或套接字还在保持事件循环。process.getActiveResourcesInfo 可列出当前活跃资源类型，帮助缩小范围。

~~~js
import process from 'node:process';

const timer = setInterval(() => {}, 1_000);
console.log(process.getActiveResourcesInfo());
clearInterval(timer);
console.log(process.getActiveResourcesInfo());
~~~

输出只给资源类型，不会直接指出创建位置。测试中可结合资源生命周期日志、afterEach 清理和逐步禁用模块定位。不要为了让进程退出而直接 process.exit，这会掩盖未关闭连接并可能截断日志。生产服务应显式关闭监听器、连接池和周期任务，并设置有限的优雅退出期限。
