# Node.js fs.open('wx')：原子创建任务占用文件

先用 `existsSync` 检查再创建文件存在竞态：两个进程可能同时看到“不存在”。`wx` 标志让“仅当文件不存在时创建”成为一次原子文件系统操作。

~~~javascript
import { open, unlink } from 'node:fs/promises'

const lockPath = './daily-job.lock'
let handle

try {
  handle = await open(lockPath, 'wx', 0o600)
  await handle.writeFile(`${process.pid}\n`)
  console.log('task acquired')
} catch (error) {
  if (error.code === 'EEXIST') {
    console.error('task is already running')
    process.exitCode = 1
  } else {
    throw error
  }
} finally {
  if (handle) {
    await handle.close()
    await unlink(lockPath).catch(() => {})
  }
}
~~~

占用文件只能协调共享同一可靠文件系统的进程。进程崩溃会留下陈旧文件，因此生产实现需写入进程标识与开始时间，并在确认原持有者已失效后再清理；不能只凭“超过五分钟”删除仍在运行的任务。

网络文件系统的排他语义可能不同。跨多台主机的任务应使用数据库唯一约束、租约服务或调度器提供的互斥能力。
