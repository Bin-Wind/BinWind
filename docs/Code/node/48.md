# Node.js timingSafeEqual：安全比较消息摘要

验证 HMAC 时，普通字符串比较可能在不同前缀处提前结束，暴露细微时间差。先把接收到的十六进制摘要严格解码，再用 `timingSafeEqual` 比较等长 Buffer。

~~~javascript
import { createHmac, timingSafeEqual } from 'node:crypto'

function verify(body, receivedHex, secret) {
  if (!/^[0-9a-f]{64}$/i.test(receivedHex)) return false

  const expected = createHmac('sha256', secret).update(body).digest()
  const received = Buffer.from(receivedHex, 'hex')
  return received.length === expected.length &&
    timingSafeEqual(received, expected)
}

const body = Buffer.from('{"event":"demo"}')
const secret = 'local-demo-key'
const signature = createHmac('sha256', secret).update(body).digest('hex')
console.log(verify(body, signature, secret))
~~~

签名必须覆盖请求的原始字节；先解析 JSON 再重新序列化会改变空格和键顺序。生产密钥从安全存储读取，并同时验证时间戳与一次性标识，限制截获请求被重放。

`timingSafeEqual` 只保护最终比较，不会自动消除周围代码的所有侧信道。长度、编码和算法应在固定规则下校验，错误响应也不要泄露“格式正确但摘要错误”等额外信息。
