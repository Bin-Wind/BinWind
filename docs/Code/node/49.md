# Node.js HTTP 超时组合：限制慢连接占用

HTTP 服务需要分别限制请求头、完整请求和空闲连接。单独设置一个超时无法覆盖慢速发送请求头、长时间上传和 keep-alive 占用。

~~~javascript
import http from 'node:http'

const server = http.createServer((request, response) => {
  request.resume()
  request.on('end', () => {
    response.writeHead(200, { 'content-type': 'text/plain' })
    response.end('ok\n')
  })
})

server.headersTimeout = 5_000
server.requestTimeout = 15_000
server.keepAliveTimeout = 5_000
server.setTimeout(10_000, socket => socket.destroy())

server.listen(3000, '127.0.0.1', () => {
  console.log('listening on http://127.0.0.1:3000')
})
~~~

数值应大于合法客户端在真实网络下的需要，并与前置代理的超时顺序配合：外层期限略长于内层，才能让应用先返回可识别错误。上传接口可单独设置更合适的限制，但仍需请求体大小上限。

超时后要确保 socket 和正在进行的业务工作都被取消。监控各类超时、活跃连接和事件循环延迟，再通过慢客户端测试验证配置，而不是只确认普通请求成功。
