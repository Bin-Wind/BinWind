# Node.js events.once：等待一次事件并支持取消

`events.once()` 把一次性事件转换为 Promise，适合等待服务器监听、流完成或自定义任务信号。它会同时关注 EventEmitter 的 `error` 事件，并可用 `AbortSignal` 取消等待。

```javascript
import { EventEmitter, once } from 'node:events';

const worker = new EventEmitter();
const controller = new AbortController();
const timer = setTimeout(() => controller.abort(), 1_000);

setTimeout(() => worker.emit('ready', { port: 3000 }), 50);

try {
  const [info] = await once(worker, 'ready', {
    signal: controller.signal,
  });
  console.log(info.port);
} finally {
  clearTimeout(timer);
}
```

事件参数以数组返回，因为一个事件可以携带多个参数。等待期间 emitter 发出 `error` 时，Promise 会拒绝；如果等待的事件本身就是 `error`，则按普通事件处理。

## 先建立等待再触发

EventEmitter 不会重放历史事件。必须先调用 `once` 注册监听，再启动可能同步发出事件的操作。等待多个可能很快发生的事件时，先创建所有 Promise，再 `await Promise.all`。

取消只会移除这次等待的监听器，不会自动停止底层任务。还应把同一个 `AbortSignal` 传给实际 IO，或在捕获 `AbortError` 后显式清理任务。
