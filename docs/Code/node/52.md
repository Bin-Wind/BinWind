# Node.js crypto.randomUUID：生成标识而不是安全口令

`crypto.randomUUID()` 使用加密安全随机源生成 RFC 4122 版本 4 UUID，适合请求 ID、任务 ID 和无需排序的公开标识。它不是口令哈希，也不应替代访问令牌的权限校验。

```javascript
import { randomUUID } from 'node:crypto';

const request = {
  id: randomUUID(),
  createdAt: new Date().toISOString(),
};

console.log(request);
```

UUID 提供很大的随机空间，但数据库仍应设置唯一约束，并在极罕见冲突时重试。不要从 ID 中推断创建时间、地区或用户身份。

## 令牌需要不同处理

重置密码等机密令牌可使用 `randomBytes` 产生足够熵并进行 URL 安全编码：

```javascript
import { randomBytes } from 'node:crypto';

const token = randomBytes(32).toString('base64url');
```

服务端只保存令牌摘要、用途和到期时间，验证后立即作废。UUID 即使随机，也不自动具备一次性、过期或权限范围。

## 可观测性边界

请求 ID 可以出现在日志和响应头中，但不要把用户邮箱、数据库主键等敏感信息编码进 ID。跨服务传播同一请求 ID 时要限制长度和字符集，外部传入值不能未经清洗直接进入日志格式。
