# Node.js crypto.scrypt：为口令派生可验证摘要

口令不能直接使用快速哈希保存。`scrypt` 是内存困难型口令派生函数，配合每条记录独立随机盐，可以提高离线猜测成本。

```javascript
import { randomBytes, scrypt as scryptCallback, timingSafeEqual } from 'node:crypto';
import { promisify } from 'node:util';

const scrypt = promisify(scryptCallback);

async function derive(password, salt) {
  return Buffer.from(await scrypt(password, salt, 64));
}

const salt = randomBytes(16);
const stored = await derive('correct horse battery staple', salt);
const candidate = await derive('correct horse battery staple', salt);
console.log(timingSafeEqual(stored, candidate));
```

数据库保存算法、参数、盐和派生值，并使用版本字段支持将来升级。盐无需保密，但必须随机且不可复用。比较前先确认缓冲区长度一致，再使用 `timingSafeEqual`。

示例使用运行时默认成本，真实服务应根据硬件、并发和登录延迟预算选择参数，并设置服务器资源上限，防止攻击者用大量请求耗尽内存。可额外使用存放在密钥管理系统中的 pepper，但不能把它与数据库放在一起。

新项目也可选择成熟身份库提供的 Argon2id 等方案。无论算法如何，都应加入登录限速、泄露口令检查和多因素认证；哈希本身不能阻止在线猜测。
