# Node.js diagnostics_channel：低耦合发布运行时诊断事件

`node:diagnostics_channel` 允许库发布诊断事件，只有存在订阅者时才交付，适合把可观测性钩子与业务逻辑分开。

```javascript
import diagnosticsChannel from 'node:diagnostics_channel';

const channel = diagnosticsChannel.channel('demo.request');
channel.subscribe(({ id, durationMs }) => {
  console.log({ id, durationMs });
});

const start = performance.now();
channel.publish({ id: 'r-1', durationMs: performance.now() - start });
```

频道名应带稳定命名空间，消息结构也要版本化。订阅回调同步执行，过重处理会直接增加发布路径延迟；应只提取必要字段，再交给异步批处理。

不要发布口令、令牌或完整请求体。`hasSubscribers` 可在构造昂贵诊断数据前快速判断，但发布者仍应保证没有订阅时业务行为完全相同。订阅器抛错也要通过测试隔离，避免观测代码影响生产请求。
