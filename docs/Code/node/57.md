# Node.js fs.statfs：在写入前观察文件系统容量

`fs.statfs` 返回挂载文件系统的块数与可用块，可在大型导出或缓存预热前做容量预检。

```javascript
import { statfs } from 'node:fs/promises';

const info = await statfs('.');
const available = BigInt(info.bavail) * BigInt(info.bsize);
console.log(`${available / 1024n / 1024n} MiB available`);
```

数值可能很大，转为 `BigInt` 后计算可避免超过安全整数范围。`bavail` 通常更接近普通进程可使用的块数，而 `bfree` 可能包含保留空间；具体语义仍受平台影响。

预检不是写入保证：检查后其他进程仍可能占满磁盘，配额、inode 和稀疏文件也会改变结果。真正写入必须处理 `ENOSPC`，采用临时文件与原子替换，并为失败清理留出空间。监控时还应同时关注 inode 与目标挂载点，不能误查父路径所在磁盘。
