# Node.js Readable.fromWeb：桥接 Web Stream 与 Node 流

Node 内置 `fetch` 的响应体是 Web `ReadableStream`，而许多文件与压缩 API 使用 Node 流。`Readable.fromWeb` 可以把两者接入同一条带背压管线。

```javascript
import { Readable } from 'node:stream';
import { pipeline } from 'node:stream/promises';
import { createWriteStream } from 'node:fs';

const response = await fetch('https://example.com/');
if (!response.ok || !response.body) throw new Error(`HTTP ${response.status}`);
await pipeline(Readable.fromWeb(response.body), createWriteStream('page.html'));
```

`pipeline` 会传播错误并在失败时销毁相关流，比手工监听 `data` 更可靠。下载前仍要检查状态码、内容类型和大小上限；不可信 URL 还需防范服务端请求伪造。

取消时把 `AbortSignal` 同时传给 fetch 与管线相关逻辑，避免一端停止而另一端继续等待。Web 流与 Node 流对对象模式、编码和队列策略的定义不同，桥接二进制数据时应明确使用字节块并做集成测试。
