# Node.js crypto.timingSafeEqual：等长缓冲区的恒定时间比较

比较 Webhook 摘要或认证标签时，普通字符串比较可能因首个差异位置不同而提前结束。`timingSafeEqual` 能降低这类时序信息，但要求两个缓冲区长度相同。

```js
import { createHmac, timingSafeEqual } from 'node:crypto';

function verify(body, receivedHex, secret) {
  const expected = createHmac('sha256', secret).update(body).digest();
  if (!/^[0-9a-f]{64}$/i.test(receivedHex)) return false;
  const received = Buffer.from(receivedHex, 'hex');
  return received.length === expected.length && timingSafeEqual(received, expected);
}

const body = Buffer.from('{"event":"paid"}');
const secret = 'demo-secret';
const signature = createHmac('sha256', secret).update(body).digest('hex');
console.log(verify(body, signature, secret));
```

必须对原始请求字节计算摘要，不能先解析再重新序列化。还需验证时间戳并防重放；常量时间比较只解决比较阶段，不会修复弱密钥或错误的签名协议。
