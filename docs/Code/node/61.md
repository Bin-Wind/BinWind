# Node.js fs.opendir：用异步迭代逐项读取目录

`readdir()` 会一次返回全部目录项；超大目录更适合用 `opendir()` 流式迭代，便于施加数量限制和及时响应取消。

```js
import { opendir } from 'node:fs/promises';

async function listFiles(path, limit = 100) {
  const names = [];
  const directory = await opendir(path);
  try {
    for await (const entry of directory) {
      if (entry.isFile()) names.push(entry.name);
      if (names.length >= limit) break;
    }
  } finally {
    await directory.close().catch((error) => {
      if (error.code !== 'ERR_DIR_CLOSED') throw error;
    });
  }
  return names;
}

console.log(await listFiles('.'));
```

异步迭代完成时目录通常会自动关闭，`finally` 让提前退出路径也清晰可查。`Dirent` 反映遍历时的信息，真正读取文件前仍要处理文件被替换、删除或权限变化。
