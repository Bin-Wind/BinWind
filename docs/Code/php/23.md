# Composer 依赖管理与自动加载

Composer 负责声明 PHP 包依赖、解析兼容版本并生成自动加载器。`composer.json` 表达允许范围，`composer.lock` 固定一次可复现的安装结果。

## 初始化项目

```bash
mkdir demo && cd demo
composer init --name=example/demo --no-interaction
composer require monolog/monolog:^3.0
```

应用项目通常应提交 `composer.lock`，部署使用：

```bash
composer install --no-dev --prefer-dist --classmap-authoritative
```

`install` 按锁文件安装；`update` 会重新求解版本并改写锁文件，不应在生产部署时随意执行。

## 配置自己的命名空间

```json
{
  "autoload": {
    "psr-4": {
      "App\\": "src/"
    }
  }
}
```

创建 `src/Greeting.php`：

```php
<?php
namespace App;

final class Greeting
{
    public static function hello(string $name): string
    {
        return "Hello, {$name}";
    }
}
```

修改自动加载配置后执行 `composer dump-autoload`。入口只需 `require __DIR__ . '/vendor/autoload.php';`，无需手工包含每个类文件。

## 安全与维护

定期运行 `composer audit` 检查已知安全公告；升级前在分支中执行测试。不要直接编辑 `vendor`，因为下次安装会覆盖。私有仓库凭据放在本机或 CI 的认证配置中，不提交到项目。
