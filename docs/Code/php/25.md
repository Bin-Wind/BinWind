# PHPUnit 单元测试入门

单元测试应快速、确定，并聚焦一个行为。先从纯函数和领域规则开始，比直接测试整个 Web 请求更容易建立稳定反馈。

## 项目配置

```bash
composer require --dev phpunit/phpunit:^11
mkdir -p src tests
```

创建 `src/Price.php`：

```php
<?php
namespace App;

final class Price
{
    public static function discounted(int $cents, int $percent): int
    {
        if ($cents < 0 || $percent < 0 || $percent > 100) {
            throw new \InvalidArgumentException('invalid input');
        }
        return intdiv($cents * (100 - $percent), 100);
    }
}
```

创建 `tests/PriceTest.php`：

```php
<?php
use PHPUnit\Framework\TestCase;
use App\Price;

final class PriceTest extends TestCase
{
    public function testAppliesDiscount(): void
    {
        self::assertSame(800, Price::discounted(1000, 20));
    }

    public function testRejectsInvalidPercent(): void
    {
        $this->expectException(InvalidArgumentException::class);
        Price::discounted(1000, 101);
    }
}
```

确认 `composer.json` 已按 PSR-4 映射 `App\\` 到 `src/`，再执行 `composer dump-autoload` 和 `vendor/bin/phpunit tests`。

## 测试边界

覆盖正常值、边界值与异常值。时间、随机数和外部服务通过接口注入，避免测试依赖真实网络。Mock 用来隔离昂贵边界，不要把每个内部方法都 Mock 掉，否则重构会造成大量无意义失败。
