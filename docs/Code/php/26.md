# PHP strict_types 与值对象：让输入边界更明确

PHP 的严格类型声明可以减少隐式转换造成的意外。它只影响当前文件发起的标量类型调用，因此应在项目源文件中一致启用。

```php
<?php
declare(strict_types=1);

final readonly class Money
{
    public function __construct(
        public int $cents,
        public string $currency
    ) {
        if ($cents < 0) {
            throw new InvalidArgumentException('cents must be non-negative');
        }
        if (!preg_match('/^[A-Z]{3}$/', $currency)) {
            throw new InvalidArgumentException('invalid currency');
        }
    }

    public function add(self $other): self
    {
        if ($this->currency !== $other->currency) {
            throw new InvalidArgumentException('currency mismatch');
        }
        return new self($this->cents + $other->cents, $this->currency);
    }
}

echo (new Money(1200, 'CNY'))->add(new Money(300, 'CNY'))->cents;
```

示例需要 PHP 8.2；较早版本可改为私有属性与只读访问方法。金额用最小货币单位整数，避免二进制浮点误差。

值对象在构造时完成校验，后续代码便无需反复判断。数据库、HTTP 和命令行输入仍是不可信字符串，应先解析再创建值对象。
