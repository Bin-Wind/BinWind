# PHP 密码存储：password_hash 与安全验证

密码不能明文保存，也不应使用通用快速哈希。PHP 内置密码 API 会生成带盐的慢哈希，并把算法参数编码在结果中。

```php
<?php
declare(strict_types=1);

$plain = 'correct horse battery staple';
$hash = password_hash($plain, PASSWORD_DEFAULT);
if ($hash === false) {
    throw new RuntimeException('hashing failed');
}

var_dump(password_verify($plain, $hash));
if (password_needs_rehash($hash, PASSWORD_DEFAULT)) {
    $hash = password_hash($plain, PASSWORD_DEFAULT);
}
```

数据库字段要给哈希预留足够长度，例如 `VARCHAR(255)`。登录成功后检查是否需要升级参数，再用同一明文生成新哈希。

查询不到用户时也执行一次固定的伪哈希验证，降低通过响应时间枚举账号的风险。失败提示统一为“账号或密码错误”，并配合速率限制、审计日志和多因素认证。

重置密码应使用随机、短时、一次性的令牌；数据库只保存令牌哈希。不要通过邮件发送原密码，也不要在日志中记录密码或重置令牌。
