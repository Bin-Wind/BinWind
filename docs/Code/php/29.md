# PHP 枚举与 match：把有限状态写进类型

订单状态若用任意字符串表示，拼写错误直到运行到冷门分支才暴露。PHP 8.1 的 backed enum 可以同时提供类型约束和稳定存储值。

```php
<?php
declare(strict_types=1);

enum OrderStatus: string
{
    case Pending = 'pending';
    case Paid = 'paid';
    case Cancelled = 'cancelled';
}

function label(OrderStatus $status): string
{
    return match ($status) {
        OrderStatus::Pending => '待支付',
        OrderStatus::Paid => '已支付',
        OrderStatus::Cancelled => '已取消',
    };
}

$status = OrderStatus::tryFrom($argv[1] ?? '')
    ?? throw new InvalidArgumentException('未知状态');
echo label($status), PHP_EOL;
```

外部输入使用 `tryFrom` 并显式处理失败；确定可信的数据可用 `from`，未知值会抛出异常。`match` 使用严格比较且必须覆盖分支，比宽松的 `switch` 更适合有限状态。

数据库仍保存枚举的 `value`，业务层尽早转换为枚举。新增状态时，让未覆盖的 `match` 在测试中暴露，比静默落入默认分支更安全。
