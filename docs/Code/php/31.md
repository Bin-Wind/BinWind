# PHP 流式处理 CSV：避免一次读入全部数据

`file()` 会把整个文件载入内存，大型导入很容易触及限制。`SplFileObject` 可以逐行读取，并由生成器向下游提供记录。

```php
<?php
declare(strict_types=1);

function rows(string $path): Generator
{
    $file = new SplFileObject($path, 'rb');
    $file->setFlags(SplFileObject::READ_CSV | SplFileObject::SKIP_EMPTY);
    $header = $file->fgetcsv();
    if (!is_array($header)) throw new RuntimeException('缺少表头');

    foreach ($file as $row) {
        if (!is_array($row) || $row === [null]) continue;
        if (count($row) !== count($header)) {
            throw new RuntimeException('列数不一致');
        }
        yield array_combine($header, $row);
    }
}

foreach (rows($argv[1]) as $row) echo $row['name'], PHP_EOL;
```

导入前明确编码、分隔符、引号规则和最大字段长度。每批若干行提交一次数据库事务，并记录最后成功的行号；全文件一个事务可能持锁太久，逐行提交又会过慢。

遇到坏行时选择“立即失败”或写入错误报告，不能静默跳过。若表格可能来自电子表格软件，还要防范以 `= + - @` 开头的单元格在导出后触发表格公式。
