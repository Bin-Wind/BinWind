# PHP SPL 迭代器：逐行处理大型文本

大文件不应使用 `file()` 一次读入内存。`SplFileObject` 实现迭代器，可逐行读取并保留清晰的异常边界。

```php
<?php
declare(strict_types=1);

function nonEmptyLines(string $path): Generator
{
    $file = new SplFileObject($path, 'rb');
    $file->setFlags(
        SplFileObject::DROP_NEW_LINE |
        SplFileObject::SKIP_EMPTY
    );

    foreach ($file as $lineNumber => $line) {
        if (!is_string($line)) {
            continue;
        }
        yield $lineNumber + 1 => trim($line);
    }
}

foreach (nonEmptyLines(__FILE__) as $number => $line) {
    printf("%d: %s\n", $number, $line);
}
```

生成器让调用方按需消费结果，不会累计全部行。读取 CSV 时可启用 `READ_CSV` 并设置分隔符，但仍要验证列数、编码和字段长度。

不要把超长单行当成普通输入；在日志、上传文件等不可信来源上设置文件大小与行长限制。需要从中途恢复时记录字节偏移和文件摘要，单独的行号无法判断文件是否已被替换。
