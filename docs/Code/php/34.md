# PHP DateTimeImmutable：跨时区时间计算不再互相污染

`DateTimeImmutable` 的修改方法返回新对象，适合在多步计算中避免共享对象被意外改变。持久化时间建议统一使用 UTC，展示时再转换到用户时区。

```php
<?php
declare(strict_types=1);

$sourceZone = new DateTimeZone('Asia/Shanghai');
$displayZone = new DateTimeZone('Europe/Paris');

$meeting = DateTimeImmutable::createFromFormat(
    '!Y-m-d H:i',
    '2026-09-11 09:30',
    $sourceZone
);
if ($meeting === false) {
    throw new RuntimeException('时间格式错误');
}

$utc = $meeting->setTimezone(new DateTimeZone('UTC'));
echo $utc->format(DateTimeInterface::ATOM), PHP_EOL;
echo $utc->setTimezone($displayZone)->format('Y-m-d H:i T'), PHP_EOL;
```

`!` 会把未提供的字段重置，避免继承当前日期或时间。严格输入还应检查 `getLastErrors()` 中的警告，例如不存在的日期被自动归一化。

“一天后”和“24 小时后”在夏令时切换地区可能不同：日历计划用 `P1D`，精确时长用秒或时间戳表达。数据库同时保存 UTC 时刻与原始时区标识，才能正确重建未来的本地日程。
