# PHP flock：用文件锁保护临界区

多个 PHP 进程同时更新同一文件时，“读取—修改—写回”会丢失数据。`flock` 可在同一主机、支持锁语义的文件系统上协调访问。

```php
<?php
declare(strict_types=1);

$path = __DIR__ . '/counter.txt';
$handle = fopen($path, 'c+');
if ($handle === false) {
    throw new RuntimeException('无法打开文件');
}

try {
    if (!flock($handle, LOCK_EX)) {
        throw new RuntimeException('无法取得文件锁');
    }
    rewind($handle);
    $value = (int) stream_get_contents($handle);
    ftruncate($handle, 0);
    rewind($handle);
    fwrite($handle, (string) ($value + 1));
    fflush($handle);
    flock($handle, LOCK_UN);
} finally {
    fclose($handle);
}
```

所有访问者必须遵守同一锁协议。网络文件系统上的行为需按部署环境验证；高并发计数、跨主机协调或需要事务时，应使用数据库等合适存储。锁内只做必要工作，并为无法获取锁设计超时或失败策略。
