# PHP random_bytes：生成不可预测的安全令牌

重置链接、邀请令牌和会话标识不能由时间戳、用户名或 `mt_rand()` 拼接，因为这些值可被预测。`random_bytes` 使用适合密码学场景的随机源。

```php
<?php
declare(strict_types=1);

$token = bin2hex(random_bytes(32));
$storedHash = hash('sha256', $token);

echo "只发送一次的令牌: {$token}\n";
echo "数据库保存摘要: {$storedHash}\n";
```

数据库保存摘要、用途、用户、创建时间和过期时间；用户提交令牌后重新计算摘要，并用 `hash_equals` 比较。验证成功后立即标记为已使用，整个过程放进事务，防止并发重复兑换。

令牌不要进入访问日志、分析参数或 Referer。URL 中的令牌应短期有效，页面加载后尽快兑换为受保护会话。若怀疑泄漏，应能批量撤销对应用途的未使用令牌。
