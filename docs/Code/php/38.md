# PHP array_is_list：避免 JSON 数组意外变成对象

json_encode 会把连续的 0 开始整数键编码为数组，键有缺口时则编码为对象。过滤元素后未重建索引，是接口形状突然变化的常见原因。

~~~php
<?php
declare(strict_types=1);

$values = [10, 20, 30];
$filtered = array_filter($values, fn(int $v): bool => $v >= 20);
if (!array_is_list($filtered)) {
    $filtered = array_values($filtered);
}
echo json_encode($filtered, JSON_THROW_ON_ERROR) . PHP_EOL;
~~~

接口层先定义字段究竟是列表还是键值映射，并在编码前断言。array_values 会重建数字索引，但不应盲目用于有语义键的数组。启用 JSON_THROW_ON_ERROR，避免编码失败后把 false 当作合法响应继续发送。
