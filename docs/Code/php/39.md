# PHP hash_equals：安全比较 Webhook 摘要

签名摘要不能用普通字符串相等直接比较。hash_equals 使用与匹配前缀无关的比较过程，减少通过响应时间推测摘要的风险。

~~~php
<?php
declare(strict_types=1);

$secret = 'local-demo-secret';
$body = '{"event":"paid"}';
$received = hash_hmac('sha256', $body, $secret);
$expected = hash_hmac('sha256', $body, $secret);
if (!hash_equals($expected, $received)) {
    http_response_code(401);
    exit('invalid signature');
}
echo "verified\n";
~~~

实际处理必须对原始请求字节计算摘要，不能先解析再重新编码 JSON。先检查签名格式与长度，密钥来自安全配置。若协议包含时间戳，还要限制可接受窗口并保存事件 ID 防重放；签名正确只证明来源，不代表业务事件可重复执行。
