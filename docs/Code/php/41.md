# PHP hash_file：复制后校验文件内容

仅比较文件大小无法发现静默损坏。对下载或备份文件可计算 SHA-256，并与通过可信渠道获得的期望摘要比较。

~~~php
<?php
declare(strict_types=1);

$path = tempnam(sys_get_temp_dir(), 'checksum-');
if ($path === false) throw new RuntimeException('cannot create temp file');
try {
    file_put_contents($path, "verified content\n");
    $expected = hash('sha256', "verified content\n");
    $actual = hash_file('sha256', $path);
    if ($actual === false || !hash_equals($expected, $actual)) {
        throw new RuntimeException('file checksum mismatch');
    }
    echo "verified\n";
} finally {
    unlink($path);
}
~~~

摘要只能证明内容与期望值相同；如果文件与摘要来自同一个被篡改位置，校验没有意义。处理大文件时 hash_file 会流式读取，但仍要考虑 I/O 压力。校验期间应避免源文件被并发修改，发布流程可先写入临时路径，校验成功后再原子重命名。
