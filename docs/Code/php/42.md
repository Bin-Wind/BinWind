# PHP parse_url 后的主机白名单：约束服务端外部请求

允许用户提供回调或抓取 URL 时，只检查字符串前缀可能被 userinfo、大小写和重定向绕过。应解析 URL 并对规范化后的 scheme、host 和 port 做白名单判断。

~~~php
<?php
declare(strict_types=1);

function assertAllowedUrl(string $url): void {
    $parts = parse_url($url);
    if ($parts === false) throw new InvalidArgumentException('invalid URL');
    $scheme = strtolower($parts['scheme'] ?? '');
    $host = strtolower(rtrim($parts['host'] ?? '', '.'));
    if ($scheme !== 'https' || $host !== 'api.example.com') {
        throw new InvalidArgumentException('URL is not allowed');
    }
}

assertAllowedUrl('https://api.example.com/v1/status');
~~~

真实 SSRF 防护还要在连接时校验 DNS 解析结果，拒绝回环、私网和链路本地地址，并对每次重定向重复检查。固定允许端口，限制响应大小和超时。应用层白名单应配合网络出口策略，不能只依赖 parse_url。
