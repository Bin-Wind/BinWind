# PHP SplFileObject：逐行读取 CSV 并保留错误边界

大型 CSV 不应一次读入内存。SplFileObject 可以迭代读取，并让解析选项集中在文件对象上。

~~~php
<?php
declare(strict_types=1);

$file = new SplFileObject(__DIR__ . '/sample.csv', 'w+');
$file->fputcsv(['id', 'name']);
$file->fputcsv(['1', 'Alice']);
$file->rewind();
$file->setFlags(SplFileObject::READ_CSV | SplFileObject::SKIP_EMPTY);
foreach ($file as $row) {
    if ($row === [null] || $row === false) continue;
    echo implode('|', $row) . PHP_EOL;
}
~~~

生产导入先确认编码、分隔符、表头和最大字段长度；每行校验列数与类型，并用行号记录错误。不要把电子表格公式前缀原样导出给不可信用户，以免形成公式注入。数据库写入采用有界批次和事务，失败时能定位并重放，而不是整文件静默跳过。
