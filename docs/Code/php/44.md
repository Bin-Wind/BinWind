# PHP JsonException：让无效 JSON 立即失败

`json_decode` 默认通过全局错误状态报告失败，调用者很容易忘记检查。使用 `JSON_THROW_ON_ERROR` 后，无效 JSON 会抛出 `JsonException`，边界更清楚。

~~~php
<?php
declare(strict_types=1);

function decodeObject(string $json): array
{
    $value = json_decode($json, true, 32, JSON_THROW_ON_ERROR);
    if (!is_array($value) || array_is_list($value)) {
        throw new InvalidArgumentException('JSON object required');
    }
    return $value;
}

try {
    $data = decodeObject('{"name":"BinWind","active":true}');
    echo $data['name'], PHP_EOL;
} catch (JsonException | InvalidArgumentException $error) {
    fwrite(STDERR, $error->getMessage() . PHP_EOL);
    exit(1);
}
~~~

解析成功只代表语法有效，不代表字段可信。随后仍需验证必填键、类型、长度和允许值。`depth` 应按实际结构设置上限，避免异常深的输入消耗资源。

接口响应错误时不要把原始敏感 JSON 或完整解析异常返回给外部；给客户端稳定错误码，把脱敏后的诊断信息写入内部日志。
