# PHP finfo：根据文件内容校验上传类型

浏览器提交的文件名和 MIME 类型都可伪造。服务端应先检查上传错误与大小，再使用 Fileinfo 扩展读取临时文件的实际内容类型。

~~~php
<?php
declare(strict_types=1);

function validateUpload(array $file): string
{
    if (($file['error'] ?? UPLOAD_ERR_NO_FILE) !== UPLOAD_ERR_OK) {
        throw new RuntimeException('upload failed');
    }
    if (!is_uploaded_file($file['tmp_name']) || $file['size'] > 2_000_000) {
        throw new RuntimeException('invalid upload');
    }

    $mime = (new finfo(FILEINFO_MIME_TYPE))->file($file['tmp_name']);
    $extensions = ['image/jpeg' => 'jpg', 'image/png' => 'png'];
    if (!isset($extensions[$mime])) {
        throw new RuntimeException('unsupported file type');
    }
    return $extensions[$mime];
}
~~~

校验通过后生成随机文件名，并用 `move_uploaded_file` 移到不可执行的专用目录；不要沿用用户文件名作为路径。图片业务还应尝试用图像库解码并限制像素尺寸，因为合法头部之后仍可能是损坏或超大文件。

内容检测只能降低风险，不能证明文件安全。公开下载时设置准确的 `Content-Type`、`Content-Disposition` 和嗅探保护，并对高风险格式使用隔离扫描流程。
