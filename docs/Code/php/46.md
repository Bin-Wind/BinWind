# PHP sodium_crypto_secretbox：认证加密敏感值

libsodium 的 `sodium_crypto_secretbox` 同时提供加密和完整性校验，适合保护需要恢复的短小配置值。密钥必须来自密钥管理系统或安全注入，不能和密文放在同一配置文件。

~~~php
<?php
declare(strict_types=1);

function encrypt(string $plain, string $key): string
{
    $nonce = random_bytes(SODIUM_CRYPTO_SECRETBOX_NONCEBYTES);
    $cipher = sodium_crypto_secretbox($plain, $nonce, $key);
    return base64_encode($nonce . $cipher);
}

function decrypt(string $encoded, string $key): string
{
    $packed = base64_decode($encoded, true);
    if ($packed === false || strlen($packed) < SODIUM_CRYPTO_SECRETBOX_NONCEBYTES) {
        throw new RuntimeException('invalid payload');
    }
    $nonce = substr($packed, 0, SODIUM_CRYPTO_SECRETBOX_NONCEBYTES);
    $cipher = substr($packed, SODIUM_CRYPTO_SECRETBOX_NONCEBYTES);
    $plain = sodium_crypto_secretbox_open($cipher, $nonce, $key);
    if ($plain === false) {
        throw new RuntimeException('authentication failed');
    }
    return $plain;
}

$key = sodium_crypto_secretbox_keygen();
$sealed = encrypt('demo-secret', $key);
echo decrypt($sealed, $key), PHP_EOL;
~~~

每次加密都生成新 nonce，nonce 可与密文一起保存但不能在同一密钥下重复使用。存储时还应记录密钥版本，轮换时才能选择正确密钥解密并逐步重加密。

密码不应可逆加密，应使用 `password_hash`。密钥泄露后加密无法补救，所以访问控制、日志脱敏和轮换流程与算法同样重要。
