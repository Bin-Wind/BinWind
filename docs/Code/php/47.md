# PHP SensitiveParameter：避免敏感参数出现在堆栈中

PHP 8.2 起可用 `#[\SensitiveParameter]` 标记函数参数。发生异常并输出堆栈时，该参数值会被替换为敏感占位对象，降低密码、令牌被日志记录的风险。

```php
<?php
declare(strict_types=1);

function authenticate(
    string $username,
    #[\SensitiveParameter] string $password
): void {
    if ($username === '') {
        throw new InvalidArgumentException('用户名不能为空');
    }
}

authenticate('', 'do-not-log-this');
```

属性只影响调试回溯中的参数展示，不会加密内存、数据库或网络传输，也不会阻止业务代码主动记录 `$password`。日志过滤和最小采集仍然必需。

## 标记真正的秘密

适合标记明文口令、访问令牌、私钥内容和恢复码。对象参数若内部含秘密，标记整个参数，或让对象的调试表示主动隐藏字段。不要因调试不方便而关闭保护。

异常处理器在生产环境不应向客户端返回完整堆栈。测试可以捕获异常并检查字符串化后的 trace 不包含测试秘密；同时检查应用日志、APM 标签和自定义上下文没有另一条泄露路径。
