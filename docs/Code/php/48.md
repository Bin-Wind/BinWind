# PHP stream_context_create：为 HTTP 读取设置明确边界

启用 URL fopen wrapper 后，PHP 可以通过流读取 HTTP 资源。必须显式设置超时、方法和错误处理；对于复杂生产请求，cURL 通常提供更完整的控制。

```php
<?php
declare(strict_types=1);

$context = stream_context_create([
    'http' => [
        'method' => 'GET',
        'timeout' => 3.0,
        'ignore_errors' => true,
        'header' => [
            'Accept: application/json',
            'User-Agent: BinWindExample/1.0',
        ],
    ],
]);

$body = file_get_contents('https://example.com/data.json', false, $context);
if ($body === false) {
    throw new RuntimeException('请求失败');
}
```

`ignore_errors` 只表示在 4xx/5xx 时仍读取响应体，不代表忽略状态码。需要解析 `$http_response_header` 的状态行，并对允许的状态做判断。

## SSRF 与响应上限

URL 来自用户时，必须采用协议与主机白名单，并在 DNS 解析后防止目标落到回环、链路本地或内网地址。重定向也要重新校验目标。简单的 `parse_url` 检查不足以覆盖 DNS 重绑定。

`file_get_contents` 会把响应放入内存。未知或大型内容应使用流式读取并累计字节上限。TLS 证书验证保持默认开启，不通过关闭验证来“修复”证书问题。
