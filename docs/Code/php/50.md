# PHP php://temp：让中间数据超过阈值后自动落盘

生成 CSV、压缩前清洗文本等任务需要一个可读写的中间流。把全部内容拼成字符串会复制内存；`php://temp` 会先使用内存，超过指定阈值后转到临时文件。

```php
<?php
declare(strict_types=1);

$stream = fopen('php://temp/maxmemory:1048576', 'w+b');
if ($stream === false) {
    throw new RuntimeException('无法创建临时流');
}

try {
    fputcsv($stream, ['id', 'name']);
    fputcsv($stream, [1, '示例']);
    rewind($stream);
    while (($line = fgets($stream)) !== false) {
        echo $line;
    }
} finally {
    fclose($stream);
}
```

`maxmemory` 是切换阈值，不是总大小限制。输入不可信时仍要自己限制行数、字段长度和最终字节数，否则临时磁盘同样可能被写满。

流用完必须关闭。需要交给 HTTP 响应时，可逐块复制到输出流，避免再次 `stream_get_contents` 成为大字符串。临时文件位置由 PHP 环境决定；涉及敏感数据时应核对临时目录权限、磁盘加密与容器清理策略。
