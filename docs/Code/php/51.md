# PHP stream_copy_to_stream：限制大文件复制的内存占用

`file_get_contents` 再 `file_put_contents` 会把整个文件放进内存。PHP 的流复制可以边读边写，并返回实际复制的字节数。

```php
<?php
declare(strict_types=1);

$source = fopen(__DIR__ . '/input.bin', 'rb');
$target = fopen(__DIR__ . '/output.bin.part', 'xb');
if ($source === false || $target === false) {
    throw new RuntimeException('无法打开输入或输出');
}

try {
    $copied = stream_copy_to_stream($source, $target, 10 * 1024 * 1024);
    if ($copied === false) {
        throw new RuntimeException('复制失败');
    }
    fflush($target);
    echo "copied={$copied}\n";
} finally {
    fclose($source);
    fclose($target);
}
```

第三个参数限制本次最多复制的字节数，但若输入更大，返回达到上限并不代表输入恰好结束。需要强制总大小时，再读取一个字节判断是否仍有剩余；超限则删除 `.part` 文件。

目标用 `x` 模式避免静默覆盖。生产流程应写到同目录临时名，复制后比较预期大小或摘要，再用 `rename` 发布。远程流还要设置超时并检查流元数据；复制成功只证明字节已读写，不证明业务格式有效。
