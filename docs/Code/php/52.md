# PHP usort：用稳定规则完成多字段排序

`usort` 接收比较器，返回负数、零或正数。比较器应具有传递性，并在主字段相同时明确次级规则，避免页面间顺序抖动。

```php
<?php
declare(strict_types=1);

$rows = [
    ['id' => 3, 'score' => 90],
    ['id' => 1, 'score' => 90],
    ['id' => 2, 'score' => 75],
];

usort($rows, static function (array $a, array $b): int {
    return ($b['score'] <=> $a['score'])
        ?: ($a['id'] <=> $b['id']);
});

print_r($rows);
```

太空船运算符避免用 `$a - $b` 比较大整数时溢出。字符串需要根据业务选择字节、自然排序或区域规则；面向用户的语言排序通常应使用 Intl 扩展的 `Collator`，并固定区域设置。

`usort` 会重新建立数字索引。若必须保留关联键，使用 `uasort`。比较器中不要访问网络、修改数组或返回布尔值，它可能被调用多次且调用顺序不应成为业务逻辑。

数据来自数据库时，分页前应尽量在查询中用同样的完整排序键完成排序；只对当前页在 PHP 中排序，无法保证全局顺序。测试应包含相等主键值、负数、空值策略和已排序输入。
