# PHP fputcsv：按规则输出可交换的 CSV

手工用逗号拼接字段会在内容含逗号、引号或换行时损坏文件。`fputcsv` 会处理必要的引用与转义，并直接写入流。

```php
<?php
$out = fopen('php://output', 'wb');
fputcsv($out, ['name', 'note'], ',', '"', '');
fputcsv($out, ['小林', "包含,逗号与\n换行"], ',', '"', '');
fclose($out);
```

分隔符、包围符、转义符和换行约定应与接收方确认。显式传入空转义符可避免依赖旧式反斜杠转义；字段编码也要统一，CSV 本身不会声明字符集。

来自不可信来源且以 `=`, `+`, `-`, `@` 开头的字段，可能被电子表格当作公式执行。若文件会被办公软件打开，应按产品威胁模型做转义或拒绝，并保留原始值与展示值的区别。大数据量使用流逐行写出，不要先构建完整字符串。
