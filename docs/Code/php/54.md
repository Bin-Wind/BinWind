# PHP hrtime：测量耗时不受系统时钟跳变影响

`microtime(true)` 来自墙上时间，系统校时可能让两个读数突然前跳或后退。`hrtime` 使用单调高精度时钟，更适合测量代码耗时。

```php
<?php
$start = hrtime(true);
usleep(20_000);
$elapsedNs = hrtime(true) - $start;
printf("%.2f ms\n", $elapsedNs / 1_000_000);
```

传入 `true` 时返回纳秒整数；默认返回秒与纳秒组成的数组。它的零点没有日历意义，不能保存为事件发生时间，也不能跨不同机器直接比较。

微基准应预热代码、重复多次并报告分布，避免一次测量被调度、I/O 或缓存状态左右。生产追踪仍需记录墙上时间用于关联事件，同时用单调时钟计算持续时间，两者用途不同。
