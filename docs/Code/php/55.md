# PHP password_needs_rehash：登录时平滑升级口令哈希

口令哈希算法和成本会随硬件与安全要求变化。`password_needs_rehash` 能判断数据库中的旧摘要是否符合当前策略，从而在用户成功登录时逐步升级。

```php
<?php
$stored = password_hash('correct horse', PASSWORD_BCRYPT, ['cost' => 10]);
$options = ['cost' => 12];

if (password_verify('correct horse', $stored) &&
    password_needs_rehash($stored, PASSWORD_BCRYPT, $options)) {
    $stored = password_hash('correct horse', PASSWORD_BCRYPT, $options);
}
echo password_verify('correct horse', $stored) ? "ok\n" : "failed\n";
```

只有在 `password_verify` 成功后才能重算，因为此时才拥有明文口令。更新数据库应避免并发登录互相覆盖，并确保摘要列长度能容纳未来算法结果。

成本参数需在目标生产硬件上压测，兼顾抗破解能力与登录容量。不要自行加密口令或重复哈希；框架限流、多因素认证和泄露口令检查仍是独立防线。
