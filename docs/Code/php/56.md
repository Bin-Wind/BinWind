# PHP http_build_query：按明确规则生成查询字符串

手工拼接查询参数容易漏掉编码，也会在数组和空值上产生歧义。`http_build_query` 能完成百分号编码，但调用方仍要决定哪些键可以发送。

```php
<?php
declare(strict_types=1);

$input = [
    'q' => '咖啡 器具',
    'page' => 2,
    'redirect' => 'https://evil.example/',
];

$allowed = array_intersect_key($input, array_flip(['q', 'page']));
$query = http_build_query($allowed, '', '&', PHP_QUERY_RFC3986);
$url = 'https://search.example.com/results?' . $query;
echo $url, PHP_EOL;
```

`PHP_QUERY_RFC3986` 会把空格编码为 `%20`。同名重复参数、嵌套数组和布尔值在不同服务端的解释可能不同，应根据目标 API 写测试。构造查询字符串也不会自动阻止 SSRF，目标主机仍需独立校验。
