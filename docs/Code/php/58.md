# PHP DatePeriod：生成周期日期并看清结束边界

`DatePeriod` 适合生成报表日期或提醒计划。最容易出错的是结束日期是否包含，以及“每月一次”遇到短月份时的语义。

```php
<?php
declare(strict_types=1);

$timezone = new DateTimeZone('Asia/Shanghai');
$start = new DateTimeImmutable('2026-09-20 09:00:00', $timezone);
$end = new DateTimeImmutable('2026-09-24 09:00:00', $timezone);
$period = new DatePeriod(
    $start,
    new DateInterval('P1D'),
    $end,
    DatePeriod::INCLUDE_END_DATE
);

foreach ($period as $date) {
    echo $date->format(DateTimeInterface::ATOM), PHP_EOL;
}
```

显式时区可避免服务器默认配置改变结果。业务上的“每月最后一天”不要简单从 31 日不断加一个月，应先定义缺失日期如何处理，再按每个月计算目标日。落库时同时保存时区或业务区域。
