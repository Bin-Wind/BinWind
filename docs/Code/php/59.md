# PHP hash_equals：比较签名时避免时序泄漏

验证 Webhook 或消息签名时，普通字符串比较可能在遇到第一个不同字符后提前结束，耗时差异会泄露前缀信息。PHP 的 `hash_equals` 会用适合敏感值的方式比较两个字符串。

```php
<?php
function verifySignature(string $body, string $header, string $secret): bool
{
    if (!str_starts_with($header, 'sha256=')) {
        return false;
    }

    $provided = substr($header, strlen('sha256='));
    $expected = hash_hmac('sha256', $body, $secret);

    return hash_equals($expected, $provided);
}

$body = '{"event":"ping"}';
$secret = 'development-secret';
$signature = 'sha256=' . hash_hmac('sha256', $body, $secret);
var_dump(verifySignature($body, $signature, $secret));
```

已知可信字符串应作为第一个参数，用户提供的字符串放在第二个参数。两者必须都是字符串；长度不同会返回 `false`。

## 比较之前同样重要

签名必须基于收到的原始请求字节，而不是解析 JSON 后重新编码的文本，否则空格和键顺序变化会导致不一致。按平台规范校验算法、前缀与时间戳，并限制允许的时间偏差，防止捕获的旧请求被重放。密钥来自安全配置，不写入源码和日志。

`hash_equals` 只解决最终比较环节，不能弥补弱密钥、错误的签名输入或缺少重放保护。测试应覆盖正文被改动、签名长度错误、过期时间戳和重复事件。
