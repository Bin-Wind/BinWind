# PHP flock：为本机文件更新加互斥锁

两个 PHP 进程同时执行“读取计数—加一—写回”，可能都读到相同旧值并覆盖彼此。`flock` 可以在支持的平台上对打开的文件句柄申请协作锁，让遵守同一约定的进程串行更新。

```php
<?php
function incrementCounter(string $path): int
{
    $handle = fopen($path, 'c+');
    if ($handle === false) {
        throw new RuntimeException('无法打开计数文件');
    }

    try {
        if (!flock($handle, LOCK_EX)) {
            throw new RuntimeException('无法取得文件锁');
        }

        rewind($handle);
        $raw = stream_get_contents($handle);
        $value = $raw === '' ? 0 : (int) trim($raw);
        $value++;

        ftruncate($handle, 0);
        rewind($handle);
        if (fwrite($handle, (string) $value) === false || !fflush($handle)) {
            throw new RuntimeException('写入失败');
        }
        return $value;
    } finally {
        flock($handle, LOCK_UN);
        fclose($handle);
    }
}

echo incrementCounter(sys_get_temp_dir() . '/demo-counter.txt'), PHP_EOL;
```

锁应覆盖完整的读取、计算和写回过程，且所有写入者必须使用同一个锁目标。`LOCK_NB` 可实现非阻塞尝试，但失败后要有明确重试或返回策略。

文件锁通常是协作式的，不能阻止不使用 `flock` 的程序修改文件；网络文件系统上的语义也需按环境验证。多机服务或关键事务应使用数据库原子更新、分布式协调或专门存储，而不是把本机文件锁当作全局锁。
