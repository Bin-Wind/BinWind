# dataclass：让数据对象更清晰

`dataclasses` 能自动生成初始化、比较和打印方法，适合表达配置、值对象与函数间传递的数据。它不是完整验证框架，外部输入仍需显式校验。

## 基础用法

```python
from dataclasses import dataclass, field

@dataclass(frozen=True, slots=True)
class Product:
    sku: str
    price_cents: int
    tags: tuple[str, ...] = field(default_factory=tuple)

    def __post_init__(self) -> None:
        if not self.sku.strip():
            raise ValueError("sku cannot be empty")
        if self.price_cents < 0:
            raise ValueError("price cannot be negative")

p = Product("BOOK-001", 5900, ("python",))
print(p)
```

`frozen=True` 防止实例创建后意外修改，`slots=True` 减少属性拼写错误和部分内存开销。两者是否启用应由对象语义决定，而非一律开启。

## 避免可变默认值

列表、字典等默认值必须使用工厂：

```python
@dataclass
class Cart:
    items: list[str] = field(default_factory=list)
```

这样每个实例拥有独立列表。直接写 `items = []` 会造成实例间共享状态，而且 dataclass 会对此报错。

## 转换与复制

`dataclasses.asdict()` 会递归复制嵌套结构，深层大对象可能成本较高。修改不可变对象可用 `dataclasses.replace(product, price_cents=6900)`。

当对象需要复杂解析、跨字段错误报告或 JSON Schema 时，应引入专门验证层；dataclass 保持领域模型简单。一个好数据对象应让无效状态难以出现，而不是仅减少样板代码。
