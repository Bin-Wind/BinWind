# Python 上下文管理器：可靠释放资源

上下文管理器把“获取资源”和“无论成功失败都释放资源”绑定在一起。文件、锁、数据库连接和临时配置都适合使用 `with`，避免异常路径漏掉清理。

## 类实现方式

```python
class ManagedFile:
    def __init__(self, path: str):
        self.path = path
        self.file = None

    def __enter__(self):
        self.file = open(self.path, "w", encoding="utf-8")
        return self.file

    def __exit__(self, exc_type, exc, traceback):
        self.file.close()
        return False

with ManagedFile("demo.txt") as stream:
    stream.write("hello\n")
```

`__exit__` 返回 `False`，表示不吞掉代码块中的异常。除非能完整处理异常，否则不要返回 `True`。

## 函数实现方式

```python
from contextlib import contextmanager

@contextmanager
def temporary_value(mapping, key, value):
    existed, old = key in mapping, mapping.get(key)
    mapping[key] = value
    try:
        yield mapping
    finally:
        if existed:
            mapping[key] = old
        else:
            mapping.pop(key, None)
```

清理逻辑必须放在 `finally`。管理多个动态资源时可用 `contextlib.ExitStack`，按进入的相反顺序释放。
