# pathlib 批量整理文件：先预览再执行

批量重命名最危险的地方不是语法，而是路径冲突和不可撤销。安全脚本应先生成计划、验证目标唯一，再显式执行。

```python
from pathlib import Path
import re

def safe_name(name: str) -> str:
    stem = re.sub(r"[^\w.-]+", "-", name, flags=re.UNICODE).strip("-")
    return stem.lower()

root = Path("incoming")
plan: list[tuple[Path, Path]] = []
for source in sorted(root.iterdir()):
    if source.is_file():
        target = source.with_name(safe_name(source.stem) + source.suffix.lower())
        plan.append((source, target))

targets = [target for _, target in plan]
if len(targets) != len(set(targets)):
    raise RuntimeError("multiple files map to the same target")

for source, target in plan:
    print(f"{source.name} -> {target.name}")
```

确认预览后，再执行改名：

```python
for source, target in plan:
    if target.exists() and target != source:
        raise FileExistsError(target)
    source.rename(target)
```

先复制少量样本到临时目录试运行，并把旧名、新名写入清单，便于恢复。跨文件系统移动时用 `shutil.move`，因为 `Path.rename` 可能无法跨设备完成。
