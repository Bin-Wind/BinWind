# argparse 子命令：构建可维护的 Python 命令行工具

当脚本同时支持导入、导出和检查时，用大量布尔参数会产生互斥组合。`argparse` 的子命令能让每个动作拥有独立参数与帮助文本。

```python
import argparse

def run_import(args: argparse.Namespace) -> None:
    print(f"import {args.source}, dry_run={args.dry_run}")

parser = argparse.ArgumentParser(prog="catalog")
sub = parser.add_subparsers(dest="command", required=True)
import_parser = sub.add_parser("import", help="导入目录")
import_parser.add_argument("source")
import_parser.add_argument("--dry-run", action="store_true")
import_parser.set_defaults(handler=run_import)
args = parser.parse_args()
args.handler(args)
```

每个子命令用 `set_defaults` 绑定处理函数，入口只负责解析和分派。路径、日期等复杂值可用 `type=` 提前转换，失败时用户能直接看到参数错误。

不要在模块导入时调用 `parse_args()`，否则测试和复用都会受影响。把解析器创建封装成函数，在测试中传入参数数组并断言解析结果；真正入口放进 `if __name__ == "__main__":`。
