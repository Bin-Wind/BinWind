# Python 有限重试：指数退避与抖动

重试只适用于暂时性故障，例如网络抖动或服务限流。参数校验失败、权限不足等确定性错误应立即返回，否则只会放大流量。

```python
import random
import time
from collections.abc import Callable
from typing import TypeVar

T = TypeVar("T")

def retry(operation: Callable[[], T], attempts: int = 4) -> T:
    for index in range(attempts):
        try:
            return operation()
        except TimeoutError:
            if index == attempts - 1:
                raise
            ceiling = min(0.5 * (2 ** index), 8.0)
            time.sleep(random.uniform(0, ceiling))
    raise AssertionError("unreachable")
```

全抖动让多个客户端不会在同一时刻再次冲击服务。HTTP 调用还应识别状态码，并优先遵守服务端 `Retry-After`。每次尝试都设置独立超时，同时给整个操作设置总期限。

写操作只有在接口提供幂等键或能查询最终状态时才自动重试。日志记录尝试次数、错误类型和最终结果，但不要把令牌或请求正文完整写入日志。
