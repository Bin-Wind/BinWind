# queue.Queue：构建有背压的生产者消费者

生产速度高于消费速度时，无界列表会持续吃内存。`queue.Queue` 用容量限制形成背压，并提供线程安全的任务计数。

```python
from queue import Queue
from threading import Thread

STOP = object()
jobs: Queue[object] = Queue(maxsize=20)

def worker() -> None:
    while True:
        item = jobs.get()
        try:
            if item is STOP:
                return
            print(f"处理 {item}")
        finally:
            jobs.task_done()

threads = [Thread(target=worker) for _ in range(2)]
for thread in threads:
    thread.start()

for number in range(10):
    jobs.put(number)
for _ in threads:
    jobs.put(STOP)

jobs.join()
for thread in threads:
    thread.join()
```

`task_done()` 必须放在 `finally` 中，每次成功 `get()` 恰好调用一次，否则 `join()` 会永久等待。哨兵数量应与消费者数量相同。

为 `put`、`get` 设置超时可让线程响应取消，但要明确超时后的重试和丢弃策略。线程适合阻塞 IO；CPU 密集工作受 GIL 影响，应考虑进程池。队列容量根据可接受内存和峰值延迟测量，而不是随意设大。
