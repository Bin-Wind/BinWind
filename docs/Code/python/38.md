# contextvars：在异步任务中传递请求上下文

把请求 ID 放进全局变量，在并发请求间会互相覆盖；作为参数层层传递又很繁琐。`ContextVar` 能让每个线程或异步任务拥有独立上下文。

```python
import asyncio
from contextvars import ContextVar

request_id: ContextVar[str] = ContextVar("request_id", default="-")

async def query() -> None:
    await asyncio.sleep(0.01)
    print("query", request_id.get())

async def handle(value: str) -> None:
    token = request_id.set(value)
    try:
        await query()
    finally:
        request_id.reset(token)

async def main() -> None:
    await asyncio.gather(handle("req-a"), handle("req-b"))

asyncio.run(main())
```

必须在 `finally` 中用 token 恢复旧值，避免复用执行上下文时泄漏。`ContextVar` 适合追踪 ID、语言等请求元数据，不适合隐藏业务依赖；核心逻辑需要的值仍应显式传参。创建新线程时上下文不会自动等同于调用方，跨线程边界要单独设计传播方式。
