# concurrent.futures：统一管理线程池与进程池任务

`concurrent.futures` 用相同接口提交并发任务。阻塞 IO 通常用线程池；纯 Python 的 CPU 密集计算通常用进程池，并确保函数可序列化。

```python
from concurrent.futures import ThreadPoolExecutor, as_completed
from urllib.request import urlopen

def size(url: str) -> tuple[str, int]:
    with urlopen(url, timeout=5) as response:
        return url, len(response.read())

urls = ["https://example.com", "https://example.org"]
with ThreadPoolExecutor(max_workers=4) as pool:
    futures = [pool.submit(size, url) for url in urls]
    for future in as_completed(futures):
        try:
            print(future.result())
        except Exception as exc:
            print(type(exc).__name__, exc)
```

异常会在 `result()` 时重新抛出，不能漏掉结果收集。`Future.cancel()` 只能取消尚未开始的任务，运行中的阻塞调用还要自身支持超时。工作线程数应由依赖容量和内存决定；无限提交任务仍会堆积，生产系统可用有界队列或分批提交形成背压。
