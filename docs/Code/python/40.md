# Decimal：精确处理金额与舍入规则

二进制浮点不能精确表示多数十进制小数，金额计算应从字符串创建 `Decimal`，并在业务边界明确舍入模式。

```python
from decimal import Decimal, ROUND_HALF_UP

price = Decimal("19.90")
quantity = Decimal("3")
tax_rate = Decimal("0.06")

subtotal = price * quantity
tax = (subtotal * tax_rate).quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
total = subtotal + tax
print(subtotal, tax, total)
```

不要写 `Decimal(0.1)`，因为浮点误差已经产生；应使用 `Decimal("0.1")`。`quantize` 的位置取决于业务规则：逐行舍入与汇总后舍入可能得到不同结果，发票、税费和支付系统必须统一。

数据库字段使用定点十进制类型，接口传输金额时用十进制字符串或最小货币单位整数。显示格式与计算精度分开处理，并用边界值、负数、退款和多行合计建立测试。
