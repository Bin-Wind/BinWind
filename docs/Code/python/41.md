# heapq：在数据流中保留最大的 K 项

面对无法一次载入内存的数据流，维护固定大小的最小堆即可得到最大的 K 项。堆顶始终是当前入选项中最小的一个，新值更大时替换它。

~~~python
import heapq

values = [9, 2, 17, 4, 12, 8, 21]
k = 3
heap: list[int] = []
for value in values:
    if len(heap) < k:
        heapq.heappush(heap, value)
    elif value > heap[0]:
        heapq.heapreplace(heap, value)
print(sorted(heap, reverse=True))
~~~

时间复杂度约为 O(n log k)，空间为 O(k)。若数据已在内存且只需一次结果，heapq.nlargest 更简洁。排序键相同时要准备稳定的第二字段，避免堆比较到不可比较对象。k 必须校验为正数；要取最小 K 项可对逻辑对称处理。
