# asyncio.TaskGroup：让并发子任务一起收尾

Python 3.11 的 TaskGroup 提供结构化并发：代码块退出前会等待所有子任务；一个任务失败时，其余任务会被取消，异常以 ExceptionGroup 汇总。

~~~python
import asyncio

async def fetch(name: str, delay: float) -> str:
    await asyncio.sleep(delay)
    return name.upper()

async def main() -> None:
    async with asyncio.TaskGroup() as group:
        first = group.create_task(fetch("alpha", 0.1))
        second = group.create_task(fetch("beta", 0.2))
    print(first.result(), second.result())

asyncio.run(main())
~~~

不要在协程中吞掉 CancelledError，否则 TaskGroup 可能无法及时结束。独立任务允许部分失败时，应在单个任务内部把预期错误转换为结果；必须共同成功的任务则保留默认传播。外层再用 asyncio.timeout 设置整个批次的截止时间。
