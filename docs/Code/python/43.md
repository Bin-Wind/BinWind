# zoneinfo：用时区规则处理本地时间

固定 UTC 偏移不能表达夏令时变化。Python 标准库 zoneinfo 使用 IANA 时区规则，适合在“用户当地上午九点”与 UTC 时间之间转换。

~~~python
from datetime import datetime
from zoneinfo import ZoneInfo

shanghai = ZoneInfo("Asia/Shanghai")
new_york = ZoneInfo("America/New_York")
meeting = datetime(2026, 9, 13, 9, 0, tzinfo=shanghai)
print(meeting.astimezone(new_york).isoformat())
print(meeting.astimezone(ZoneInfo("UTC")).isoformat())
~~~

数据库通常保存 UTC 瞬间，并另存用户选择的时区名称；展示时再转换。不要把本地时间先当 UTC 再 replace 时区。夏令时切换附近可能出现不存在或重复的本地时间，排程系统需定义拒绝、前移或使用 fold 的明确策略。
