# contextlib.ExitStack：动态管理数量不定的资源

资源数量在运行时才确定时，嵌套多个 with 不够灵活。ExitStack 可以按进入顺序登记清理动作，并在离开作用域时逆序执行。

~~~python
from contextlib import ExitStack
from pathlib import Path

paths = [Path("a.txt"), Path("b.txt")]
with ExitStack() as stack:
    files = [stack.enter_context(path.open("w", encoding="utf-8")) for path in paths]
    for file, text in zip(files, ["甲\n", "乙\n"]):
        file.write(text)
~~~

中途打开失败时，已经进入的资源仍会关闭。callback 可登记非上下文管理器的清理函数，但回调参数要在登记时固定，避免闭包捕获变化变量。若所有步骤成功后要把资源所有权移交，可使用 pop_all，并在新所有者处明确关闭。

ExitStack 解决清理顺序，不提供事务原子性。多文件同时发布仍应先写临时文件、校验完成后逐步替换，并设计失败恢复。
