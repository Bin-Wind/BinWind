# tomllib：用标准库读取 pyproject.toml 配置

Python 3.11 起可用 tomllib 读取 TOML，适合检查 pyproject.toml 等只读配置。它返回普通字典，不负责写回文件。

~~~python
import tomllib

sample = """
[project]
name = "demo-app"
requires-python = ">=3.11"
"""
config = tomllib.loads(sample)

project = config.get("project", {})
name = project.get("name")
if not isinstance(name, str) or not name:
    raise ValueError("project.name is required")
print(name)
~~~

实际读取文件时使用 `with open("pyproject.toml", "rb") as file: config = tomllib.load(file)`；文件必须以二进制模式打开。解析错误会抛出 TOMLDecodeError。读取成功后仍需校验必需字段、类型和业务范围；语法合法不代表配置可用。对日期时间值要注意 tomllib 会转换为相应 Python 类型。

需要兼容更早 Python 版本时可使用 tomli，并在版本条件中保持同一接口。需要保留注释和格式的写回场景，应选择专门编辑库，不要把字典重新序列化后覆盖用户文件。
