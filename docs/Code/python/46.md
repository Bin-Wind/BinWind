# asyncio.timeout：为一组异步操作设置总期限

单独给每个请求设置超时，仍可能让串行流程累计等待过久。Python 3.11 的 asyncio.timeout 可为整个代码块设置截止时间。

~~~python
import asyncio

async def step(delay: float) -> str:
    await asyncio.sleep(delay)
    return "ok"

async def main() -> None:
    try:
        async with asyncio.timeout(0.2):
            print(await step(0.05), await step(0.3))
    except TimeoutError:
        print("deadline exceeded")

asyncio.run(main())
~~~

超时会取消当前任务，并在上下文外转换为 TimeoutError。协程收到取消后应在 finally 中释放资源，再重新传播 CancelledError；吞掉取消会让期限失效。屏蔽取消只应用于很短且必须完成的清理步骤。

总期限与单次网络超时可以同时存在：前者约束用户等待，后者定位具体慢调用。重试前计算剩余预算，不能每轮重新获得完整超时时间。
