# Python StrEnum：让配置值兼顾类型与序列化

Python 3.11 的 `StrEnum` 适合表示来自配置、JSON 或命令行的有限字符串。成员仍是字符串，可以直接序列化，同时比散落的常量更容易校验。

~~~python
from enum import StrEnum

class Mode(StrEnum):
    SAFE = "safe"
    FAST = "fast"

def parse_mode(raw: str) -> Mode:
    try:
        return Mode(raw)
    except ValueError as exc:
        allowed = ", ".join(m.value for m in Mode)
        raise ValueError(f"mode must be one of: {allowed}") from exc

mode = parse_mode("safe")
print(mode, mode == "safe", {"mode": mode})
~~~

枚举值是外部协议的一部分，成员名可以重构，值却不能随意改。接收输入时用 `Mode(raw)` 显式转换，不要让任意字符串长期混在业务层。

`StrEnum.auto()` 默认生成小写成员名，公开配置中更推荐写明值，审查变更时更直观。若需要兼容旧值，可在输入边界迁移，内部始终只使用当前枚举。
