# Python logging QueueHandler：让工作线程快速交出日志

多个工作线程直接写慢速文件会把格式化和 I/O 带入业务路径。标准库的 `QueueHandler` 将记录放入队列，由 `QueueListener` 在单独线程中统一输出。

~~~python
import logging
from logging.handlers import QueueHandler, QueueListener
from queue import SimpleQueue
from threading import Thread

records = SimpleQueue()
console = logging.StreamHandler()
console.setFormatter(logging.Formatter("%(threadName)s %(message)s"))

logger = logging.getLogger("worker")
logger.setLevel(logging.INFO)
logger.addHandler(QueueHandler(records))
listener = QueueListener(records, console, respect_handler_level=True)

def work(item: int) -> None:
    logger.info("processed item=%d", item)

listener.start()
try:
    threads = [Thread(target=work, args=(i,)) for i in range(3)]
    for thread in threads:
        thread.start()
    for thread in threads:
        thread.join()
finally:
    listener.stop()
~~~

`SimpleQueue` 没有容量限制，突发日志可能占用过多内存；高吞吐服务可使用有界队列并明确丢弃、阻塞或采样策略。进程间日志不能直接照搬线程队列，应使用适合多进程的传输方式。

退出前调用 `stop()`，让已入队记录完成处理。异常对象、请求标识等上下文应在入队前就可序列化，敏感字段则在日志边界统一脱敏。
