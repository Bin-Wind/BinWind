# Python subprocess.run：安全传参、超时与状态码

调用外部程序时把命令写成参数列表，避免用户输入经过 shell 解释。`check=True` 让非零退出码成为异常，`timeout` 则限制等待时间。

~~~python
import subprocess
import sys

code = "import sys; print(sys.argv[1].upper())"

try:
    result = subprocess.run(
        [sys.executable, "-c", code, "hello world"],
        check=True,
        capture_output=True,
        text=True,
        timeout=2,
    )
except subprocess.TimeoutExpired:
    print("command timed out")
except subprocess.CalledProcessError as exc:
    print(f"failed with code {exc.returncode}: {exc.stderr}")
else:
    print(result.stdout.strip())
~~~

不要为拼接重定向或管道而轻易使用 `shell=True`；若确实需要 shell，所有动态值都必须经过对应 shell 的严格转义，且风险更高。环境变量可通过 `env` 显式传入，不要无意继承含密钥的完整环境。

`capture_output` 会把内容放进内存，大量输出应重定向到文件或流式读取。超时异常会终止子进程并等待回收，但子进程自行派生的进程树可能仍存在，生产任务需要额外的进程组与清理策略。
