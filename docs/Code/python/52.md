# pathlib.Path.walk：遍历目录时原地剪枝

Python 3.12 为 `Path` 增加了 `walk()`。它逐层返回 `(dirpath, dirnames, filenames)`，并允许在自顶向下遍历时修改 `dirnames`，跳过缓存、虚拟环境等不需要进入的目录。

```python
from pathlib import Path

root = Path("project")
ignored = {".git", ".venv", "node_modules"}

for directory, dirnames, filenames in root.walk(top_down=True):
    dirnames[:] = [name for name in dirnames if name not in ignored]
    for name in filenames:
        path = directory / name
        if path.suffix == ".py":
            print(path)
```

必须使用切片赋值修改原列表；写成 `dirnames = [...]` 只会重新绑定局部变量，不会阻止遍历器进入原目录。

## 符号链接与错误

默认不会跟随目录符号链接。开启 `follow_symlinks=True` 前要考虑环路，因为遍历器不会自动记录所有已访问目录。处理不可信目录树时通常保持默认，并用 `on_error` 记录权限或读取失败。

```python
def report(error: OSError) -> None:
    print(f"无法读取 {error.filename}: {error}")

for directory, dirs, files in root.walk(on_error=report):
    pass
```

## 路径边界

遍历前先确认根目录是预期位置；删除或改名时再次解析并验证目标仍位于根目录内。目录内容可能在遍历过程中变化，`walk()` 提供的是扫描过程，不是文件系统快照。需要一致性的任务应在隔离副本或具有快照能力的存储上执行。
