# Python graphlib.TopologicalSorter：按依赖顺序执行任务

构建、迁移或数据处理任务常有“先完成 A，才能执行 B”的关系。标准库 `graphlib.TopologicalSorter` 可以给有向无环依赖图排序，并在存在环时明确失败。

输入字典的键是任务，值是该任务的直接前置任务：

```python
from graphlib import CycleError, TopologicalSorter

dependencies = {
    "fetch": set(),
    "clean": {"fetch"},
    "train": {"clean"},
    "report": {"clean", "train"},
}

try:
    order = tuple(TopologicalSorter(dependencies).static_order())
except CycleError as error:
    raise SystemExit(f"依赖存在环: {error.args}")

print(" -> ".join(order))
```

同一层没有依赖关系的任务，其相对顺序不应被业务依赖。测试若需要确定输出，可对任务名排序后再构图，但不要把偶然顺序写成隐含约束。

## 并发调度

需要并行时，先调用 `prepare()`，再用 `get_ready()` 取得当前可运行任务；任务成功后调用 `done(task)`，新的任务才会就绪。失败任务不能标记完成，应取消或阻止依赖它的下游。

拓扑排序只验证依赖结构，不负责重试、资源限制和幂等。任务图来自配置时，应同时检查未知任务、自依赖和空名称，并把检测到的环作为配置错误在执行前报告。
