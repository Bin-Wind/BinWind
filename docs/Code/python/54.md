# Python bisect：在有序列表中插入并明确重复值边界

`bisect` 用二分查找定位插入点，适合中小规模、读多写少的有序列表。`bisect_left` 返回相等元素的左边界，`bisect_right` 返回右边界；选择哪一个决定重复值的排列规则。

```python
from bisect import bisect_left, insort_right

scores = [60, 75, 75, 90]
first_75 = bisect_left(scores, 75)
print(first_75)  # 1

insort_right(scores, 75)
print(scores)  # [60, 75, 75, 75, 90]
```

查找是对数复杂度，但列表插入需要移动后续元素，仍是线性复杂度。高频插入或百万级数据应考虑数据库索引、堆或专门的有序容器。

## 按键查找

现代 Python 的二分函数支持 `key`，但插入元素本身不会自动转换。应保证列表始终按同一规则排序：

```python
from bisect import bisect_left

rows = [{"id": "a", "price": 10}, {"id": "b", "price": 20}]
position = bisect_left(rows, 15, key=lambda row: row["price"])
rows.insert(position, {"id": "c", "price": 15})
```

若键可能被原地修改，列表就不再有序，之后的结果没有保证。并发修改也需要外部锁；`bisect` 不会为“查找再插入”这一组合提供原子性。
