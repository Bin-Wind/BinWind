# Python weakref.finalize：对象回收时安排兜底清理

`weakref.finalize` 可以在对象不可达时调用清理函数，比直接编写 `__del__` 更容易管理。但回收时机仍不确定，文件和锁等资源必须优先用上下文管理器显式释放。

```python
import tempfile
import weakref
from pathlib import Path

class Scratch:
    def __init__(self):
        self.path = Path(tempfile.mkdtemp())
        self._finalizer = weakref.finalize(self, self._cleanup, self.path)

    @staticmethod
    def _cleanup(path: Path):
        path.rmdir()  # 示例目录为空；真实场景需定义明确删除策略

    def close(self):
        self._finalizer()

s = Scratch()
print(s.path)
s.close()
```

回调参数不能持有目标对象，否则强引用会阻止回收。`finalizer.alive` 可检查是否尚未执行；直接调用 finalizer 能让显式关闭与兜底逻辑共用一次性清理。进程异常退出时不保证执行，因此它不能代替事务、落盘确认或服务关闭钩子。
