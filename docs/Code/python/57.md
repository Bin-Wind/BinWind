# Python ipaddress：验证地址并判断所属网段

字符串前缀无法可靠判断 IP 是否属于某个网段。标准库 `ipaddress` 会解析 IPv4、IPv6 与 CIDR，并拒绝格式错误的输入。

```python
from ipaddress import ip_address, ip_network

network = ip_network("192.0.2.0/24")
for raw in ["192.0.2.8", "192.0.3.8"]:
    address = ip_address(raw)
    print(raw, address in network)
```

`ip_network()` 默认要求网络地址的主机位为零；处理用户输入的 `192.0.2.3/24` 时，可明确使用 `strict=False` 将其归一化为对应网络。IPv4 与 IPv6 对象不能直接混合比较，配置中应先确认版本。

`is_private`、`is_global` 等属性依据 Python 随附的数据定义，适合分类与校验，但不能直接充当防火墙。安全边界还要处理代理头可信来源、DNS 变化、IPv4 映射 IPv6 地址和实际路由规则。
