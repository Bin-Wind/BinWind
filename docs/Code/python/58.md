# Python statistics.quantiles：用分位数观察长尾数据

平均值会掩盖请求延迟和订单金额的长尾。标准库 `statistics.quantiles` 可以把样本切成等概率区间，快速得到四分位数或百分位数边界。

```python
from statistics import median, quantiles

latency_ms = [18, 21, 19, 23, 20, 22, 85, 24, 20, 110]
p25, p50, p75 = quantiles(latency_ms, n=4, method="inclusive")
print({"median": median(latency_ms), "p25": p25, "p50": p50, "p75": p75})
```

`inclusive` 把样本最小值和最大值视为总体边界，`exclusive` 更适合样本来自更大总体的估计；选择后应固定并写进指标定义。小样本的高百分位非常不稳定，不能把一个插值结果包装成精确 SLO 证据。

生产监控通常使用直方图或流式摘要，而不是把所有数据放进列表。无论工具如何，比较两个分位数前必须保持时间窗、过滤条件、单位和算法一致。
