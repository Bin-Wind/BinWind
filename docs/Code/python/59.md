# Python csv.Sniffer：谨慎推断分隔符并准备回退

外部 CSV 可能用逗号、分号或制表符分隔。`csv.Sniffer` 能从样本推断方言，但短文本和自由文本字段会误导它，因此推断失败必须有明确回退。

```python
import csv
from io import StringIO

def read_table(text: str) -> list[dict[str, str]]:
    sample = text[:4096]
    try:
        dialect = csv.Sniffer().sniff(sample, delimiters=",;\t")
    except csv.Error:
        dialect = csv.excel
    reader = csv.DictReader(StringIO(text), dialect=dialect)
    if not reader.fieldnames or len(reader.fieldnames) < 2:
        raise ValueError("至少需要两列")
    return list(reader)

print(read_table("name;score\n小林;92\n小周;88\n"))
```

限制候选分隔符，不要让任意字符参与猜测。读取后检查列名、列数和必填字段；对关键导入任务最好让用户预览解析结果并确认。编码识别是另一层问题，应在把字节解码成文本时单独处理。
