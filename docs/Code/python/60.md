# Python os.scandir：借助目录项缓存高效筛选文件

`os.listdir()` 只给名称，后续判断文件类型往往要再次查询元数据。`os.scandir()` 返回的 `DirEntry` 可在多数系统上复用目录遍历时取得的信息，适合大目录筛选。

```python
from pathlib import Path
import os

def large_files(folder: Path, minimum: int):
    with os.scandir(folder) as entries:
        for entry in entries:
            try:
                if entry.is_file(follow_symlinks=False):
                    size = entry.stat(follow_symlinks=False).st_size
                    if size >= minimum:
                        yield Path(entry.path), size
            except FileNotFoundError:
                continue

for path, size in large_files(Path("."), 1024):
    print(size, path)
```

`follow_symlinks=False` 可避免把链接目标误当成目录内实体，但不能替代权限控制。需要递归、剪枝和更易读接口时可用 `Path.walk()`；需要在热路径处理大量目录项时再考虑 `scandir()`。
