# Python urllib.parse：拼接 URL 时防止主机被覆盖

`urljoin(base, user_input)` 遇到以 `//` 或协议开头的输入时，会采用输入中的主机。若它被用于生成站内跳转，就可能产生开放重定向。

```python
from urllib.parse import urljoin, urlsplit

ALLOWED_HOST = "docs.example.com"

def internal_url(raw: str) -> str:
    candidate = urljoin("https://docs.example.com/account/", raw)
    parsed = urlsplit(candidate)
    if parsed.scheme != "https" or parsed.hostname != ALLOWED_HOST:
        raise ValueError("只允许站内 HTTPS 地址")
    if parsed.username or parsed.password or parsed.port not in (None, 443):
        raise ValueError("URL 权限信息或端口不合法")
    return candidate

print(internal_url("settings?tab=security"))
```

解析 URL 不等于完成安全验证。服务端发起请求时还要防 DNS 重绑定和内网地址访问；重定向响应也需逐跳复核。若只接受相对路径，最稳妥的是直接拒绝带协议或 `netloc` 的输入。
