# Python secrets：生成不可预测的临时令牌

密码重置链接、邀请令牌和 CSRF Token 需要抵抗猜测。`random` 模块面向模拟和抽样，其状态可预测；安全令牌应使用标准库 `secrets`，让随机性来自操作系统提供的安全源。

## 生成 URL 安全令牌

```python
import secrets

token = secrets.token_urlsafe(32)
print(token)
```

参数表示随机字节数，不是最终字符串长度。URL-safe Base64 编码后通常会更长。数据库中不要明文保存可直接使用的令牌；保存摘要，用户提交后再用相同算法计算并比较。

```python
import hashlib
import secrets

def issue_token() -> tuple[str, str]:
    raw = secrets.token_urlsafe(32)
    digest = hashlib.sha256(raw.encode()).hexdigest()
    return raw, digest

def verify_token(raw: str, expected_digest: str) -> bool:
    actual = hashlib.sha256(raw.encode()).hexdigest()
    return secrets.compare_digest(actual, expected_digest)

raw, stored = issue_token()
assert verify_token(raw, stored)
```

## 令牌还需要生命周期

足够随机只是第一层。记录用途、账号、创建时间、过期时间和是否已使用；验证成功后在同一事务中标记为已用，避免并发重复兑换。日志中只记录令牌摘要前缀或内部记录 ID，不记录完整 URL。

长度应按风险和有效期选择，不能用短数字码替代高熵链接。若业务必须使用短验证码，就增加严格的次数限制、短有效期和账号级锁定。`secrets` 负责不可预测性，业务仍需负责绑定、过期与单次使用。
