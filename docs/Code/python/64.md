# Python zipfile：解压前拒绝路径穿越

ZIP 内部文件名可能包含 `../` 或绝对路径。若直接把每个成员拼到目标目录写出，恶意压缩包可能覆盖目标目录之外的文件。即使标准库会做部分处理，也应在安全边界处显式验证并限制资源。

## 校验最终路径

```python
from pathlib import Path
from zipfile import ZipFile, ZipInfo

def safe_target(root: Path, member: ZipInfo) -> Path:
    root = root.resolve()
    target = (root / member.filename).resolve()
    if not target.is_relative_to(root):
        raise ValueError(f"非法路径: {member.filename}")
    return target

def extract_small_zip(archive: Path, destination: Path) -> None:
    destination.mkdir(parents=True, exist_ok=True)
    with ZipFile(archive) as zf:
        members = zf.infolist()
        if len(members) > 1_000:
            raise ValueError("文件数量过多")
        if sum(item.file_size for item in members) > 100_000_000:
            raise ValueError("解压后体积过大")
        for item in members:
            target = safe_target(destination, item)
            if item.is_dir():
                target.mkdir(parents=True, exist_ok=True)
                continue
            target.parent.mkdir(parents=True, exist_ok=True)
            with zf.open(item) as source, target.open("wb") as output:
                while chunk := source.read(1024 * 1024):
                    output.write(chunk)
```

不要只检查字符串是否以 `..` 开头，`a/../../x` 同样危险。还要按业务决定是否拒绝符号链接、加密条目、重复文件名和未知扩展名。

压缩比极高的文件可能造成磁盘耗尽，因此同时限制成员数、声明的总大小、单文件大小和实际写入量。解压到新建临时目录，全部验证成功后再移动到正式位置，可避免失败时留下半套文件。
