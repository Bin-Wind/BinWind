# Vue 3 Teleport、KeepAlive 与 Suspense

三个内置组件分别解决 DOM 挂载位置、动态组件缓存和异步依赖等待问题。它们功能不同，不应因名字都像“高级组件”而混用。

## Teleport：弹窗脱离布局

```vue
<script setup>
import { ref } from 'vue'
const open = ref(false)
</script>

<template>
  <button @click="open = true">打开</button>
  <Teleport to="body">
    <div v-if="open" role="dialog" aria-modal="true">
      <p>确认操作？</p>
      <button @click="open = false">关闭</button>
    </div>
  </Teleport>
</template>
```

Teleport 只改变渲染位置，组件层级、事件和依赖注入关系保持不变。弹窗仍需实现焦点管理、Esc 关闭和背景滚动锁定。

## KeepAlive：保留页面状态

```vue
<KeepAlive :include="['UserList']" :max="5">
  <component :is="currentView" />
</KeepAlive>
```

被缓存组件不会卸载，而会触发 `onActivated` 与 `onDeactivated`。定时器和订阅应在停用时暂停，避免隐藏页面继续耗费资源。

## Suspense：异步边界

```vue
<Suspense>
  <AsyncProfile />
  <template #fallback>正在加载资料…</template>
</Suspense>
```

它能等待异步 `setup` 和异步组件，但错误处理仍需组件或应用级策略。使用前确认目标 Vue 版本对 Suspense 的支持状态，并为关键内容准备无 JavaScript 或失败兜底。
