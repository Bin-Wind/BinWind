# Vue SSR 水合不一致排查

服务端渲染先输出 HTML，客户端再把事件和响应式状态“接”到现有 DOM 上，这一步称为水合。如果两端首次渲染结果不同，就会出现警告、闪烁或局部重建。

## 常见根因

- 模板中直接调用 `Date.now()`、`Math.random()`。
- 服务端和浏览器使用不同语言、时区或数据快照。
- 在首次渲染时读取 `window`、`localStorage` 或屏幕宽度。
- HTML 结构无效，被浏览器自动修正。

## 保证首屏一致

将不确定值在服务端生成并序列化给客户端：

```vue
<script setup>
const props = defineProps({
  generatedAt: { type: String, required: true }
})
</script>

<template>
  <time :datetime="generatedAt">{{ generatedAt }}</time>
</template>
```

浏览器专属内容延后到挂载后：

```vue
<script setup>
import { onMounted, ref } from 'vue'

const theme = ref('system')
onMounted(() => {
  theme.value = localStorage.getItem('theme') ?? 'system'
})
</script>
```

首屏仍以 `system` 渲染，挂载后再更新。若布局会明显变化，使用尺寸稳定的占位元素。

## 定位步骤

先保存服务端原始响应，再与水合前 DOM 和客户端期望状态比较。缩小到最小组件，检查随机值、环境分支与异步数据。不要用忽略警告作为默认修复；只有确知差异无害且不可避免时，才局部抑制。
