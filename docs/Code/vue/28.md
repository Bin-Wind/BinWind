# Vue 组件无障碍实战

无障碍不是给元素补几个 `aria-*` 属性。优先使用语义化 HTML，再补充键盘交互、焦点管理和动态状态通知。

## 可访问的折叠面板

```vue
<script setup>
import { ref } from 'vue'
const open = ref(false)
</script>

<template>
  <section>
    <h2>
      <button
        type="button"
        :aria-expanded="open"
        aria-controls="answer-panel"
        @click="open = !open"
      >配送需要多久？</button>
    </h2>
    <div id="answer-panel" v-show="open">
      通常需要 2 至 3 个工作日。
    </div>
  </section>
</template>
```

原生 `button` 自动支持 Enter、Space 与焦点样式，通常比给 `div` 模拟点击更可靠。`aria-expanded` 表达状态，`aria-controls` 建立关联。

## 表单与错误

每个输入都要有可见 `label`。错误消息用 `aria-describedby` 与输入关联；提交失败后把焦点移到错误摘要，而不是只改变边框颜色。异步保存结果可放进适度的 `aria-live="polite"` 区域。

## 测试清单

只用键盘走完关键流程；检查焦点顺序和可见焦点；用浏览器无障碍树确认名称与角色；再用屏幕阅读器抽查。自动化工具能发现缺少标签等规则问题，但无法判断文案和交互是否真正可理解。
