# Vue 表单脏状态与重置设计

表单不仅要保存当前值，还要区分初始值、是否修改和是否提交中。直接替换 `reactive` 对象会破坏已有引用，重置时应复制字段。

```vue
<script setup lang="ts">
import { computed, reactive, ref } from 'vue'

type Profile = { name: string; city: string }
const initial: Profile = { name: 'Lin', city: 'Shanghai' }
const form = reactive<Profile>({ ...initial })
const saving = ref(false)
const dirty = computed(() =>
  form.name !== initial.name || form.city !== initial.city
)

function reset() {
  Object.assign(form, initial)
}

async function submit() {
  if (!dirty.value || saving.value) return
  saving.value = true
  try {
    // await api.updateProfile({ ...form })
    Object.assign(initial, form)
  } finally {
    saving.value = false
  }
}
</script>
```

复杂嵌套数据应保存结构化快照，并明确数组顺序是否影响“已修改”判断。路由离开保护只在确有未保存修改时出现；提交成功后更新基线。

服务端校验错误应绑定到字段，网络错误保留用户输入，重复提交则由按钮状态与服务端幂等共同防护。
