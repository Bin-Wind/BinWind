# Vue 组件错误捕获与降级界面

子组件在渲染或生命周期中抛错时，可以用 `onErrorCaptured` 在上层边界记录错误并展示局部降级，而不是让整个页面不可用。

```vue
<script setup lang="ts">
import { onErrorCaptured, ref } from 'vue'
import RiskyPanel from './RiskyPanel.vue'

const failed = ref(false)
onErrorCaptured((error, instance, info) => {
  failed.value = true
  console.error('panel failed', { error, info })
  return false
})
</script>

<template>
  <section>
    <div v-if="failed" role="alert">面板加载失败，请刷新后重试。</div>
    <RiskyPanel v-else />
  </section>
</template>
```

返回 `false` 会阻止错误继续向上传播。只应在当前边界已经记录并提供合理降级时这样做。

错误边界不能捕获所有异步事件异常，事件处理器和请求 Promise 仍需自己的 `try/catch`。生产日志记录路由、组件和发布版本，但不要上传用户敏感数据。
