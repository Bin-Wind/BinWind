# Vue watch 清理副作用：取消过期请求

搜索词快速变化时，旧请求可能晚于新请求返回，覆盖正确结果。Vue 3 的 `watch` 清理函数可在下一次执行前取消上一轮副作用。

```vue
<script setup lang="ts">
import { ref, watch } from 'vue'

const keyword = ref('')
const results = ref<string[]>([])
const loading = ref(false)

watch(keyword, async (value, _oldValue, onCleanup) => {
  const query = value.trim()
  if (!query) return void (results.value = [])

  const controller = new AbortController()
  onCleanup(() => controller.abort())
  loading.value = true
  try {
    const response = await fetch(`/api/search?q=${encodeURIComponent(query)}`, {
      signal: controller.signal,
    })
    if (!response.ok) throw new Error(`HTTP ${response.status}`)
    results.value = await response.json()
  } catch (error) {
    if (!(error instanceof DOMException && error.name === 'AbortError')) throw error
  } finally {
    if (!controller.signal.aborted) loading.value = false
  }
})
</script>
```

输入搜索通常还要防抖，减少请求数量；取消负责正确性，防抖负责效率。组件卸载时 watcher 会停止，清理函数也会执行。
