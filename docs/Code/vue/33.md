# Vue 异步组件：按需加载与可恢复失败

低频弹窗、图表和管理页面不必进入首屏包。`defineAsyncComponent` 可以延后加载，同时为慢网络和加载失败提供明确界面。

```vue
<script setup lang="ts">
import { defineAsyncComponent } from 'vue'
import LoadingPanel from './LoadingPanel.vue'
import LoadError from './LoadError.vue'

const ReportPanel = defineAsyncComponent({
  loader: () => import('./ReportPanel.vue'),
  loadingComponent: LoadingPanel,
  errorComponent: LoadError,
  delay: 150,
  timeout: 10_000,
})
</script>

<template><ReportPanel /></template>
```

短暂延迟可避免资源很快加载时闪烁 Loading。超时只改变组件状态，不一定取消底层网络请求；错误界面应允许用户重试或返回安全页面。

不要把首屏核心内容全拆成异步块，否则请求瀑布会延迟可用时间。结合构建产物分析选择边界，并在弱网下测试加载、失败、重试和版本发布后旧 chunk 失效的场景。
