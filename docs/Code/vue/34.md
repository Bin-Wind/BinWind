# Vue 列表渲染：稳定 key 与可预测状态

`key` 用来告诉 Vue 哪个旧节点对应哪个新节点。用数组索引作为 key，在插入、排序或删除后会把输入框状态复用到错误项目。

```vue
<script setup lang="ts">
import { ref } from 'vue'

type Task = { id: string; title: string }
const tasks = ref<Task[]>([
  { id: 'a1', title: '检查需求' },
  { id: 'b2', title: '运行测试' },
])
function remove(id: string) {
  tasks.value = tasks.value.filter(task => task.id !== id)
}
</script>

<template>
  <div v-for="task in tasks" :key="task.id">
    <input v-model="task.title">
    <button @click="remove(task.id)">删除</button>
  </div>
</template>
```

key 应来自数据的稳定身份，不能在渲染时调用随机数生成。临时客户端记录可在创建时生成一次 ID，服务端保存后再用映射替换。

过滤列表优先使用计算属性，不要把 `v-if` 与 `v-for` 放在同一元素。测试排序后焦点、展开状态和编辑内容是否仍属于正确记录，这比只看文本顺序更能发现 key 问题。
