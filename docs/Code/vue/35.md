# Vue 组件 v-model：显式约定值与更新事件

可复用表单组件应把当前值视为 prop，通过事件请求父组件更新，避免子组件悄悄修改外部状态。Vue 3.4+ 可用 `defineModel` 简化这一约定。

```vue
<script setup lang="ts">
const query = defineModel<string>({ required: true })

function clear() {
  query.value = ''
}
</script>

<template>
  <label>
    搜索
    <input v-model="query" type="search">
  </label>
  <button type="button" @click="clear">清空</button>
</template>
```

父组件使用 `<SearchBox v-model="keyword" />`。需要多个值时可用具名模型，如 `v-model:start` 与 `defineModel('start')`，名称应表达领域含义。

不要在组件内部复制 prop 后长期双向同步，两份状态容易产生竞态。只有草稿需要“应用/取消”时才保留本地副本，并明确何时从父值重置。

模型的类型和默认值必须与父组件一致；子组件设默认值而父值是 `undefined` 时可能暂时不同步。表单错误、脏状态和校验时机最好用独立事件或接口表达，不要塞进一个复杂模型对象。
