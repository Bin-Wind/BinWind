# Vue effectScope：集中释放一组响应式副作用

组合式服务可能同时创建多个 `watch`、`computed` 和清理回调。它们若不隶属于组件生命周期，就需要显式停止。`effectScope` 可以把这组副作用作为一个单元管理。

```typescript
import { effectScope, onScopeDispose, ref, watch } from 'vue'

export function createDraftAutosave(save: (value: string) => void) {
  const scope = effectScope()
  const draft = ref('')

  scope.run(() => {
    const timer = ref<number>()
    watch(draft, (value) => {
      window.clearTimeout(timer.value)
      timer.value = window.setTimeout(() => save(value), 500)
    })
    onScopeDispose(() => window.clearTimeout(timer.value))
  })

  return { draft, stop: () => scope.stop() }
}
```

使用者销毁编辑器或切换文档时调用 `stop`，所有作用域内监听会一起停止。组件 `setup` 内创建的普通副作用本来就会随组件卸载，无需为了形式额外包一层。

清理函数仍要处理计时器、订阅和外部资源；作用域只能自动管理 Vue 的响应式 effect。测试应验证停止后修改数据不会再保存，并确保重复调用 `stop` 不产生异常。
