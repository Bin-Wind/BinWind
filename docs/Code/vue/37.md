# Vue 路由后的焦点管理：让页面切换可被感知

单页应用切换路由时不会触发浏览器整页加载，键盘焦点可能仍停在已经消失的导航链接。视觉上换页了，屏幕阅读器用户却未必知道。

在页面容器放一个可编程聚焦的标题，并在路由完成、DOM 更新后移动焦点：

```vue
<script setup lang="ts">
import { nextTick, ref, watch } from 'vue'
import { useRoute } from 'vue-router'

const route = useRoute()
const heading = ref<HTMLHeadingElement>()

watch(() => route.fullPath, async () => {
  await nextTick()
  heading.value?.focus()
})
</script>

<template>
  <main>
    <h1 ref="heading" tabindex="-1">订单详情</h1>
    <router-view />
  </main>
</template>
```

`tabindex="-1"` 允许脚本聚焦，但不会把标题加入日常 Tab 顺序。标题获得焦点时不要移除可见轮廓，用户需要知道当前位置。

若切换只更新页面局部，可用礼貌的 live region 宣布结果数量，而不是抢走正在输入的焦点。自动聚焦前还应区分浏览器前进后退和弹窗关闭等场景，并在真实键盘与屏幕阅读器中验证阅读顺序。
