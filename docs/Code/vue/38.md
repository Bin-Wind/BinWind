# Vue computed：派生状态不必再用 watch 同步

一个值完全由其他响应式状态计算得出时，应使用 `computed`。用 `watch` 把结果复制到另一个 `ref`，容易出现初始值遗漏和更新时序问题。

```vue
<script setup lang="ts">
import { computed, ref } from 'vue'

const price = ref(19.9)
const quantity = ref(2)
const total = computed(() => price.value * quantity.value)
</script>

<template>
  <label>数量 <input v-model.number="quantity" type="number" min="0"></label>
  <p>合计：{{ total.toFixed(2) }}</p>
</template>
```

`computed` getter 应保持纯粹，不发请求、不修改其他状态。需要把变化同步到外部系统时才使用 `watch`，并处理取消与错误。可写 computed 只适合天然存在双向映射的值；业务更新最好通过明确方法完成，便于验证和追踪。
