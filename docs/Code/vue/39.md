# Vue 模板引用：挂载后访问并及时清理监听器

模板引用在组件挂载前为空，元素也可能因 `v-if` 消失。访问 DOM 时要处理生命周期，并在卸载时移除手动注册的副作用。

```vue
<script setup lang="ts">
import { onBeforeUnmount, onMounted, ref } from 'vue'

const panel = ref<HTMLElement | null>(null)

function onKeydown(event: KeyboardEvent) {
  if (event.key === 'Escape') panel.value?.focus()
}

onMounted(() => window.addEventListener('keydown', onKeydown))
onBeforeUnmount(() => window.removeEventListener('keydown', onKeydown))
</script>

<template>
  <section ref="panel" tabindex="-1">可被聚焦的面板</section>
</template>
```

能用模板声明完成的 class、属性和事件绑定，不必绕到 DOM API。引用子组件时只暴露必要方法，避免父组件依赖内部实现。若监听目标会动态变化，用 `watch` 旧值清理或封装 composable，保证每次注册都有对应注销。
