# Vue 属性透传：让包装组件保留原生能力

包装按钮或输入框时，调用方传入的 `aria-*`、`data-*` 和原生事件默认会落到组件根节点。若根节点不是目标元素或组件有多个根节点，就要显式控制 `$attrs`。

```vue
<script setup lang="ts">
defineOptions({ inheritAttrs: false })
defineProps<{ label: string }>()
</script>

<template>
  <label class="field">
    <span>{{ label }}</span>
    <input v-bind="$attrs">
  </label>
</template>
```

这样 `id`、`name`、`disabled`、`aria-describedby` 与 `@blur` 都传给真正的输入框。组件自己声明的 props 和 emits 不会留在 `$attrs` 中。

不要逐个猜测所有 HTML 属性，也不要把 `$attrs` 同时绑定到多个交互元素，否则事件可能重复触发。组件测试应覆盖键盘焦点、禁用态、辅助说明关联和事件参数，确保封装没有损坏平台原生语义。
