# Vue 列表 key：用稳定身份保住组件状态

key 决定 Vue 在列表更新时复用哪个组件实例。使用数组下标后，在头部插入或排序会让输入值、焦点和子组件状态跟着位置走。

~~~vue
<script setup lang="ts">
import { ref } from 'vue'
const rows = ref([{ id: 'a', name: '甲' }, { id: 'b', name: '乙' }])
</script>

<template>
  <label v-for="row in rows" :key="row.id">
    {{ row.name }}
    <input :name="'note-' + row.id">
  </label>
</template>
~~~

key 应来自后端主键或创建时生成且持久的 ID，不能在渲染期间调用随机函数。筛选、排序和分页后同一实体保持相同 key；确实需要重置组件时，才有意更换 key。用填写输入后重排列表的测试最容易发现身份错误。
