# Vue 类型化 provide/inject：用 Symbol 避免依赖冲突

跨多层组件共享局部服务时，provide/inject 比逐层传 props 更直接。TypeScript 项目可用 InjectionKey 让提供者和消费者共享类型。

~~~ts
import { inject, provide, type InjectionKey, type Ref } from 'vue'

type Theme = 'light' | 'dark'
export const themeKey: InjectionKey<Ref<Theme>> = Symbol('theme')
// 父组件 setup：provide(themeKey, themeRef)
const theme = inject(themeKey)
if (!theme) throw new Error('theme provider is missing')
~~~

Symbol 可避免不同模块使用相同字符串键。依赖若为必需项，缺失时尽早抛出清晰错误；可选项则提供显式默认值。修改共享状态的函数最好由提供者暴露，消费者不要任意改深层对象。全局业务状态较复杂时仍应使用专门状态管理。
