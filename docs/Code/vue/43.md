# Vue Teleport 弹层：视觉越级但状态仍在原组件树

对话框嵌在有 overflow 或 transform 的容器内时容易被裁切。Teleport 可把 DOM 渲染到 body，同时保持事件、props 和响应式状态属于原组件。

~~~vue
<script setup lang="ts">
import { ref } from 'vue'
const open = ref(false)
</script>

<template>
  <button @click="open = true">打开</button>
  <Teleport to="body">
    <div v-if="open" role="dialog" aria-modal="true" aria-labelledby="dialog-title">
      <h2 id="dialog-title">确认操作</h2>
      <button @click="open = false">关闭</button>
    </div>
  </Teleport>
</template>
~~~

Teleport 只解决挂载位置，不自动实现焦点循环、Escape 关闭、背景不可交互和关闭后焦点归还。目标节点必须存在，SSR 还要考虑水合顺序。优先复用经过无障碍验证的弹层组件，而不是每个页面手写一套。
