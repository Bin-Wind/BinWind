# Vue shallowRef：为大型外部对象减少深层代理

图表实例、编辑器对象或大型不可变数据不需要 Vue 递归代理。用 ref 包装会遍历深层结构并可能影响第三方库的身份判断；shallowRef 只追踪 .value 的替换。

~~~vue
<script setup lang="ts">
import { shallowRef, triggerRef } from 'vue'

const rows = shallowRef([{ id: 1, name: '甲' }])
function replaceRows() {
  rows.value = [...rows.value, { id: 2, name: '乙' }]
}
function mutateForLegacyCode() {
  rows.value.push({ id: 3, name: '丙' })
  triggerRef(rows)
}
</script>

<template><button @click="replaceRows">新增</button>{{ rows.length }}</template>
~~~

优先用不可变替换触发更新；triggerRef 只适合无法避免的原地修改，并应封装在单一边界。shallowRef 不是通用性能开关，表单等需要深层响应的状态仍应使用 ref 或 reactive。用真实数据量测量渲染和内存，再决定是否改变模型。
