# Vue useId：为表单生成 SSR 稳定的关联标识

可复用组件若把 id 写死，页面出现多个实例时 label 会指向错误输入框。随机数又可能让服务端渲染与客户端水合不一致。Vue 的 useId 为应用生成稳定且唯一的标识。

~~~vue
<script setup lang="ts">
import { useId } from 'vue'
const id = useId()
</script>

<template>
  <label :for="id">邮箱</label>
  <input :id="id" type="email" autocomplete="email">
</template>
~~~

同一组件需要提示和错误说明时，可从基础 id 派生后缀，并用 aria-describedby 连接。不要把 useId 的结果当数据库主键或跨会话持久标识，它只服务于当前渲染树。若项目使用的 Vue 版本尚不支持 useId，应由父组件传入确定性 id，而不是在模板求值时生成随机值。
