# Vue 路由离开保护：只在确有未保存修改时拦截

编辑页无条件弹出“确定离开吗”会训练用户机械确认。应从初始快照与当前值计算脏状态，只在确有未保存修改时注册路由保护。

~~~vue
<script setup lang="ts">
import { computed, ref } from 'vue'
import { onBeforeRouteLeave } from 'vue-router'

const initial = '草稿'
const title = ref(initial)
const dirty = computed(() => title.value !== initial)

onBeforeRouteLeave(() => {
  if (!dirty.value) return true
  return window.confirm('修改尚未保存，仍要离开吗？')
})
</script>

<template><input v-model="title"></template>
~~~

保存成功后更新基准快照，不能只把布尔值清零。浏览器刷新与关闭需要另行处理 beforeunload，并仅在脏状态期间监听。复杂表单应规范化比较，排除后端自动字段；能自动保存时展示同步状态和冲突处理，比频繁拦截更可靠。
