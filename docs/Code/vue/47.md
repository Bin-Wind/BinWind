# Vue readonly：向消费组件暴露只读状态

组合式函数可以在内部维护可变状态，对外只暴露只读视图和明确动作。这样消费组件不会绕过业务规则直接赋值。

~~~vue
<script setup lang="ts">
import { readonly, ref } from 'vue'

function useCounter() {
  const count = ref(0)
  const increment = () => {
    if (count.value < 10) count.value++
  }
  return { count: readonly(count), increment }
}

const { count, increment } = useCounter()
</script>

<template>
  <button type="button" @click="increment">
    次数：{{ count }}
  </button>
</template>
~~~

`readonly` 是运行时代理，开发模式下会对写入发出警告；它不是权限或安全边界。若返回的原对象还被其他代码持有，那些代码仍能修改状态。

对外类型也应表达只读意图，动作名称则描述业务行为而不是 `setState`。需要快照时另行复制，不能把响应式只读代理误认为不可变化的历史值。
