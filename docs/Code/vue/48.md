# Vue toValue：统一接收值、Ref 与 Getter

可复用组合式函数常希望参数既能是普通值，也能是 `ref` 或计算 getter。Vue 3.3 起的 `toValue` 会统一解包，并在 getter 场景保留依赖追踪。

~~~vue
<script setup lang="ts">
import { ref, toValue, watchEffect, type MaybeRefOrGetter } from 'vue'

function useGreeting(name: MaybeRefOrGetter<string>) {
  watchEffect(() => {
    console.log(`你好，${toValue(name)}`)
  })
}

const first = ref('小风')
const last = ref('同学')

useGreeting(() => `${first.value}${last.value}`)
setTimeout(() => { first.value = '阿风' }, 500)
</script>

<template>
  <p>{{ first }}{{ last }}</p>
</template>
~~~

只在响应式作用域里调用 `toValue`，getter 读取的依赖才会被 `watchEffect` 或 `watch` 收集。普通字符串不会自动变成响应式，这是预期行为。

API 文档应明确是否接受 getter，以及回调会在何时重新执行。异步副作用还需要清理过期请求，统一输入形式并不替代生命周期管理。
