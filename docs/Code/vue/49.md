# Vue markRaw：让外部实例避开深层响应式代理

编辑器、图表或地图实例通常有自己的状态系统，把它们深度代理既无收益，也可能影响身份判断。`markRaw` 可以让对象保持原样，再用 `shallowRef` 跟踪实例是否被替换。

~~~vue
<script setup lang="ts">
import { markRaw, onBeforeUnmount, onMounted, shallowRef } from 'vue'

class DemoWidget {
  constructor(readonly element: HTMLElement) {}
  destroy() { this.element.textContent = '' }
}

const host = shallowRef<HTMLElement | null>(null)
const widget = shallowRef<DemoWidget | null>(null)

onMounted(() => {
  if (host.value) widget.value = markRaw(new DemoWidget(host.value))
})

onBeforeUnmount(() => {
  widget.value?.destroy()
  widget.value = null
})
</script>

<template><div ref="host">外部组件容器</div></template>
~~~

`markRaw` 只标记传入对象；其未标记的嵌套对象若后来被放进响应式状态，仍可能被代理。不要把它用作普遍性能开关，普通业务对象依赖深层响应时不应跳过代理。

外部实例仍需在组件卸载时清理监听器、定时器和 DOM。是否代理与是否释放资源是两件独立的事。
