# Vue customRef：实现可控的防抖输入状态

`customRef` 允许显式决定何时追踪依赖、何时触发更新。它适合将输入即时值与对外防抖值封装在组合式函数中，但组件卸载时必须清理定时器。

```vue
<script setup lang="ts">
import { customRef, onScopeDispose } from 'vue'

function useDebouncedRef<T>(initial: T, delay = 300) {
  let value = initial
  let timer: ReturnType<typeof setTimeout> | undefined

  onScopeDispose(() => clearTimeout(timer))

  return customRef<T>((track, trigger) => ({
    get() {
      track()
      return value
    },
    set(next) {
      clearTimeout(timer)
      timer = setTimeout(() => {
        value = next
        trigger()
      }, delay)
    },
  }))
}

const query = useDebouncedRef('', 250)
</script>

<template>
  <input v-model="query" type="search" aria-label="搜索" />
</template>
```

这个实现连输入框显示也会延迟，因为 getter 只返回已提交值。多数搜索框更适合维护一个即时 `input` ref，再把防抖后的值用于请求；是否延迟 UI 必须由交互目标决定。

## 避免隐藏副作用

`customRef` 只管理状态触发，不应偷偷发网络请求。用 `watch` 观察防抖值，并通过清理回调取消旧请求，职责更清晰。对象值尽量保持稳定引用，避免 getter 每次返回新对象导致子组件无谓更新。
