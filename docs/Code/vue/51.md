# Vue onScopeDispose：让组合式函数离开作用域就清理资源

组合式函数可能创建计时器、订阅或外部监听。只依赖组件的 `onUnmounted` 会限制复用范围；`onScopeDispose` 会在当前响应式作用域停止时运行，既适用于组件，也适用于 `effectScope`。

```typescript
import { onScopeDispose, ref } from 'vue'

export function useClock(intervalMs = 1000) {
  const now = ref(new Date())
  const timer = window.setInterval(() => {
    now.value = new Date()
  }, intervalMs)

  onScopeDispose(() => window.clearInterval(timer))
  return { now }
}
```

组件在 `setup` 中调用时，会自动拥有活动作用域；组件卸载后定时器被清理。不要在异步回调很晚才注册清理函数，因为那时活动作用域可能已经不存在。

## 在独立作用域中使用

```typescript
import { effectScope } from 'vue'

const scope = effectScope()
scope.run(() => {
  useClock()
})

scope.stop() // 触发组合式函数的清理
```

这对可启停模块和测试很有用。每个创建资源的位置都应紧邻注册清理逻辑；多个调用各自持有资源，不能用一个全局定时器 ID 相互覆盖。开发测试可挂载、卸载组件后确认监听器数量与计时器都回到基线。
