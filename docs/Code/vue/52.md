# Vue defineModel 修饰符：显式处理组件双向绑定

Vue 3.4 起，`defineModel` 可简化组件的 `modelValue` prop 与 `update:modelValue` 事件。组件需要支持 `.trim` 等修饰符时，可以读取 modifiers 并在 `set` 转换中明确处理。

```vue
<!-- NameField.vue -->
<script setup lang="ts">
const [model, modifiers] = defineModel<string>({
  required: true,
  set(value) {
    return modifiers.trim ? value.trim() : value
  },
})
</script>

<template>
  <input v-model="model" autocomplete="name" />
</template>
```

父组件使用：

```vue
<NameField v-model.trim="name" />
```

## 转换时机要符合预期

示例会在每次输入更新时 `trim`，可能让用户难以输入尾随空格。实际表单常在 `blur` 或提交时规范化；此时不要仅为代码简短而强行放进 setter。

多个双向字段可以用命名 model，例如 `defineModel<string>('title')` 对应 `v-model:title`。名称是组件 API，应与 prop 文档、验证和错误提示一致。

`defineModel` 不能消除数据所有权问题。复杂对象若在子组件中原地修改，父层很难审计变化；优先产生新值并发出更新。测试应覆盖默认值、修饰符以及父组件外部重置后的同步行为。
