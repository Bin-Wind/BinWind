# Vue defineExpose：只向父组件开放必要能力

`<script setup>` 组件默认不会把内部变量全部暴露给模板引用。需要让父组件触发聚焦、校验等命令式能力时，使用 `defineExpose` 建立小而稳定的公开接口。

```vue
<!-- SearchBox.vue -->
<script setup lang="ts">
import { ref } from 'vue'

const input = ref<HTMLInputElement | null>(null)

function focus() {
  input.value?.focus()
}

defineExpose({ focus })
</script>

<template>
  <input ref="input" type="search" />
</template>
```

父组件通过模板引用调用 `focus()`，但不需要知道子组件内部 DOM 结构。公开原始响应式状态或多个内部元素会增加耦合，重构时也更容易破坏调用方。

## 命令式接口的边界

数据仍优先通过 props 下发、事件上送。只有聚焦、滚动、播放控制等天然命令式动作适合暴露。方法应说明挂载前、卸载后和禁用状态的行为，并避免静默修改父层拥有的数据。

模板引用在挂载前是空值，条件渲染后也可能再次为空。调用方应判空，并在组件测试中覆盖显示切换与多实例场景。若父组件需要频繁读取大量内部状态，通常说明组件边界需要重新设计。
