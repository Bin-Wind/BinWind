# Vue defineEmits 校验：让组件事件在开发阶段尽早失败

组件事件是公开 API。只声明事件名称能防止监听器被当作属性透传，但对复杂载荷还可提供运行时校验，在开发阶段发现字段缺失。

```vue
<script setup lang="ts">
type SavedItem = { id: string; title: string }

const emit = defineEmits<{
  save: [item: SavedItem]
  cancel: []
}>()

function submit() {
  emit('save', { id: 'draft-1', title: '草稿' })
}
</script>
```

类型声明约束本项目中的 TypeScript 调用者，但运行时收到的数据仍可能来自 API 或普通 JavaScript。需要时可改用对象形式验证关键不变量；验证器返回 `false` 会给出开发警告，不能替代真正的输入拒绝与错误处理。

## 事件名和载荷设计

事件描述已经发生的事实，如 `saved`、`selection-change`，或描述明确请求，如 `submit`。避免一个 `change` 事件根据字段猜测多种含义。载荷只包含调用方需要的信息，不传 DOM 节点和庞大内部对象。

Vue 自定义事件不会像 DOM 事件一样跨组件层级冒泡。跨多层状态应提升所有权、使用注入服务或状态管理，而不是逐层假设冒泡。测试应验证事件次数、顺序和完整载荷。
