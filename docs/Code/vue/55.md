# Vue KeepAlive 激活钩子：缓存页面恢复时重新校准外部状态

被 `<KeepAlive>` 缓存的组件切走时通常不会卸载，而是进入停用状态；返回时重新激活。只依赖 `onMounted` 和 `onUnmounted`，可能让轮询、键盘监听或数据新鲜度在缓存期间失控。

```vue
<script setup lang="ts">
import { onActivated, onDeactivated, ref } from 'vue'

const lastRefresh = ref(0)
let timer: number | undefined

async function refresh() {
  lastRefresh.value = Date.now()
}

onActivated(() => {
  if (Date.now() - lastRefresh.value > 60_000) refresh()
  timer = window.setInterval(refresh, 60_000)
})

onDeactivated(() => {
  if (timer !== undefined) window.clearInterval(timer)
  timer = undefined
})
</script>
```

激活钩子第一次挂载时也会运行，逻辑必须可重复。停用时取消轮询、媒体播放和全局监听，但是否取消正在进行的请求取决于结果能否安全写入缓存状态；若取消，要传递 `AbortSignal` 并识别取消错误。

`KeepAlive` 适合保留昂贵页面状态，不应作为修复错误数据所有权的手段。设置 `include`、`exclude` 或 `max` 时使用稳定组件名，并测试缓存淘汰后真正卸载的清理路径。
