# Vue useTemplateRef：用稳定名称取得模板引用

Vue 3.5 的 `useTemplateRef` 让模板 `ref` 与脚本引用通过同一个名字关联，不再需要手工声明同名的 `ref(null)`。

```vue
<script setup>
import { onMounted, useTemplateRef } from 'vue'

const searchInput = useTemplateRef('search')
onMounted(() => searchInput.value?.focus())
</script>

<template>
  <input ref="search" type="search" aria-label="站内搜索" />
</template>
```

引用在组件挂载前为 `null`，元素被 `v-if` 移除后也会恢复为 `null`，因此访问时要处理生命周期。`v-for` 中的模板引用会得到元素数组，但顺序不应被当作业务主键。

引用子组件时只能访问它公开的实例能力；`<script setup>` 子组件应通过 `defineExpose` 明确暴露。能用 props 和事件表达的数据流，不要因为模板引用方便就改成父组件直接操纵子组件内部状态。
