# Vue triggerRef：外部对象原地变化后显式通知视图

`shallowRef` 只追踪 `.value` 的替换，不追踪对象深层修改。集成地图、图表等外部可变对象时，可在批量原地修改后调用 `triggerRef` 通知依赖更新。

```vue
<script setup>
import { shallowRef, triggerRef } from 'vue'

const state = shallowRef({ points: [] })
function addPoint(point) {
  state.value.points.push(point)
  triggerRef(state)
}
</script>

<template><p>点数：{{ state.points.length }}</p></template>
```

若可以采用不可变更新，`state.value = {...state.value, points: [...]}` 更容易追踪历史，也无需手动触发。`triggerRef` 适合明确的批处理边界，不应散落在每个深层赋值后，否则很难证明视图何时同步。

外部实例可配合 `markRaw` 避免代理。测试要覆盖修改后是否触发、连续修改是否只刷新一次，以及组件卸载后订阅是否清理。
