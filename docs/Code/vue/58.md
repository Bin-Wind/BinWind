# Vue defineAsyncComponent：把重组件延迟到真正需要时

`defineAsyncComponent` 可以把编辑器、图表等重组件拆成独立 chunk，在组件首次渲染时再加载。

```vue
<script setup>
import { defineAsyncComponent } from 'vue'

const ReportChart = defineAsyncComponent({
  loader: () => import('./ReportChart.vue'),
  delay: 150,
  timeout: 10_000,
  onError(error, retry, fail, attempts) {
    if (attempts <= 2) retry()
    else fail(error)
  }
})
</script>

<template><Suspense><ReportChart /></Suspense></template>
```

重试只适合临时网络失败；构建产物缺失等确定性错误反复重试没有意义。生产界面应提供可访问的加载和失败状态，并避免短请求闪烁，所以可设置合理 delay。

按路由或用户动作预加载可以降低等待，但会增加流量。用真实包体、缓存命中率和交互时间验证拆分收益，不要把每个小组件都异步化，造成大量额外请求与复杂错误路径。
