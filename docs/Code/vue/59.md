# Vue shallowReadonly：只保护容器第一层的边界

`shallowReadonly` 只阻止顶层属性被替换，嵌套对象仍可修改。它适合明确表达“容器结构由提供者控制，内部对象由其他系统管理”，不适合假装实现深度不可变。

```vue
<script setup>
import { reactive, shallowReadonly } from 'vue'

const source = reactive({ profile: { name: '小林' }, version: 1 })
const view = shallowReadonly(source)

function rename() {
  view.profile.name = '小周' // 嵌套对象仍可写
  // view.version++          // 开发环境会警告：顶层只读
}
</script>

<template>
  <button @click="rename">{{ view.profile.name }} · v{{ view.version }}</button>
</template>
```

若组件不应修改嵌套状态，应暴露只读快照或操作函数，而不是依赖团队记忆。选择 `readonly`、`shallowReadonly` 前，把允许修改的层级写进接口约定。
