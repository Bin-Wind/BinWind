# Vue effectScope：成组启动并停止响应式副作用

在组件外创建多个 `watch` 或 `watchEffect` 时，可以用 `effectScope` 统一管理生命周期，避免每个调用者分别保存停止函数。

```vue
<script setup>
import { effectScope, onUnmounted, ref, watch } from 'vue'

const count = ref(0)
const scope = effectScope()

scope.run(() => {
  watch(count, value => console.log('count:', value))
  watch(count, value => {
    if (value >= 3) console.log('达到提醒阈值')
  })
})

onUnmounted(() => scope.stop())
</script>

<template>
  <button @click="count++">增加：{{ count }}</button>
  <button @click="scope.stop()">停止观察</button>
</template>
```

组件 `setup` 内的副作用本来就会随组件卸载；`effectScope` 的价值主要在可复用服务、临时工作区或一次启动多项观察的场景。停止后不要假定可再次运行同一 scope，需要重建实例。
