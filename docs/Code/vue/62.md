# Vue customRef：为输入框封装可复用防抖状态

搜索框若在每次按键后立即请求，会制造过多调用。`customRef` 允许控制依赖何时被追踪、何时触发更新，可把防抖行为封装成普通 Ref。

```vue
<script setup>
import { customRef, watch } from 'vue'

function useDebouncedRef(initialValue, delay = 300) {
  let value = initialValue
  let timer

  return customRef((track, trigger) => ({
    get() {
      track()
      return value
    },
    set(nextValue) {
      clearTimeout(timer)
      timer = setTimeout(() => {
        value = nextValue
        trigger()
      }, delay)
    },
  }))
}

const query = useDebouncedRef('', 300)

watch(query, (value) => {
  console.log('执行搜索:', value)
})
</script>

<template>
  <input v-model="query" type="search" placeholder="搜索" />
</template>
```

这个实现让输入框显示也延迟更新，快速输入时可能感觉不跟手。更常见的产品需求是保留一个即时 `rawQuery` 驱动输入框，再把防抖后的值用于请求；选择哪种语义要显式说明。

定时器属于外部资源。若封装在长期复用的组合式函数中，可提供清理方法，或在组件卸载时取消。防抖只减少触发次数，不能解决旧请求晚于新请求返回的问题；网络查询还应使用 `AbortController` 或请求序号丢弃过期响应。
