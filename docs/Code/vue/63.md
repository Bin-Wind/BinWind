# Vue markRaw：让第三方实例退出深层响应式

Vue 会把放入响应式对象的普通对象转换为代理。编辑器、地图或图表库的实例通常拥有自己的状态系统，不需要被深层代理；`markRaw` 可以明确告诉 Vue 保留原对象。

```vue
<script setup>
import { markRaw, onBeforeUnmount, shallowRef } from 'vue'

class PreviewEngine {
  destroy() {
    console.log('engine destroyed')
  }
}

const engine = shallowRef(null)

function start() {
  engine.value = markRaw(new PreviewEngine())
}

onBeforeUnmount(() => {
  engine.value?.destroy()
  engine.value = null
})
</script>

<template>
  <button @click="start">启动预览</button>
  <p>{{ engine ? '已启动' : '未启动' }}</p>
</template>
```

这里使用 `shallowRef` 追踪实例引用是否被替换，同时用 `markRaw` 避免实例内部被代理。实例内部状态变化不会自动刷新模板，需要把真正影响界面的值单独放进 `ref`。

`markRaw` 只标记传入对象本身。若把它的未标记嵌套对象取出再放入另一个响应式对象，那个嵌套对象仍可能被代理，造成原对象与代理对象身份不一致。它适合明确的集成边界，不应作为遇到响应式问题时的通用开关。无论是否代理，第三方实例的销毁与事件解绑都仍由组件负责。
