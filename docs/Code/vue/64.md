# Vue toValue：统一读取普通值、Ref 与 Getter

组合式函数常希望同时接受固定值、Ref 和 Getter。Vue 3.3 起的 `toValue` 会统一解包三种输入：普通值原样返回，Ref 读取 `.value`，函数则执行并返回结果。

```vue
<script setup>
import { ref, toValue, watchEffect } from 'vue'

function useDisplay(source) {
  watchEffect(() => {
    console.log('当前值:', toValue(source))
  })
}

const count = ref(1)
useDisplay(count)
useDisplay(() => count.value * 2)
useDisplay('固定文本')

count.value++
</script>

<template>
  <button @click="count++">{{ count }}</button>
</template>
```

与 `unref` 不同，`toValue` 会调用 Getter。因此若普通函数本身就是要传递的数据，不应交给 `toValue`，否则它会被执行。Getter 也应保持无副作用，避免每次响应式重新求值都修改外部状态。

## 让依赖在正确位置被收集

在 `watchEffect` 或 `watch(() => toValue(source), ...)` 内调用，Getter 访问的响应式依赖才会被追踪。若只在组合式函数初始化时读取一次，后续 Ref 变化不会自动触发任何逻辑。

公开 API 时可将参数类型命名为 `MaybeRefOrGetter<T>`，并在文档中说明函数输入会被求值。统一输入形态能减少调用方样板代码，但不能模糊“回调函数”和“值 Getter”之间的语义。
