# 数据表格设计：在密度与可读性之间取平衡

数据表格的任务是帮助用户扫描、比较并采取动作。先确认核心问题：用户最常按什么定位记录、比较哪些字段、接下来要做什么，而不是把数据库所有列直接搬到界面。

## 建立列优先级

第一列提供稳定识别信息，关键状态和数值靠前，低频元数据允许隐藏。数字右对齐并统一小数位，文本左对齐；日期明确时区或相对时间含义。不要只靠颜色表达状态，同时提供文字或图标标签。

## 处理宽表

优先允许用户选择列、固定识别列和横向滚动。把次要信息放入可展开行，胜过无限压缩列宽。手机端可转为卡片，但应保留同样的信息优先级与操作能力。

## 排序、筛选与批量操作

表头明确显示当前排序方向；筛选条件可见、可清除，并能恢复上次工作状态。批量动作必须显示已选数量与作用范围，分页全选尤其要区分“本页”与“全部结果”。

交付时覆盖加载、空结果、部分失败、无权限、长文本和极端数值。用真实规模数据测试，而不是只放三行整齐样例。
