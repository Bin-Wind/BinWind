# 国际化界面设计：为文本增长和文化差异留空间

国际化不是翻译完成后的工程修补。文字长度、阅读方向、日期、姓名和复数规则都会改变布局，设计稿应提前容纳这些变化。

## 弹性布局

按钮用内边距而非固定宽度，文本容器允许换行，导航为长标签准备折叠方案。不要把文字烘焙进图片。图标若依赖方向含义，在从右到左语言中要判断是否镜像。

## 内容与格式

避免拼接“您有”+ 数字 +“条消息”，完整句子交给本地化系统处理。日期、时间、数字和货币使用区域格式化；展示时区，尤其是会议和截止时间。姓名字段不要默认人人都有姓和名两个部分。

## 伪本地化测试

在翻译前把字符串扩展约 30%～50%，加入带重音字符，并测试从右到左布局。重点检查截断、重叠、图标方向、表格和弹窗。最终仍需母语审校，因为布局通过不代表语气与含义正确。

组件库应记录文本最大行数、溢出策略和双向布局行为，使国际化能力成为系统约束，而不是每个页面临时处理。
