# 站内搜索设计：从空查询到无结果恢复

搜索体验不仅是输入框和结果列表。用户需要知道可搜什么、当前用了哪些条件，以及无结果后如何继续。

## 输入与建议

占位文案说明范围，例如“搜索标题、作者或标签”。输入时的建议区分历史、实体和操作，并通过分组标题建立预期。键盘上下选择、回车确认和 Escape 关闭都应可用；焦点样式不能只靠颜色。

## 结果可判断

每条结果展示与选择相关的最少信息，并高亮真正匹配字段。排序方式要可理解，筛选条件用可单独移除的标签展示。分页或无限滚动都要保留返回位置，否则用户查看详情后会丢失上下文。

无结果页保留原查询，指出可能过严的筛选，提供清除筛选、检查拼写和浏览相关分类等行动。不要伪造“相似结果”却不说明匹配变宽。

评估时除了搜索成功率，还看首次有效点击时间、查询改写率和无结果恢复率。高频无结果词应反馈给内容与同义词维护，而不是只优化界面。
