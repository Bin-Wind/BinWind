# 数据图表无障碍：颜色之外还要有结构

图表若只用红绿区分类别，色觉差异用户难以判断；若只有画布或 SVG 图形，屏幕阅读器也无法获得数据关系。无障碍设计要同时覆盖感知、操作与替代内容。

## 视觉编码冗余

颜色之外增加线型、点形、直接标签或图案。文本与背景保持足够对比，细线和小标记也要在低对比屏幕上可见。不要让悬停成为唯一入口，键盘焦点和触摸点击也应能打开同一提示。

## 提供等价信息

图表标题先说结论，副标题说明范围与单位。紧邻图表提供可访问的数据表或摘要，包含峰值、变化方向和异常点。复杂图表可用分层描述：一句总览、关键发现、最后是完整数据。

筛选或时间范围变化后，通过合适的状态区域通知辅助技术，但避免每次指针移动都播报。导出的图片要有替代文本，导出的数据保留列名和单位。

测试时仅用键盘完成筛选，再用屏幕阅读器理解趋势；同时检查灰度打印和放大 200% 后是否仍能识别。合规检查是底线，用户能否得出同样结论才是目标。
