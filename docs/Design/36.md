# 渐进式引导：让新用户先完成一次真实任务

首次打开就展示十张功能卡片，用户记不住，也无法感受产品价值。好的引导围绕一个最短成功路径，只在相关时刻解释必要概念。

## 从目标而非功能出发

先问用户想完成什么，再给出一个可跳过的示例或导入入口。每一步只要求当前任务必需的信息；高级配置使用安全默认值，成功后再提供调整入口。

例如项目管理工具的首次路径可以是：

1. 创建或导入一个真实项目；
2. 添加一项今天要做的任务；
3. 邀请协作者，或明确选择稍后邀请；
4. 展示任务已进入日程，并给出下一步。

进度指示应反映真实长度。不要用未告知的额外步骤延长流程，也不要把“允许营销通知”混入完成条件。

## 允许退出与恢复

引导随时可跳过，重新进入时从已完成状态继续，而不是清空用户数据。空状态用真实动作按钮承接任务，工具提示则在用户第一次遇到功能时出现。

评估完成率之外，还要看用户是否在一天或一周后再次完成核心任务。通过新手访谈观察卡点，区分“没看懂”和“此刻不需要”。引导减少的是理解成本，不应成为阻挡产品的必经长廊。
