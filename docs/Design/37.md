# 长表单信息层级：降低填写与复核成本

长表单的问题通常不是字段太多，而是用户不知道为什么要填、哪些必填、错误在哪里。信息层级应帮助用户形成小块目标，并在提交前快速复核。

## 按用户任务分组

使用有意义的小节标题，如“收件地址”“开票信息”，而不是“步骤 1”。相关字段保持邻近，条件字段在触发后就地出现。必填与选填用文字标识，不能只靠星号。

单列布局通常更容易扫描；日期、金额、单位等关联输入可并排，但移动端必须保持合理顺序。说明文字放在字段旁，示例不能只依赖输入框 placeholder，因为输入后它会消失。

## 错误要能被找到和修正

失焦时校验格式，提交时做完整业务校验。错误信息说明问题和修复方式，并与字段程序化关联。提交失败后：

- 页面顶部给出错误摘要和可跳转链接；
- 保留所有合法输入；
- 焦点移到摘要或第一个错误；
- 不清除用户上传或已完成的步骤。

长流程可自动保存草稿并显示保存时间，但涉及敏感信息要说明保留策略。上线前用键盘完成整份表单、模拟慢网与服务端错误，并记录各字段放弃率；不要只看最终提交按钮点击量。
