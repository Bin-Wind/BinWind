# 分页与无限滚动：按用户任务选择浏览方式

无限滚动适合连续探索，分页适合定位、比较和返回。选择应由任务决定，不能只看哪种交互更“流畅”。

## 给用户稳定的位置感

搜索结果、订单和管理列表通常需要页码、总数、筛选与可分享 URL。内容流可使用“加载更多”或无限滚动，但要保留已读位置，并允许访问页脚和跳过长列表。

加载新内容时不要突然移动现有项目。显示明确的加载状态与重试按钮，将新增结果公告给读屏软件，但避免每一项都打断用户。浏览器返回后应恢复筛选、排序、滚动位置和已加载批次。

无论哪种方式，后端都要定义稳定排序；数据更新时仅按偏移分页可能重复或漏项，游标分页更适合连续流。测试键盘导航、慢网、空结果、末页和插入新内容的情况，并观察用户是否能完成“找到刚才那一项”的任务。
