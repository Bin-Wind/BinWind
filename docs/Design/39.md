# 对话框焦点管理：打开、循环与关闭都有落点

视觉上盖住页面不等于形成可用的模态对话框。键盘和读屏用户需要知道对话框已打开，焦点不能落到背后的页面。

## 设计完整的焦点旅程

打开时把焦点放到标题、首个字段或最安全的主要动作，取决于内容长度和风险。Tab 与 Shift+Tab 在对话框可交互元素间循环；背景内容设为不可交互。Escape 是否关闭要符合任务性质，未保存输入应先提示。

关闭后通常把焦点还给触发按钮；若触发项已被删除，则移到逻辑上的邻近元素或列表标题。嵌套对话框容易让焦点和层级失控，应优先改成单一流程。

语义上使用原生 `dialog` 或正确的 dialog role、可访问名称和模态属性。测试鼠标、键盘、读屏、内容滚动、错误提示以及动态按钮禁用。不要仅依赖焦点环颜色，保证轮廓与背景有足够对比。
