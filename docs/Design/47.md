# 表单错误关联：让提示被看见也能被读屏定位

只把输入框描红，会让色觉差异用户和读屏用户难以理解错误。每条提示应说明具体问题，并通过程序关系绑定到对应字段。

~~~html
<label for="email">邮箱</label>
<input
  id="email"
  name="email"
  type="email"
  aria-invalid="true"
  aria-describedby="email-hint email-error"
>
<p id="email-hint">用于接收登录链接</p>
<p id="email-error">请输入完整邮箱，例如 name@example.com</p>
~~~

提交失败后在表单顶部提供错误摘要，并把每项链接到字段；同时把焦点移到摘要或第一个错误，避免用户从头寻找。提示应保留用户已经输入的内容，密码等敏感字段则按安全策略处理。

校验时机要克制：用户尚未完成输入就不断报错会制造噪声。通常在字段离开焦点或提交后显示，再在用户修正时及时清除。验收需覆盖键盘、读屏、放大和只看灰度的场景。
