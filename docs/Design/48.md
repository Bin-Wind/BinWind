# 焦点可见性：为键盘操作保留清楚路径

键盘用户依靠焦点环判断下一次操作作用在哪里。全局写 `outline: none` 会让界面看似干净，却切断了这条路径。应设计与背景有足够对比、不会被裁切的焦点样式。

~~~css
:where(a, button, input, select, textarea):focus-visible {
  outline: 3px solid #0b63ce;
  outline-offset: 3px;
}

.card:focus-within {
  box-shadow: 0 0 0 2px #b8d7ff;
}
~~~

`:focus-visible` 通常只在键盘等需要提示的交互中显示，鼠标点击不必强制出现同样样式。组件库要为浅色、深色、错误态和高对比模式分别验证，不要只在白底按钮上检查。

焦点顺序应跟视觉与阅读顺序一致，弹窗打开时进入弹窗、关闭后回到触发按钮。不要用正数 `tabindex` 手工拼顺序；优先调整 DOM 结构。验收时只用 Tab、Shift+Tab、Enter、Space 和 Escape 完成核心流程。
