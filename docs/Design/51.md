# 会话即将过期提示：给用户保存与续期的机会

出于安全原因，系统可能在无操作后结束会话。若用户正在填写长表单，突然跳回登录页会造成数据丢失。过期提示应同时说明剩余时间、可采取动作和续期失败的后果。

## 提示出现时机

在真正过期前给出足够时间，使用明确文案：“会话将在 2 分钟后结束”。提供“继续会话”和“退出”两个动作，并把键盘焦点移入对话框、限制焦点循环。倒计时变化不应每秒被读屏器高频朗读，可在关键节点用适度的 live region 提醒。

## 保存用户工作

可以安全本地保存的草稿应提前保存并明确隐私边界；敏感字段不应无条件落到浏览器存储。续期请求失败时保留仍可保留的内容，提供重新登录后恢复路径。不要以模拟鼠标或后台心跳无限绕过组织规定的绝对会话上限。

## 多标签页与服务端时间

多个标签页应共享最新会话状态，避免一个页面已续期、另一个仍强制退出。倒计时以服务端返回的到期时间为准，并容忍客户端时钟偏差。收到 401 后停止继续提交写请求，先进入可恢复的登录流程。

测试覆盖键盘、读屏、后台标签页、网络断开和恰在提交时过期。验收标准是用户知道发生了什么，并能保存、续期或安全退出。
