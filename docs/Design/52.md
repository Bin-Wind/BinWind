# 图表替代说明：让数据关系不只存在于颜色和形状里

一张图表的无障碍支持不只是加一句“销售趋势图”。替代内容应传达图的目的、关键关系与可访问的数据入口，同时避免把屏幕上每个点机械朗读一遍。

## 分三层提供信息

图表前用标题说明问题，例如“各地区季度退货率”。紧邻图表给出短摘要，写出峰值、显著变化和异常点。再提供可展开的数据表或下载入口，使用户能查到精确值。

颜色编码同时配合标签、纹理或线型；图例顺序与视觉顺序一致。交互点要能用键盘到达，焦点样式清楚，并用文本报告系列、横轴值和纵轴值。悬浮提示不能是唯一入口。

## 不替用户下过度结论

摘要可写“华东从 3.1% 升至 4.8%”，不要在没有证据时写“因为物流问题”。轴截断、缺失值和单位应明确说明。实时数据注明更新时间，避免截图与当前数值混淆。

## 验证方式

关闭颜色、放大至 200%、仅用键盘完成“找到最高值”和“比较两个季度”等任务，再用读屏器检查标题、摘要与表格阅读顺序。若图表很复杂，为不同任务提供筛选后的简化表，通常比让一个 SVG 承担所有信息更可靠。
