# 对象命名一致性：让同一个概念在界面里只有一个名字

同一对象若在导航中叫“项目”、按钮里叫“空间”、提示里又叫“工作区”，用户会怀疑它们是否不同。命名一致性是一项信息架构工作，不只是文案润色。

## 建立界面词汇表

为核心对象记录首选名称、定义、允许的短称、禁用同义词和典型动作。例如“归档项目”与“删除项目”必须有不同含义；名词和动词不要互相替代。产品、帮助文档、通知邮件和客服话术共用同一来源。

检查名称在单复数、量词和本地化后的变化。英文缩写第一次出现时给出完整含义；行业术语若用户并不熟悉，优先使用任务语言。变量名不必直接暴露给用户，但分析事件和接口字段应能映射回同一概念。

## 在真实流程中走查

从创建、分享、移动、归档到恢复串起一条流程，搜索每个对象出现的位置。特别检查空状态、错误提示、权限对话框和邮件主题，它们最容易落后于主界面改名。

改名属于迁移：在发布说明和搜索别名中暂时保留旧词，避免用户突然找不到功能。验收标准不是“所有词完全相同”，而是每个差异都有明确语义理由。
