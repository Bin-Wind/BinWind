# 触控目标间距：避免按钮够大却仍然容易误触

单个图标按钮达到建议尺寸，并不代表操作就可靠。两个高风险操作紧挨、透明可点区域重叠，或滚动手势与按钮竞争，仍会造成误触。

## 画出真实命中区域

在设计稿中标出可点击边界，而不只看图标轮廓。小图标可用内边距扩大目标，但相邻目标之间应保留清晰间隔，且不能覆盖其他元素。列表整行可点时，行内“更多”按钮需要独立命中区与明确事件规则。

把高频与破坏性动作分开：删除不应紧贴保存，撤销也不能依赖极短提示。底部区域要考虑系统手势、安全区、键盘和单手握持；悬浮按钮不能遮住最后一条内容。

## 用场景而非静态尺寸验收

在小屏、放大字体、屏幕旋转和单手操作下完成任务，记录误触而非只测像素。运动能力受限、手部颤动和移动环境中的用户会更依赖宽容布局。长按、双击等手势需要可发现的替代入口。

最终由真实设备验证，因为浏览器缩放的桌面预览无法还原手指遮挡和系统边缘手势。平台指南给出起点，实际任务的风险与频率决定是否还需更大目标和间距。
