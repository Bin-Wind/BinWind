# 键盘快捷键设计：让速度提升不牺牲可发现性

快捷键适合重复、高频且可撤销的动作，但不能成为唯一入口。每个命令仍应在菜单或界面中可找到，并在标签旁展示当前平台的按键组合。

先建立命令清单，记录作用域、前置条件、是否会修改数据以及浏览器、操作系统和辅助技术的保留键。单字母快捷键在输入框、编辑器和屏幕阅读器模式下尤其容易误触，应限制作用域或提供关闭选项。

冲突处理要有明确优先级：组件局部命令先判断焦点，随后才是页面级命令；`Escape` 的行为从最内层浮层开始退出。组合键监听应使用 `event.key` 表达字符意图，或在需要物理位置时明确使用 `event.code`，不能混为一谈。

验收时覆盖不同键盘布局、macOS 与 Windows 修饰键、输入法组合阶段和焦点位置。用户自定义快捷键需检测冲突并能恢复默认。设计完成的标志不是“按键能触发”，而是用户能发现、理解并安全退出。
