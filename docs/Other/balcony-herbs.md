# 阳台香草种植：罗勒、薄荷与迷迭香

香草适合小空间，但三种植物对水分的偏好不同。把它们种在同一个盆里通常不利于长期管理，分盆更容易控制。

## 光照与容器

多数食用香草需要明亮环境和数小时直射光。先连续几天观察阳台实际日照，而不是只看朝向。花盆必须有排水孔，盆底不要长期积水；土壤选择疏松、排水良好的栽培基质。

## 分别照顾

- **罗勒**喜温暖，表土开始变干时浇透。经常摘心能促进分枝，开花后叶片风味会变化。
- **薄荷**生长旺盛、喜欢较稳定水分，最好单独种，防止地下茎占满其他花盆。
- **迷迭香**更耐旱，最怕长期湿涝。两次浇水之间让土壤明显变干，并保证通风。

浇水不要死守日历。把手指插入表层土，结合花盆重量判断；浇时一次浇透，倒掉托盘积水。

## 采收与病虫

从健康植株上方嫩枝采收，每次不要剪掉大部分叶片。清晨或凉爽时采摘，洗净后尽快使用。发现蚜虫或红蜘蛛，先隔离植株并用清水冲洗叶背；需要处理剂时，选择明确标注可用于食用植物的产品，并严格遵守标签。

若叶片发黄，先检查积水、光照和根系空间，再考虑施肥。过量肥料会伤根，也可能让香气变淡。记录光照、浇水与生长变化，一季后就能得到适合自家阳台的小气候经验。
