# 数码文件整理：建立找得到的个人档案

文件整理不是给每个文档设计完美分类，而是让新文件有明确去处、旧文件能通过搜索找到、重要资料有可靠备份。

## 先建立少量顶层目录

```text
Documents/
  01_Projects/
  02_Areas/
  03_Resources/
  90_Archive/
  99_Inbox/
```

项目有明确结束时间，领域是持续责任，资料是未来可能参考的内容。暂时无法判断的文件先进入 Inbox，每周处理一次，不要在下载目录中永久堆积。

## 命名规则

用 `YYYY-MM-DD-主题-版本.ext` 表达日期和内容，例如 `2026-09-08-租房交接清单-v1.pdf`。避免“新建文档”“最终版真的最终”等依赖记忆的名称。需要排序的编号使用固定宽度。

## 去重与归档

先按文件哈希找完全相同副本，再人工判断相似文件。删除前把候选移动到临时隔离目录，确认一段时间后再处理。项目结束时保留最终成果、源文件、关键沟通和 README，其余缓存与可重建产物无需长期保存。

## 搜索与备份

重要扫描件做 OCR，但要抽查姓名、编号和金额。标签只用于跨目录维度，数量保持克制。备份至少覆盖误删历史、磁盘损坏和异地灾害三种情形，并定期随机恢复几个文件。

整理系统应该降低每次决策成本。如果你总在犹豫放哪里，说明顶层分类太多或定义不清，而不是需要更多文件夹。
