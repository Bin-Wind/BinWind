# TLS 证书故障排查：从握手到证书链

浏览器提示证书错误时，不要立刻重新签发。先区分域名不匹配、过期、证书链缺失、系统时间错误和协议握手失败。

## 查看服务实际返回

```bash
openssl s_client -connect example.com:443 -servername example.com \
  -showcerts </dev/null
```

`-servername` 会发送 SNI，缺少它时多站点服务器可能返回默认证书。重点检查叶子证书主题、签发者、有效期、返回的中间证书及最后的验证结果。

```bash
curl -Iv https://example.com/
```

`curl` 可同时显示 TLS 和 HTTP 重定向过程。不要用 `-k` 把证书校验关闭后宣布问题已解决。

## 常见修复

证书应覆盖实际访问域名，服务器通常要提供叶子证书和中间链，但不必发送根证书。续期成功却仍返回旧证书时，检查反向代理是否加载了新文件、证书路径是否正确，以及负载均衡各节点是否一致。

建立到期告警，并从外部网络定期探测。修改后同时测试主域名、备用域名和不同终端，防止本地缓存掩盖问题。
