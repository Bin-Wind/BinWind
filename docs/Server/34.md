# Linux 时间同步：排查时钟漂移与证书异常

系统时钟不准会导致 TLS 证书“尚未生效”、日志顺序错乱、令牌提前过期和分布式追踪无法对齐。时间同步属于基础设施依赖，不应等出故障才检查。

## 先看状态

使用 systemd 的服务器可执行：

```bash
timedatectl status
timedatectl timesync-status
date --iso-8601=seconds
```

关注系统时钟是否同步、时区是否正确以及最近使用的时间源。容器通常共享宿主机内核时钟，应在宿主机解决漂移，而不是在容器中运行多个时间服务。

## 修复与验证

确认 UDP 123 或所用协议没有被网络策略阻断，并配置组织认可的多个时间源。不要同时运行多个 NTP 客户端，它们会竞争调整时钟。大幅跳时可能影响定时器和数据库，应按所用服务的机制选择渐进校时或维护窗口。

告警监控时钟偏移量、同步状态和时间源可达性。排查跨机器日志时统一保存 UTC 时间戳，并在展示层转换时区；只写“本地时间”会在夏令时或跨地域环境中产生歧义。
