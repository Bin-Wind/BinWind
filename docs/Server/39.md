# Linux inode 耗尽：磁盘有空间也无法创建文件

文件系统同时受数据块和 inode 数量约束。大量小文件耗尽 inode 后，即使 `df -h` 仍显示空闲空间，创建文件也会报 `No space left on device`。

## 先确认是哪一种资源不足

```bash
df -h
df -i
sudo du -x --inodes --max-depth=2 /var 2>/dev/null | sort -n | tail
```

`df -i` 查看 inode 使用率，`du --inodes` 帮助定位目录。常见来源包括失控缓存、会话文件、邮件队列、小日志和构建产物。先停止持续制造文件的进程，再按应用保留规则清理；不要在未确认路径时批量删除。

删除后若资源未释放，检查进程是否仍持有已删除文件；数据块问题可用 `lsof +L1` 排查，但 inode 通常会在目录项删除后释放。长期方案是合并小对象、设置缓存上限与生命周期、监控 inode 百分比和增长速率。重新格式化调整 inode 密度属于高风险迁移，必须先备份并验证恢复。
