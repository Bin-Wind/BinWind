# cron 防重入：用 flock 避免任务重叠执行

定时任务运行时间超过调度间隔时，多个实例可能同时改同一批数据。flock 可为单机任务提供简单互斥。

~~~bash
flock -n /run/lock/report-job.lock /usr/local/bin/build-report
~~~

使用 -n 时拿不到锁立即退出，适合下一轮可以补做的任务；关键任务可设置有限等待并记录失败。锁文件放在权限明确且重启语义可接受的目录，脚本本身仍需幂等。flock 只约束共享同一文件系统锁的进程，跨主机部署要用数据库、队列或调度平台的分布式协调。监控最后成功时间，而不是只监控 cron 是否启动。
