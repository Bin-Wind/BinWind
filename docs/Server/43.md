# 磁盘 SMART 监测：在故障前发现介质异常

SMART 能暴露部分磁盘健康信号，但不能保证预测所有故障。先确认设备类型与控制器是否透传信息，再用 smartctl 查看总体状态、错误日志和关键属性。

~~~bash
sudo smartctl --health /dev/sda
sudo smartctl --attributes /dev/sda
sudo smartctl --log=error /dev/sda
~~~

重点观察不可校正错误、待处理扇区和重映射趋势，而不是机械套用所有厂商原始值。NVMe 使用对应健康日志，阵列卡后的设备可能需要指定设备类型。短测和长测会增加 I/O，应按业务窗口安排。SMART 告警后先确认备份可恢复、记录序列号并准备更换；健康状态正常也不能替代备份与冗余。
