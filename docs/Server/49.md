# Linux 时间同步排查：从时钟偏差到 NTP 来源

时钟偏差会造成证书校验失败、日志顺序混乱和分布式租约异常。先确认系统当前状态与时区，不要直接手工改时间掩盖同步问题。

~~~bash
timedatectl status
date --iso-8601=seconds
~~~

若系统使用 chrony，可继续检查：

~~~bash
chronyc tracking
chronyc sources -v
~~~

`tracking` 展示当前参考源、系统偏差和校正状态；`sources` 用于判断候选时间源是否可达及哪一个被选中。使用其他 NTP 守护进程时应查对应工具，不要同时启动多个服务争夺系统时钟。

排查网络 ACL、DNS、虚拟机宿主时间和休眠恢复，并记录偏差是逐渐累积还是突然跳变。时间严重错误时，是否允许步进校正要按业务评估：数据库、鉴权和定时任务可能无法接受向后跳时。

最终以持续指标验收，包括同步状态、偏差、可达时间源数量和校正频率。时区只影响显示，NTP 解决的是系统时钟，两者不能互相替代。
