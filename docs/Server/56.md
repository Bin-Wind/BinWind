# journalctl 游标续读：从上次位置继续采集日志

按时间戳续读日志容易在时钟校准或同一微秒多条记录时重复、遗漏。systemd journal 的 cursor 是某条记录的稳定位置，更适合增量采集。

先取得最后一条已处理记录及其游标：

```bash
journalctl -u myapp.service -n 1 --show-cursor --no-pager
```

将输出末尾 `-- cursor: ...` 的值保存到采集器状态文件。下次使用：

```bash
journalctl -u myapp.service --after-cursor='s=...' --output=json --no-pager
```

只有在下游成功持久化一批记录后，才原子更新游标；先更新游标再写入会在崩溃时丢日志。下游按 journal 记录 ID 或自有幂等键去重，可应对写入成功但游标尚未保存的重复消费。

journal 轮转、真空清理或机器重装后，旧游标可能不可用。采集器应检测错误，按保守时间窗口回退并告警，而不是悄悄从“现在”开始。游标只在对应 journal 范围内有意义，跨主机迁移时需分别保存状态。
