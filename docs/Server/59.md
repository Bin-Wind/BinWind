# logrotate 调试：先预演轮转，再交给定时任务

日志不轮转会占满磁盘，错误轮转则可能让服务继续写入已删除文件。修改规则后，先验证解析结果和状态文件，再决定是否强制执行。

## 从最小规则开始

```text
/var/log/example/app.log {
    daily
    rotate 14
    missingok
    notifempty
    compress
    delaycompress
    create 0640 app app
}
```

用 `sudo logrotate --debug /etc/logrotate.d/example` 预演；调试模式不会真正轮转。确认路径、用户和指令后，可在维护窗口用 `--force` 测试一次，并检查新旧文件权限、压缩结果和服务写入位置。

## 选择重开方式

能响应信号重新打开日志的服务，应在 `postrotate` 中调用官方重载命令。只有无法重开文件的旧程序才考虑 `copytruncate`；复制与截断之间可能丢失或重复少量日志。最后检查系统定时器和 logrotate 状态文件，避免手工成功、自动任务却从未运行。
