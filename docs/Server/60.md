# systemctl show：读取服务的实际运行属性

`systemctl status` 适合人工浏览，脚本则更适合读取 `systemctl show` 的稳定属性。它能同时看到单元配置与 systemd 计算后的运行状态。

```bash
systemctl show ssh.service \
  --property=LoadState \
  --property=ActiveState \
  --property=SubState \
  --property=MainPID \
  --property=ExecMainStatus \
  --property=FragmentPath
```

## 不把“active”当成全部健康

`ActiveState=active` 只说明 systemd 认为单元处于活动状态，不代表业务端口、依赖或请求都正常。结合 `SubState`、退出码、最近日志和应用自己的健康检查判断。一次性任务可能以 `active (exited)` 合理存在，不能套用常驻服务标准。

脚本若只取一个值，可加 `--value --property=ActiveState`，但仍要处理命令失败和单元不存在。排障时再用 `systemctl cat` 查看主文件与 Drop-In，确认“实际属性”来自哪一层配置。
