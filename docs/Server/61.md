# rsync 断点续传：区分临时文件、校验与最终发布

大文件传输中断后，直接重来既慢又增加源端压力。`rsync` 可以保留部分结果继续传输，但参数应围绕“未完成文件放哪里、何时视为完成”来选择。

```bash
rsync -a --partial --partial-dir=.rsync-partial \
  --info=progress2 \
  ./release/ user@example:/srv/releases/incoming/
```

`--partial-dir` 把未完成块与目标文件分开，减少消费者误读半成品的风险。传输结束后核对退出码，再在目标机运行清单校验并原子切换发布指针。

## 不要默认开启所有选项

`--append` 假设目标只是源文件的前缀，内容被改写时可能得到错误结果；`--checksum` 会读完两端文件，适合时间戳不可信或验收阶段，不一定适合每次同步。带 `--delete` 的镜像操作先用 `--dry-run` 查看删除清单，并确保目标路径已解析到预期目录。
