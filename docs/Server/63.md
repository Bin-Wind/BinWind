# ss 查看监听端口：从套接字定位到进程

端口冲突或服务无法访问时，先确认机器实际监听了什么。`ss` 直接读取内核套接字信息，通常比猜测配置文件更可靠。

## 列出 TCP 监听者

```bash
sudo ss -ltnp
```

- `-l`：只看监听套接字；
- `-t`：TCP；
- `-n`：不解析服务名，直接显示数字端口；
- `-p`：显示进程，需要相应权限。

只检查 8080 端口：

```bash
sudo ss -ltnp 'sport = :8080'
```

输出中的本地地址同样重要。`127.0.0.1:8080` 只能从本机访问，`0.0.0.0:8080` 表示所有 IPv4 接口；`[::]:8080` 的 IPv4 行为还受系统双栈设置影响。确认监听后，再检查防火墙、云安全组和反向代理，不能把“正在监听”直接等同于“公网可达”。

## UDP 与已建立连接

DNS 等 UDP 服务使用：

```bash
sudo ss -lunp
```

观察到某进程后，用 `systemctl status` 或进程管理器确认它为何启动，不要直接 `kill -9`。若进程信息缺失，可能是权限不足或进程已退出。记录查询时间、网络命名空间和容器边界；宿主机、容器内看到的监听表可能不同。
