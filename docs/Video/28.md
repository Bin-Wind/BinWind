# 视频素材归档：命名、校验与长期保存

素材归档的目标是几年后仍能找到、验证并重新剪辑。只把项目文件拖进一块硬盘，往往会留下离线媒体、缺失字体和无法识别的代理文件。

## 摄制当天

每张存储卡至少复制到两个独立位置，再格式化原卡。复制后使用支持校验和的工具验证，不能只比较文件数量。目录按项目、日期、机位和卡号组织：

```text
ProjectName/
  01_Footage/2026-09-08/A_CAM_CARD01/
  02_Audio/
  03_Project/
  04_Exports/
  05_Documents/
```

保留相机原始文件名或在前面加唯一前缀，避免不同卡出现同名片段。

## 完成项目时收集依赖

整理最终工程、原始素材、正式音频、字幕、字体许可、LUT、图形源文件和最终导出。代理与渲染缓存通常可以重建，但要记录生成方式。删除素材前先复制到隔离目录并重新打开工程检查离线项。

## 保存策略

至少保留三个副本、两种介质、一份异地。硬盘不是永久介质，定期通电、读取并计算校验和；发现错误时从健康副本修复。每隔几年评估接口、文件系统与编解码器是否仍受支持，必要时迁移。

## 建立索引

在项目根目录保存 README，记录内容摘要、日期、参与者、版权限制、软件版本和关键导出位置。好的归档不是一堆“最终版2_真的最终”，而是一套可验证、可解释的项目资产。
