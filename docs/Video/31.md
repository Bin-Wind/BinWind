# 视频导出质检清单：交付前完整看一遍

时间线播放正常不等于导出文件正确。离线媒体、错误入出点、字幕裁切和编码异常往往只出现在最终文件中，因此成片必须从头到尾检查。

## 导出前

确认时间线分辨率、帧率、音频采样率和色彩空间符合交付要求；清除禁用片段、测试字幕和临时水印。检查首尾黑场、片尾长度与文件命名。

## 导出后

用交付播放器观看最终文件，重点检查：

- 画面是否有黑帧、离线素材、闪烁或比例错误；
- 对白是否清楚，左右声道、峰值和同步是否正常；
- 字幕是否错字、越界、过快或与画面冲突；
- 章节、封面和元数据是否正确；
- 文件能否在另一台设备完整播放。

## 可追溯交付

记录导出预设、软件版本、时长、文件大小和校验和。平台二次压缩后再抽查一次关键段落。若有多个比例或语言版本，为每个版本单独走清单，不能用横版通过来推定竖版也正确。
