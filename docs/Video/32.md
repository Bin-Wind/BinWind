# 帧率与快门：让运动模糊服务于画面

帧率决定每秒记录多少幅画面，快门时间决定每一帧曝光多久。两者共同影响运动是否连贯、模糊是否自然，不能只在导出时随意选择。

## 建立基准

叙事和日常内容常用 24、25 或 30 fps；快速运动或需要慢放时可拍 50 或 60 fps。项目开始先确定交付帧率，并让主素材保持一致，避免时间线上混合转换产生不规律卡顿。

自然运动模糊的常见起点是快门时间约等于帧间隔的一半：25 fps 可从 1/50 秒开始，30 fps 从 1/60 秒开始。这不是硬性规则；更快快门会得到清脆、跳跃的动作，更慢则拖影更明显。

## 现场验证

户外为保持快门而曝光过亮时使用合适 ND 滤镜，不要不断提高快门补救。人工灯光下先检查频闪，电源频率、灯具调光方式和快门组合都会影响条纹。

拍摄前录一段包含人物走动和横向摇摄的测试，在正常速度与预定慢放速度下回看。元数据记录帧率和快门，剪辑时才能判断素材意图。
