# 字幕质检：从文字正确到观看舒适

自动字幕只能提供初稿。人名、术语、数字和断句错误会改变意思，过长或闪现的字幕即使文字正确也难以阅读。

## 先校内容

逐句对照声音，重点核对专有名词、否定词、金额、日期和单位。建立项目词表统一人名与术语写法。听不清的地方标记回查，不能靠上下文编出一句看似合理的话。

## 再校时间与版式

字幕入点贴近说话开始，出点避免压到下一位说话者。按语义短语断行，不把姓名与称谓、数量与单位拆开。控制每条长度和显示时间，在手机尺寸上按正常速度完整观看；安全区要避开平台按钮、人物姓名条和画面内文字。

说话者不明显时增加简洁标识，重要环境声用一致格式说明。多语言版本分别检查文本增长、标点和阅读方向，不能只替换文字后沿用所有断行。

最后审查导出成片而非编辑器预览，随机跳看无法发现累积漂移。交付时同时保留带时间码字幕文件、词表和烧录版本，便于平台上传与后续修订。
