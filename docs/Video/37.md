# 响度统一：让对白、音乐与平台播放更稳定

峰值相同的两个视频，听起来可能一大一小。峰值描述瞬间上限，节目响度则更接近人耳对一段时间音量的感受，通常用 LUFS 表示。

## 先完成混音，再测量

对白优先保证清晰，使用增益、轻度压缩和自动化控制句间差异；音乐在对白出现时降低，而不是靠最终限制器硬压。去噪过度会产生金属伪影，应在正常播放设备上判断。

导出前测量整段 integrated loudness、短时响度和 true peak。交付目标以平台或客户最新规范为准，不要把某个 LUFS 数字当作所有场景通用答案。

## 调整而不破坏动态

整体过响时先降低总线增益；局部峰值超限再用 true-peak limiter 捕捉。只把波形归一化到 0 dBFS 既不能统一听感，也可能在编码后产生削波。

质检至少包含：

- 耳机、手机扬声器和普通音箱上的对白可懂度；
- 片头、正片与片尾音量是否突变；
- 单声道折叠后有无相位抵消；
- 编码成最终格式后的响度与真峰值复测；
- 从头到尾实时听一遍。

保留无损混音母版和测量报告，平台再次转码或制作不同版本时就不必从有损文件反复处理。
