# 代理媒体剪辑：低配置设备也能流畅处理高码率素材

代理媒体是原始素材的低分辨率、易解码副本。剪辑时使用代理提升流畅度，最终导出再自动链接回原片，不会因为预览清晰度降低而牺牲交付质量。

## 从可验证的对应关系开始

导入后先校验原片，保留文件名、帧率、音频声道和时间码。代理可选较低分辨率的帧内编码，并统一保存到独立目录；不要修改原始文件。随机抽查开头、中段、结尾的画面和声音同步。

剪辑软件中用正式的代理绑定功能切换，不要手工覆盖原文件。变速、稳定、降噪等效果要在回连原片后检查，因为代理可能隐藏细节问题。多人协作时共享代理预设、目录规则和素材 ID。

导出前关闭代理显示，确认所有媒体已回连，检查离线素材、分辨率、色彩空间和音频声道。代理可以重建，原片、项目文件和关键元数据才需要纳入可靠备份。
