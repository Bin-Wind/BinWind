# 素材入库校验：复制完成不等于文件完整

相机卡复制到工作盘后，应通过校验和确认目标文件与源文件逐字节一致。只比较文件名和大小无法发现部分静默损坏。

~~~bash
find /Volumes/CAMERA -type f -print0 | sort -z | xargs -0 shasum -a 256 > camera.sha256
# 在保持相同相对路径的副本目录中再次生成清单并比较
~~~

专业拷贝工具可在复制时执行校验并生成报告。至少保留两份位于不同设备的已验证副本，再格式化相机卡；重要项目还应有异地副本。清单记录卡号、日期、操作人和算法，目录结构保持稳定。代理文件可重建，原始素材和项目文件优先保护。恢复演练比“有两个硬盘”更能证明备份有效。
