# J-cut 与 L-cut：用声音跨越剪辑点

画面和声音同时硬切，访谈容易像轮流朗读。J-cut 让下一镜头的声音先进入，L-cut 则让上一镜头的声音延续到新画面，两者都能让注意力自然转移。

先完成对白内容剪辑，再解除音视频联动，保留足够的句首呼吸与句尾余韵。J-cut 适合用下一位说话者的声音引导切换；L-cut 可在上一位继续说时展示倾听反应或相关 B-roll。交叠长度由语义和节奏决定，不需要统一秒数。

底噪不同会暴露接缝，应铺设匹配的 room tone 并做短淡化，但不能用音乐掩盖对白跳变。避免把反应镜头挪到并未发生的语境中造成误导。最终闭眼听一遍、静音看一遍，再检查声音逻辑和视觉连续性是否各自成立。
