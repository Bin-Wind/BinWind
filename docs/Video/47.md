# 代理文件回套：轻量剪辑后准确链接原始素材

代理文件让低性能设备也能顺畅剪辑，但最终输出必须准确回到原始素材。创建代理前保留唯一素材 ID、原文件名、时码、帧率、画幅和音频通道，不要只靠相似文件名匹配。

代理应保持时长、帧率和起始时码一致，避免可变帧率或裁切改变帧对应关系。转码后抽查首帧、尾帧、长镜头和独立录音同步，并让剪辑软件明确标识当前显示的是代理还是原片。

锁定剪辑后切换原始素材，逐段检查离线媒体、变速、稳定、重构图和特效。随机抽取剪辑点做帧级比对，并以原始分辨率查看焦点、噪声和边缘；代理上看不出的质量问题会在此阶段出现。

归档时保留项目、代理生成规则和素材映射清单。代理可以重建，原片和映射关系不可替代，不要为节省空间先删原片再开始回套。
