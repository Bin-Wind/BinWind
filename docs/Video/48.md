# 环境底噪铺设：让对白剪口不再忽然真空

对白删除停顿或换接镜次后，背景声突然归零会暴露剪口。拍摄现场应在人员与设备保持原位时录制 30～60 秒 room tone，记录场景、机位和麦克风设置。

剪辑时从同一场景选择没有说话、碰撞和明显瞬态的片段，铺在对白下方并用短交叉淡化连接。不要无限循环很短的一秒钟，周期性空调声或街声会变得明显；可交错使用多个较长片段。

先匹配响度与频谱，再处理剪口。底噪用于恢复连续空间，不是用降噪把所有声音抹平。若不同镜次噪声差异很大，分别轻度处理并在自然动作或景别变化处过渡。

最终用耳机和普通扬声器复听，并把音量暂时提高检查泵动、循环和突变。保留原始现场声轨，便于后续混音重新选择。
