# 字幕断行设计：按语义切分而不是塞满宽度

字幕断行应帮助观众按语义读取。优先在短语或从句边界换行，让修饰语与被修饰词、介词与宾语、姓名与称谓尽量留在一起；不要仅按固定字符数机械切断。

两行字幕的长度尽量平衡，但语义完整优先。出现数字、单位、网址和专有名词时检查是否被拆开。时间轴上给观众足够阅读时间，并让字幕出现与话语起点接近，不能为了塞完长句一直拖到下一位说话者。

在最终画幅和实际播放尺寸检查，避开人物口型、关键信息、平台按钮与安全区。竖屏、横屏不能只缩放同一版字幕；窄画幅通常需要重新断行和调整位置。

导出前分别审查文本、时间和画面三个层面，再抽查静音观看能否理解说话者切换。自动字幕可提供初稿，但人名、术语、标点与断行仍需要人工校对。
