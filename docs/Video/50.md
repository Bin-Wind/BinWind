# 容器与编码区分：排查“有画面却无法导入”

MP4、MOV 和 MKV 是容器，H.264、HEVC、ProRes 和 AV1 是编码。扩展名相同不代表内部编码、色度采样或音频格式相同；剪辑软件能打开一个 MP4，也可能拒绝另一个 MP4。

## 先读取媒体信息

```bash
ffprobe -v error -show_entries \
stream=index,codec_type,codec_name,profile,pix_fmt,width,height,r_frame_rate \
-of json input.mp4
```

记录视频编码、profile、像素格式、分辨率、帧率，以及音频编码与采样率。可变帧率素材还要结合时间戳判断，不能只看名义帧率。

## 转封装还是转码

目标软件支持现有音视频编码、只是容器不兼容时，可以转封装，速度快且不重新压缩。编码或像素格式不支持时才转码，并选择符合编辑或交付目标的中间格式。不要通过修改扩展名伪装容器。

## 保留原始素材

所有处理在副本上进行，记录命令、工具版本和输出摘要。转码后检查时长、首尾帧、音画同步、色彩和声道，而不只确认文件能导入。HDR、旋转元数据和多音轨特别容易在转换中丢失。

交付规范应同时写容器、视频编码、音频编码、帧率、分辨率和色彩要求。“交一个 MP4”不是完整技术规格。
