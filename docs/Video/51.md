# 场记板元数据：让镜头编号从片场贯穿到剪辑

场记板不只是同步拍板的声音。场次、镜次、条次、日期和音频卷号构成素材身份，能减少导入后靠缩略图猜内容的时间。

## 拍摄前统一命名

明确场次与镜次格式，例如 `S012_C03_T02`，并约定重拍、补拍和无场记板素材如何编号。摄像机、录音机和场记表使用同一日期与卷号。电子场记板时间码只是辅助，仍要让画面与录音都能看到或听到明确标记。

## 每条记录什么

除编号外，记录机位、镜头、帧率、滤镜、是否好条以及异常说明。好条标记是建议，不应导致其他条次被删除；表演、对焦或声音各自可能有不同价值。

## 入库核对

备份完成后，将文件时间、视频画面中的板号、音频口播和场记表交叉核对。发现重复编号时先加卷号或摄像机前缀，不直接覆盖文件。把标准化信息写入剪辑软件元数据字段，原始文件名若已被设备固定则保留映射表。

抽查每个拍摄日的首条、末条和特殊帧率素材，确认音视频能通过拍板或时间码对齐。元数据链的目标，是任何一条时间线片段都能追溯到原始文件和现场记录。
