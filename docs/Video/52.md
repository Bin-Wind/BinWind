# 安全框与边缘质检：为不同屏幕保留重要信息

现代平台通常能显示完整画面，但字幕、台标和互动按钮仍可能被播放器控件、刘海、裁切或平台 UI 遮挡。安全框不是固定神奇比例，而是针对目标平台与观看环境的验证区域。

## 先列交付目标

确定横屏、竖屏和方形版本，以及是否会被电视过扫描、社交平台界面或应用内控件覆盖。获取平台当前模板或规范，并把它作为可更新资产管理；不要凭多年以前的经验线猜位置。

## 分清两类安全区

动作安全区保证关键人物和操作不因轻微裁切丢失；标题安全区更保守，用于字幕、姓名条和必要说明。装饰可以越界，决定理解的信息不应贴边。竖屏短视频还要给右侧互动按钮和底部说明留空间。

## 在真实尺寸质检

导出后分别在手机、桌面和目标播放器查看，打开控制条、字幕和系统缩放。检查最小字号、长姓名换行、双语字幕和极端画幅。只在大监视器上看模板，容易高估小屏可读性。

最终保存各平台模板版本与测试日期。平台界面更新后先复测代表性成片，再调整批量模板。安全框的价值来自真实覆盖测试，而不是让所有元素机械缩到画面中央。
