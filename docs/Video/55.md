# 可变帧率素材：先识别时间戳，再决定是否转码

手机、录屏和视频会议常为控制文件大小或适应负载而使用可变帧率（VFR）。部分剪辑流程会出现音画逐渐不同步、逐帧定位不稳定或代理回套偏移。问题关键是时间戳，不是简单把文件标签改成固定帧率。

先用探测工具查看帧率与时间基：

```bash
ffprobe -v error -select_streams v:0 \
  -show_entries stream=avg_frame_rate,r_frame_rate,time_base,duration \
  -of default=noprint_wrappers=1 input.mp4
```

`avg_frame_rate` 与 `r_frame_rate` 不同只是线索，还应在剪辑软件中检查长片段尾部同步和帧时间戳。不要仅凭某一个字段自动判定所有素材。

## 需要时转为恒定帧率

在保留原件的前提下，按项目时间线生成中间文件：

```bash
ffmpeg -i input.mp4 -vf fps=30000/1001 \
  -c:v prores_ks -profile:v 2 -c:a pcm_s16le output-cfr.mov
```

目标帧率应由交付与原始运动决定，转换可能复制或丢弃帧，不能创造真实画面。转码后比较时长、开头与结尾同步、关键动作和音频声道，并保存源文件名映射。若剪辑软件原生稳定支持 VFR，可不转码，但仍应先做代表性长片段测试。
