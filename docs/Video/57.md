# 代理素材重连验收：防止成片悄悄回到低清文件

代理剪辑完成后，导出前必须确认时间线已重新连接原始素材。文件名相同并不足以证明重连正确，帧率、起始时间码和音频声道变化都可能造成错位。

先保留代理与原始媒体的唯一卷名、剪辑名和时间码，不在中途批量改名。重连后让软件显示媒体路径、分辨率和编解码器，筛选仍指向代理目录的片段。随机抽查每个机位的开头、中段、结尾和速度变化镜头。

将离线参考导出与在线时间线叠加或快速切换，检查动作帧、字幕、缩放、稳定和变速点。代理若烧入水印，成片中任何残留都应阻止导出。音频也要核对源声道映射，不能只看画面。

最终渲染前清空或绕过代理优先设置，并做一段高质量测试导出查看实际编码信息。归档时保存项目、重连报告与少量参考，不依赖未来仍存在的缓存路径。
