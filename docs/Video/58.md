# 运动镜头快门检查：在自然模糊与清晰定格间取舍

帧率决定每秒采样次数，快门时间决定每帧曝光期间物体移动多少。常见的“180 度快门”意味着快门时间约为帧间隔的一半，例如 25 fps 约为 1/50 秒，但它只是自然运动感的起点，不是硬规则。

拍摄前让主体以真实速度横穿画面，分别测试基准、较快和较慢快门。较快快门会让单帧更清楚，却可能让播放显得生硬；较慢快门增加拖影，并可能掩盖细节。相机移动、焦距和观看尺寸都会改变感受。

在灯光环境中同时检查频闪或滚动条纹。为匹配当地供电与灯具调光方式，可能需要微调快门；不能为了遵守固定角度而接受明显闪烁。升格素材应按实际拍摄帧率重新计算，而不是沿用项目时间线数值。

把测试片段在目标帧率和交付屏幕上播放，再锁定设置。快门选择服务于动作表达与光源条件，不能仅凭静止帧是否锐利来判断。
