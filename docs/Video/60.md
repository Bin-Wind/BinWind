# 响度表读法：同时观察瞬时、短时与全片积分

峰值不削波并不代表节目听起来同样响。响度表通常提供瞬时、短时和积分读数：它们回答的是不同时间尺度的问题。

## 用读数定位问题

瞬时读数帮助发现某个词或音效的突兀；短时读数适合比较一句对白和相邻段落；积分响度描述测量区间的整体水平。真峰值则关注采样间重建后可能出现的峰值风险，不能用响度读数替代。

## 按交付规范测量

先确认平台、广播机构或客户要求的目标、容差、门限和声道布局，不套用一个通用数字。把响度表放在最终母线，重置后从头到尾播放完整交付版本；片头静音、广告段或多版本内容是否计入，应按规范处理。

调整时优先修复对白不一致、过度压缩和失控低频，再做整体增益。达到目标后重新测量全片，并试听小音量、耳机与音箱环境，避免为了一个数字牺牲可懂度和动态。
