# 视频归档校验：用清单证明文件没有悄悄损坏

把工程复制到硬盘不等于归档完成。可靠归档要能回答保存了什么、文件是否完整、用什么软件与字体才能重建成片。

## 生成可核对清单

整理原始素材、工程、代理映射、图形源文件、字幕、音频分轨、授权文件与最终母版。复制完成后为文件生成 SHA-256 清单，并在另一位置重新读取验证；摘要文件本身也要与归档说明一起保存。

```bash
find archive -type f -print0 | sort -z | xargs -0 shasum -a 256 > SHA256SUMS
shasum -a 256 -c SHA256SUMS
```

文件名含换行时，简单文本清单仍可能难以解析；正式流程可使用支持空字符记录的归档工具或禁止异常命名。

## 验证可恢复性

在隔离环境打开工程，随机重连原素材并导出短片，确认插件、字体、LUT 和色彩管理说明齐全。保留至少两个独立介质或位置，定期抽检并迁移老化载体。归档成功的标准是能恢复，不是“硬盘灯亮过”。
