# 代理文件时间码验收：确保离线剪辑能够准确回套

代理文件让低性能设备也能流畅剪辑，但最终必须重新连接原始素材。若代理改变帧率、起始时间码或音频布局，剪辑点可能错位，直到交付前才暴露。

## 转码前保留身份

代理应保留源素材帧率、时长、起始时间码和唯一卷标，并在文件名或元数据中建立可逆映射。不要把 23.976 fps 素材随手转成 24 fps，也不要因为代理分辨率低就删除变帧率处理信息。相机跨午夜或多机文件名重复时，单靠文件名无法可靠匹配。

## 抽样回套测试

在正式剪辑前选每台相机的首、中、尾片段：

1. 用代理建立几个精确剪点和速度正常的片段；
2. 切换回原始素材；
3. 对比画面事件、口型、音频波形和时间码；
4. 检查长素材尾部是否逐渐漂移；
5. 导出短样片，确认渲染实际使用原始文件。

若素材是可变帧率，先按剪辑软件推荐流程转为稳定中间格式，并保存原文件，不要只修改元数据宣称为固定帧率。

回套前冻结代理映射并备份项目。出现偏移时先查帧率解释、起始时间码和音频采样率，不要逐个手工拖动剪辑点掩盖系统性错误。代理流程的成功标准不是“播放顺畅”，而是每个编辑决定都能无损落回原始素材。
