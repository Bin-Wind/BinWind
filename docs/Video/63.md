# 字幕断行检查：让语义、节奏与可读性同时成立

字幕内容正确，却在介词后、姓名中间或数字单位之间断行，会增加阅读负担。自动按字符数切割只能提供初稿，最终断行应同时考虑语义单元、画面宽度和出现时长。

## 优先保留语义块

尽量把名词与修饰语、动词与宾语、数字与单位留在同一行；避免第一行只剩一个短虚词。两行字幕通常上行略短或长度接近更易扫读，但不能为了形状漂亮改变原句顺序。

断行还要避开镜头中的关键信息。竖屏、横屏和不同安全区需要分别预览；说话人标签、音效说明和双语字幕会额外占用空间。字号不能为了塞下长句不断缩小，应拆分时间段或精简不影响意义的口语重复。

## 在播放中验收

静止画面看起来合适，不代表观众来得及读。按目标平台播放，检查字幕出现是否覆盖完整语义、切换是否跟随自然停顿，以及快速对白中是否频繁闪烁。相邻字幕间隔过短时，可调整切点，但不要让字幕提前泄露尚未说出的关键信息。

对姓名、专业术语、数字和否定词做专项复核，因为错误断行可能改变理解。最后在手机与大屏各看一次，并打开平台实际播放器，确认上传后的字体替换与缩放没有重新破坏行长。
