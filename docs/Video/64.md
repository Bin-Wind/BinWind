# 导出色彩标签核对：避免播放器误解素材颜色

同一个成片在剪辑软件里正常，上传后却发灰或过饱和，常见原因不是调色本身，而是文件的色彩原色、传递函数或矩阵标签与实际像素不一致。播放器按错误标签解释数据，就会得到另一种画面。

## 先固定交付目标

确认项目是 SDR 还是 HDR、目标平台要求、时间线工作色彩空间与监看链路。SDR 网络视频常见目标是 Rec.709，但具体传递特性和平台处理仍需遵循交付规范；HDR 还涉及 PQ/HLG、峰值亮度与元数据，不能仅靠把导出标签改成 HDR。

导出后用媒体检查工具读取编码、位深、色彩原色、传递特性和矩阵系数，并与导出设置核对。抽取若干帧与时间线参考对比，特别检查黑位、肤色、高光和高饱和区域。

## 用真实播放链路复核

至少在一个色彩管理播放器和目标平台的测试上传中检查。浏览器、系统播放器和手机屏幕可能有差异，应判断是文件标签、显示管理还是平台转码导致，而不是反复盲调素材。测试片可包含灰阶、色条和已知参考画面。

不要通过移除标签来“让某个播放器看起来对”。无标签文件会迫使各播放器猜测，跨设备结果更不稳定。保留母版、导出预设、软件版本和检查结果，确保以后重新压制时能复现同一色彩解释。
